## 🎬 这不是一款"你操作角色"的游戏

传统模拟经营里，你是指挥官：圈地、指派、催工。在这里，**你只是观察者**。

你什么都不用做。部落民会自己饿、自己渴、自己扛着水粮走回家，自己在泉边与果丛之间踩出第一条小径，自己攒够建材盖起第一间房，自己去追求心仪的对象、娶妻、生子、老去，然后由儿子继承那间漏雨的茅草房。

系统只扮演"物理规则执行者"：**放置校验、路网接入、施工结算、交易交割**。
至于"盖不盖、何时盖、盖在哪、娶不娶、夺不夺位"——那是他们自己的事。

> 于是你会看到一些没人写过的剧情：
> 有人在寒冬前囤够了柴火，有人家徒四壁而冬天硬扛；
> 有人一路走到帝国大道上，也有人一辈子在荒野里 0.5 倍速地挪；
> 老国王咽气的同一秒，某个年轻人扔下建到一半的房子，横跨地图冲向无主的营地；
> 水荒粮荒、野外断流时，有人揣着最后一点黄金，扑向涨价 100 倍的榷场买命。

## ✨ 八个值得盯着看的理由

### 1. 🧠 真·自主 AI：马斯洛五层需求驱动

每个族人心里都压着一座金字塔，**低层需求绝对阻断高层欲望**：

| 层次 | 需求 | 他们会做什么 |
| :--- | :--- | :--- |
| ① 生理 | 夺位远征 / 解渴 / 觅食 / 休养 / 立宅 | 王位是生存资源的分配权，空缺王位会点燃最原始的野心；渴了冲向清泉、饿了扑向浆果；无家成年男性生理稳定后自主掷点选址立宅 |
| ② 安全 | 房屋修缮 / 水粮储备 | 家宅耐久掉到 50% 就一路修到 100%；家户账本库存跌破红线就出发补货 |
| ③ 归属与爱 | 求偶成婚 / 家庭供给 | 单身男性主动出击，追求魅力最高的单身女性；成家后为家人驮运 |
| ④ 尊重 | 升级施工 / 采石备料 / 养育小孩 | 账本付得起升级建材就开工，一砖一瓦往上堆；想延续血脉，就真的付诸行动 |
| ⑤ 自我实现 | 大庄园备金 / 娱乐淘金 | 4 级大庄园竣工前，绝不许自己享乐淘金 |

决策**没有掷骰子**——同样的处境必然做出同样的选择。你看到的是规则推演出的命运，不是随机数。资源点该不该跑一趟，也由每名族人心里那把**私有标尺**（施密特触发器）说了算：库存过半才值得出发，跌破一成就不再前往，途中发现目标枯竭还会当场掉头、平滑改道，绝不瞬移。

更妙的是，**你可以策展他们的价值观**：页面上的「🧠 决策引擎」视图把 17 条决策分支排成可拖动的卡片，拖一下分界线，运行中的模拟立即热注入——让这个部落把"求偶"排到"囤货"前面，或是反过来。

### 2. 🛤️ 路，是他们自己踩出来的

没有预设路网。族人走过的每一段路都会累加踩踏值，从荒野小径一路升级成**紫金色的帝国大道**；没人走的路则按比例衰减，静静长回荒野。

| 等级 | 名称 | 移速加成 |
| :--- | :--- | :---: |
| 1 | 泥土细道 | 0.50× → |
| 2 | 夯土小道 | ⬆ |
| 3 | 硬质石道 | ⬆ |
| 4 | 精修通衢 | ⬆ |
| 5 | 帝国大道 | 2.20× |

一条被几代人反复踩踏的道路，就是一部无声的家族迁徙史。

### 3. 🏰 从一间仓库到一座大庄园

房屋分 5 级：**仓库 → 茅草房 → 半棚屋 → 木石庄舍 → 大庄园**。升级不再是"攒到某个百分比自动盖"，而是**家户账本一次性支付固定建材矩阵**、瞬时晋升：

| 等级 | 名称 | 升级所需建材（水/粮/木/石/金） | 解锁 |
| :--- | :--- | :--- | :--- |
| 0 | 📦 仓库 | 立宅起步（生理层末档自主选址） | 遮风挡雨的基本盘 |
| 1 | 🛖 茅草房 | 水 50 + 粮 50 | — |
| 2 | 🏡 半棚屋 | 木 75 + 水粮各 75 | — |
| 3 | 🏯 木石庄舍 | 石 100 + 水粮木各 100 | 前往金矿淘金 |
| 4 | 🏰 大庄园 | 金 125 + 水粮木石各 125 | 娱乐淘金、终极形态 |

每晋升一级，户主威望 +1——而国王与宗族长老天生自带 **+3 威望**（兼任双重身份叠加为 +6），荣誉写在血脉里。

房子会**自然折旧**（0.04/s，有主无主统一速率），耐久掉到一半就会有人放下一切去修。户主去世后，房屋变为无主空置房，由营地中介主持**麦穗 37% 最优停止博弈拍卖**：前 37% 损耗期只摸底立标杆、绝不出售；进入决策期后新报价 ≥ 标杆即成交；跌过 10% 出清线则见价就卖，无人问津便随耐久归零坍塌。竞价**下沉到每个族人自己的决策相位**——无房者倾囊出价，有房者也能按等级差折算成本**改善换房**；成交款按份额分给王国公户与在世配偶、子女。你能在地图上看到金色呼吸光晕与悬浮标牌，随时点开拍卖大盘，实时窥视族人们的竞价流水。

### 4. ❄️ 四季轮转，冬天会咬掉你的柴火储备

一年 = 240 秒，气温在 **-3℃ ~ 31℃** 之间正弦起伏。入冬或气温跌破 5℃ 时，所有非 0 级有主房屋每秒从**家户账本**烧掉 0.12 木材取暖——柴火是冬天的硬通货，账本见底的家族只能在寒风中硬扛。

春夏秋三季偷懒不囤柴的家族，会在冬天付出代价。

### 5. 🧬 生死、遗传与六维禀赋

四项生理指标（健康 / 饱食 / 水分 / 体力）持续代谢，饿死与渴死会在顶栏被单独统计，遗体保留 12 秒逐渐风化消散。

每个族人携带六项先天禀赋：**智力 / 力量 / 魅力 / 消化效率 / 睡眠效率 / 预期寿命**。始祖按正态分布生成，新生儿取父母均值再叠加 ±10 的随性偏移——**高消化效率的孩子更耐饿，高睡眠效率的孩子恢复更快，力量大的孩子走得更快**。

成年夫妇身体达标即可孕育新生命：妊娠约 200 秒分娩，流产与产后各有休养冷却；孩子的代际、家户、宗族与王国归属在出生瞬间全部落定。

几代之后，某些姓氏会明显"更能活"。

### 6. 📒 家户 → 宗族 → 王国的社会演化

经济不是魔法数字，每一笔流动都写进账本：

- **求偶成婚**：婚姻不再是系统摊派——单身男性在"归属与爱"层自主发起求偶，追求魅力最高的单身女性；一人一生多段婚姻全部留痕，丧偶封账、改嫁开新账；
- **家户与继承**：家庭跟着男人走，成年子嗣按权重分走家产自立门户，绝嗣则财产入公仓；
- **宗族**：同姓自动成族，族长为最年长在世男性，按期征收**族税**，并对揭不开锅的族人**互助救济**；
- **地区与王国**：每座营地是一位国王的领地，**长子继承制**传承王位；王位空悬时，男性会发动**夺位远征**——丢下建到一半的房子横跨地图去登基，途中若目标易主则原地重定向；
- **榷场互市**：野外断流、家底告急时，户主会揣着黄金奔赴全图唯一的市场，按**幂律动态定价**（库存越少单价越贵，平方反比放大，极端可暴涨 100 倍）抢购救命水粮；花出去的黄金流入虚空，成为整个经济的紧缩通货锚。

### 7. 🌳 千年族谱，时间轴上一目了然

族谱不是力导向的一团乱麻，而是**确定性时间轴**：Y 轴严格映射出生时刻，先出生者必在上；主干血脉优先落位，核心家庭按出生序居中于双亲之间；配时间刻度尺、视口虚拟化与三档缩放 LOD，鼠标悬停只高亮其父母与子女。

跑上一夜，你会得到一棵真正像样的家族树。

### 8. ⚡ 1x ~ 1024x，让时间快进到看得见演化

八档倍速随意切换，**无头模式**跳过渲染只推进模拟，配合 1024x 可以在一杯咖啡的时间里看完一个王朝的兴衰。看累了随时**存档**：三槽位浏览器存档，也可直写本地文件，随时读档续写同一段历史。

整个过程依然由那个 Rust 确定性内核驱动——同一个种子，跑一万次也是同一段历史。

## 🎮 三分钟上手

### 开玩

```bash
node frontend/server.js
```

然后打开浏览器访问 `http://localhost:3000`，就这样。无需构建、无需安装依赖、无需编译。

> 若 3000 端口已被占用，说明服务已在运行中，直接访问即可。

### 操作

| 操作 | 效果 |
| :--- | :--- |
| **鼠标左键点击小人** | 查看马斯洛主导需求、决策原因、饱食/水分/体力、行囊与威望 |
| **鼠标左键点击房屋** | 查看等级、耐久、家户账本与家庭成员 |
| **鼠标左键点击地标** | 查看储量、产速与实时单价（榷场显示水粮金价） |
| **双击在售房屋 / 顶栏「🏛️ 拍卖」** | 打开拍卖大盘，围观麦穗博弈时间轴与竞价流水 |
| **顶栏「🧠 决策引擎」** | 拖拽决策卡与分界线，实时重排族人的需求优先级 |
| **`Space` 空格键** | 全局暂停 / 继续 |
| **鼠标滚轮** | 缩放视口 |
| **右键拖拽** | 平移视口 |
| **顶部「重置模拟」** | 重新播撒 20 名始祖（10 男 10 女），开启新的一段历史 |
| **顶部存档按钮** | 三槽位存档 / 本地文件直写，随时读档续写 |

改完 Rust 内核后重新编译 WASM，记得按 **`Ctrl + F5`** 强刷清缓存。

## 🧠 技术底座

| 层级 | 技术 |
| :--- | :--- |

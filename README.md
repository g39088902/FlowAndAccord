## 🎬 这不是一款"你操作角色"的游戏

传统模拟经营里，你是指挥官：圈地、指派、催工。在这里，**你只是观察者**。

你什么都不用做。部落民会自己饿、自己渴、自己扛着水粮走回家，自己在泉边与果丛之间踩出第一条小径，自己攒够材料盖起第一间仓库，自己娶妻、生子、老去，然后由儿子继承那间漏雨的茅草房。

系统只扮演"物理规则执行者"：**放置校验、路网接入、施工计时、竣工扩容**。
至于"盖不盖、何时盖、盖在哪"——那是他们自己的事。

> 于是你会看到一些没人写过的剧情：
> 有人在寒冬前囤够了柴火，有人家徒四壁而冬天绝育；
> 有人一路走到帝国大道上，也有人一辈子在荒野里 0.5 倍速地挪；
> 老国王咽气的同一秒，某个年轻人扔下建到一半的房子，横跨地图冲向无主的营地。

## ✨ 八个值得盯着看的理由

### 1. 🧠 真·自主 AI：马斯洛五层需求驱动

每个族人心里都压着一座金字塔，**低层需求绝对阻断高层欲望**：

| 层次 | 需求 | 他们会做什么 |
| :--- | :--- | :--- |
| ① 生理 | 解渴 / 觅食 / 休养 | 冲向清泉与浆果丛，就地吃喝或扛回家 |
| ② 安全 | 房屋修缮 / 水粮储备 | 房子耐久掉到 50% 就一路修到 100% |
| ③ 归属与爱 | 建仓成家 / 供给家庭 | 无家成年男性自主掷点选址立宅 |
| ④ 尊重 | 建房施工 / 采石备料 | 攒满材料就开工，一砖一瓦往上堆 |
| ⑤ 自我实现 | 大庄园备金 / 娱乐淘金 | 4 级庄园竣工前，绝不许自己享乐淘金 |

决策**没有掷骰子**——同样的处境必然做出同样的选择。你看到的是规则推演出的命运，不是随机数。

### 2. 🛤️ 路，是他们自己踩出来的

没有预设路网。族人走过的每一段路都会累加踩踏值，从荒野小径一路升级成**紫金色的帝国大道**；没人走的路则按比例衰减，静静长回荒野。

| 等级 | 名称 | 移速加成 |
| :--- | :--- | :---: |
| 1 | 泥土细道 | 0.50× → |
| 2 | 夯土小道 | ⬆ |
| 3 | 硬质石道 | ⬆ |
| 4 | 精修通衢 | ⬆ |
| 5 | 帝国大道 | 2.20× |

一条被几代人反复踩踏的道路，就是一部无声的家族迁徙史。

### 3. 🏰 从一间仓库到一座大庄园

| 等级 | 名称 | 仓库容量 | 解锁 |
| :--- | :--- | :---: | :--- |
| 0 | 📦 仓库 | 20 | 立宅起步 |
| 1 | 🛖 茅草房 | 40 | 自动迎娶、激活生育 |
| 2 | 🏡 半棚屋 | 80 | 采石备料 |
| 3 | 🏯 木石庄舍 | 120 | 前往金矿淘金 |
| 4 | 🏰 大庄园 | 160 | 娱乐淘金、终极形态 |

房子会**自然折旧**（0.02/s），耐久掉到一半就会有人放下一切去修；男人死后房子由直系男性后代继承，无子继承则沦为废墟，最终坍塌风化，连大门的路网节点都会留给后来者复用。

### 4. ❄️ 四季轮转，冬天是真的会死人的

一年 = 240 秒，气温在 **-3℃ ~ 31℃** 之间正弦起伏。入冬后所有有壁炉的房屋每秒烧掉 0.12 木柴取暖；**家里柴火不足 10 单位，受孕直接被禁用**。

春夏秋三季偷懒的家族，会在冬天集体失声。

### 5. 🧬 生死、遗传与六维禀赋

四项生理指标（健康 / 饱食 / 水分 / 体力）持续代谢，饿死与渴死会在顶栏被单独统计，遗体保留 12 秒逐渐风化消散。

每个族人携带六项先天禀赋：**智力 / 力量 / 魅力 / 消化效率 / 睡眠效率 / 预期寿命**。始祖按正态分布生成，新生儿取父母均值再叠加 ±10 的随性偏移——**高消化效率的孩子更耐饿，高睡眠效率的孩子恢复更快，力量大的孩子走得更快**。

几代之后，某些姓氏会明显"更能活"。

### 6. 📒 家户 → 宗族 → 王国的社会演化

经济不是魔法数字，每一笔流动都写进账本：

- **家户与婚姻登记**：家庭跟着男人走，一人一生多段婚姻全部留痕，丧偶封账、改嫁开新账；
- **分家与继承**：成年子嗣按权重分走家产自立门户，绝嗣则财产入公仓；
- **宗族**：同姓自动成族，族长为最年长在世男性，按期征收**族税**，并对揭不开锅的族人**互助救济**；
- **地区与王国**：每座营地是一位国王的领地，**长子继承制**传承王位；王位空悬时，男性会发动**夺位远征**——丢下建到一半的房子横跨地图去登基，途中若目标易主则原地重定向。

### 7. 🌳 千年族谱，时间轴上一目了然

族谱不是力导向的一团乱麻，而是**确定性时间轴**：Y 轴严格映射出生时刻，先出生者必在上；主干血脉优先落位，核心家庭按出生序居中于双亲之间；配时间刻度尺、视口虚拟化与三档缩放 LOD，鼠标悬停只高亮其父母与子女。

跑上一夜，你会得到一棵真正像样的家族树。

### 8. ⚡ 1x ~ 1024x，让时间快进到看得见演化

八档倍速随意切换，**无头模式**跳过渲染只推进模拟，配合 1024x 可以在一杯咖啡的时间里看完一个王朝的兴衰。整个过程依然由那个 Rust 确定性内核驱动——同一个种子，跑一万次也是同一段历史。

## 🎮 三分钟上手

### 开玩

```bash
node frontend/server.js
```

然后打开浏览器访问 `http://localhost:3000`，就这样。无需构建、无需安装依赖、无需编译。

> 若 3000 端口已被占用，说明服务已在运行中，直接访问即可。

### 操作

| 操作 | 效果 |
| :--- | :--- |
| **鼠标左键点击小人** | 查看马斯洛主导需求、决策原因、饱食/水分/体力与行囊 |
| **鼠标左键点击房屋** | 查看等级、耐久、五类仓储与家庭成员 |
| **鼠标左键点击地标** | 查看清泉/果丛/林木/石矿/金矿的储量与产速 |
| **`Space` 空格键** | 全局暂停 / 继续 |
| **鼠标滚轮** | 缩放视口 |
| **右键拖拽** | 平移视口 |
| **顶部「重置模拟」** | 重新播撒 20 名始祖（10 男 10 女），开启新的一段历史 |

改完 Rust 内核后重新编译 WASM，记得按 **`Ctrl + F5`** 强刷清缓存。

## 🧠 技术底座

| 层级 | 技术 |
| :--- | :--- |
| 计算内核 | Rust 确定性内核（30Hz 固定步进，`WorldRng` 全局共享，同种子逐字节可复现） |
| 桥接层 | 零依赖 WebAssembly 导出层，线性内存 JSON 快照 |
| 表现层 | 原生静态前端 + Canvas 渲染管线，无构建步骤 |
| 可调超参 | **163 个**参数全部集中在 `frontend/js/config.js`，改完刷新即生效，无需重新编译 |
| 自动化验证 | `node tools/test-wasm.js`（确定性 / 防越界 / 防 NaN / 长程稳定） |

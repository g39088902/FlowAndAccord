## 🎬 这不是一款"你操作角色"的游戏

传统模拟经营里，你是指挥官：圈地、指派、催工。在这里，**你只是观察者**。

你什么都不用做。部落民会自己饿、自己渴、自己扛着水粮走回家，自己在泉边与果丛之间踩出第一条小径，自己攒够建材盖起第一间房，自己去追求心仪的对象、娶妻、生子、老去，然后由儿子继承那间漏雨的茅草房。

系统只扮演"物理规则执行者"：**放置校验、路网接入、施工结算、交易交割**。
至于"盖不盖、何时盖、盖在哪、娶不娶、夺不夺位"——那是他们自己的事。

> 于是你会看到一些没人写过的剧情：
> 有人在寒冬前囤够了柴火，有人家徒四壁而冬天硬扛；
> 有人一路走到帝国大道上，也有人一辈子在荒野里 0.5 倍速地挪；
> 老国王咽气的同一秒，某个年轻人扔下建到一半的房子，横跨地图冲向无主的营地；
> 水荒粮荒、野外断流时，有人揣着最后一点黄金，扑向涨价 100 倍的榷场买命；
> 错过历史的关键瞬间？随时呼出时光倒流控制器，拉动时间滑块瞬间回滚重演！

## ✨ 八个值得盯着看的理由

### 1. 🧠 真·自主 AI：马斯洛六层需求驱动与瞬时意图

每个族人心里都压着一座金字塔，从最顶级的「瞬间行为」到底层生理需求，**低层需求绝对阻断高层欲望**：

| 层次 | 需求 | 他们会做什么 |
| :--- | :--- | :--- |
| ⓪ 瞬间行为 | 竞拍购房 / 就近求偶 / 在宅养育 | 满足条件当拍即刻写入意图，零位移、零消耗结算，且同一拍内继续向下评估常规分支 |
| ① 生理 | 夺位远征 / 解渴 / 觅食 / 休养 / 立宅 | 王位是生存资源的终极分配权（空悬即点燃野心）；渴饮清泉、饥食浆果；无家成年男性生理稳定后自主选址立宅（避让营地与POI，必须物理走完路线实体化） |
| ② 安全 | 房屋修缮 / 水粮家宅储备 | 耐久跌破 50% 一路修满 100%；家户账本库存跌破阈值（施密特滞回带）即出发补货；野外断流时户主直接掉头直达榷场买命 |
| ③ 归属与爱 | 求偶成婚 / 家庭供给 | 单身男性主动出击追求魅力最高的单身女性；成家后全力为家户账本驮运给养 |
| ④ 尊重 | 升级施工 / 养育小孩 / 采石备料 | 账本建材达标当拍瞬时晋升，每晋升一级威望 +1；男户主名下有 ≥1 级私宅且夫妻体征良好自主发起繁衍 |
| ⑤ 自我实现 | 大庄园备金 / 娱乐淘金 | 4 级大庄园竣工前绝不许自己享乐淘金，自我实现必须建立在基业长青之上 |

决策**没有掷骰子**——同样的处境必然做出同样的选择。资源点该不该跑一趟，由每名族人心里那把**私有标尺**（施密特触发器）说了算：库存过半才值得出发，跌破一成就不再前往；途中遇枯竭还会当场平滑掉头改道，绝不瞬移。野外资源断流时，户主更能直达榷场远程账本结算！

更妙的是，**你可以策展他们的价值观**：页面上的「🧠 决策引擎」视图把全部 16 条决策分支按 6 大层级排成可拖动的卡片，拖一下分界线或重排卡片，运行中的模拟立即热注入——让这个部落把"求偶"排到"囤货"前面，或是反过来，还可一键落盘持久化。

### 2. 🛤️ 路，是他们自己踩出来的

没有预设路网。族人走过的每一段路都会累加踩踏值，从荒野小径一路升级成**紫金色的帝国大道**；没人走的路则按比例衰减，静静长回荒野。

| 等级 | 名称 | 移速加成 |
| :--- | :--- | :---: |
| 1 | 泥土细道 | 0.50× → |
| 2 | 夯土小道 | ⬆ |
| 3 | 硬质石道 | ⬆ |
| 4 | 精修通衢 | ⬆ |
| 5 | 帝国大道 | 2.20× |

一条被几代人反复踩踏的道路，就是一部无声的家族迁徙史。

### 3. 🏰 从一间仓库到一座大庄园

房屋分 5 级：**仓库 → 茅草房 → 半棚屋 → 木石庄舍 → 大庄园**。升级是**家户账本一次性支付固定建材矩阵**、当拍瞬时晋升：

| 等级 | 名称 | 升级所需建材（水/粮/木/石/金） | 解锁 |
| :--- | :--- | :--- | :--- |
| 0 | 📦 仓库 | 立宅起步（生理层末档自主选址） | 遮风挡雨的基本盘，无生育功能 |
| 1 | 🛖 茅草房 | 水 50 + 粮 50 | 解锁养育后代资格 |
| 2 | 🏡 半棚屋 | 木 75 + 水粮各 75 | 坚固居所，容纳家族繁衍 |
| 3 | 🏯 木石庄舍 | 石 100 + 水粮木各 100 | 前往金矿淘金 |
| 4 | 🏰 大庄园 | 金 125 + 水粮木石各 125 | 娱乐淘金、终极形态 |

每晋升一级，户主威望 +1——而国王与宗族长老天生自带 **+3 威望**（兼任双重身份叠加为 +6），荣誉写在血脉里。

房子会**自然折旧**（0.04/s，有主无主统一速率），耐久掉到一半就会有人放下一切去修。户主去世后，房屋变为无主空置房，由营地中介主持**麦穗 37% 最优停止博弈拍卖**：
- 前 37% 损耗期只摸底立标杆、绝不出售；
- 进入决策期后新报价 ≥ 标杆即成交，标杆无人击穿时按 0.02 金/秒平滑衰减，打破购买力脱节的双锁死；
- 跌过 10% 出清线则见价就卖，无人问津便随耐久归零坍塌。

出价全面下沉至个体决策的瞬间层——买家**对全图所有更高等级在售房一次性倾囊出价**，执行器按 ID 升序逐个落地、首套成交即停（一人一房铁律）。点开 1240px 专属拍卖大盘，麦穗时间轴、智能过滤后的意向买家池与实时竞价流水一览无余。

### 4. ❄️ 四季轮转，冬天会咬掉你的柴火储备

一年 = 240 秒，气温在 **-3℃ ~ 31℃** 之间正弦起伏。入冬或气温跌破 5℃ 时，所有非 0 级有主房屋每秒从**家户账本**烧掉 0.12 木材取暖——柴火是冬天的硬通货，账本见底的家族只能在寒风中硬扛。

春夏秋三季偷懒不囤柴的家族，会在冬天付出代价。

### 5. 🧬 生死、遗传与六维禀赋

四项生理指标（健康 / 饱食 / 水分 / 体力）持续代谢，饿死与渴死会在顶栏被单独统计，遗体保留 12 秒逐渐风化消散。

每个族人携带六项先天禀赋：**智力 / 力量 / 魅力 / 消化效率 / 睡眠效率 / 预期寿命**。始祖按正态分布生成（饱食与水分基线 45 并携带满额补给），新生儿取父母均值再叠加 ±10 的随机偏移——**高消化效率的孩子更耐饿，高睡眠效率的孩子恢复更快，力量大的孩子走得更快**。每人携带水/粮/木/石各 100 独立随身背包，非黄金行囊按需搬运。

成家男性名下拥有 ≥1 级私宅且夫妇身体达标即可孕育新生命：妊娠约 200 秒分娩，流产（450s）与产后（900s）休养冷却独立分立；孩子的代际、家户、宗族与王国归属在出生瞬间全部落定。

几代之后，某些姓氏会明显"更能活"。

### 6. 📒 家户 → 宗族 → 王国的社会演化

经济不是魔法数字，每一笔流动都写进账本：

- **求偶成婚**：单身男性在"归属与爱"层（或就近瞬发）自主追求魅力最高的单身女性；一人一生多段婚姻全部留痕，丧偶封账、改嫁开新账；
- **家户与继承**：家庭跟着男人走，成年子嗣按权重分走家产自立门户，绝嗣则财产入公仓；
- **宗族**：同姓自动成族，族长为最年长在世男性，按期征收**族税**，并对揭不开锅的族人**互助救济**；
- **地区与王国**：每座营地是一位国王的领地，**长子继承制**传承王位；王位空悬（包括孤儿营地）时，男性会发动**夺位远征**——物理抵达营地才正式登基，途中若目标易主则原地重定向；
- **榷场互市**：野外断流或家底告急时，户主直奔全图唯一的榷场，按**幂律动态定价**抢购救命水粮；固定以 2.0 离散单位整洁结算，交易流水环形缓冲全量可查，流入虚空的黄金成为整个经济的紧缩通货锚。

### 7. 🌳 千年族谱，时间轴上一目了然

族谱不是力导向的一团乱麻，而是**确定性时间轴**：Y 轴严格映射出生时刻，先出生者必在上；主干血脉优先落位，核心家庭按出生序居中于双亲之间；配时间刻度尺、视口虚拟化与三档缩放 LOD，鼠标悬停只高亮其父母与子女。

即使中途流产或随母亡故的胎儿，也会以"已故子嗣"节点入谱，死因与父母血缘清清楚楚。跑上一夜，你会得到一棵真正像样的家族树。

### 8. ⏪ 时光倒流、极速快进与本地永久存档

- **⏪ 时光倒流控制器 (Tick 回滚)**：不只快进，还能倒流！基于强确定性 Checkpoint + Replay 机制，输入任意指定历史 Tick 或拖动滑块，瞬间毫秒级回溯历史世界，配 `-100` / `-300` / `-900` / `-1800` / `Tick 0` 快捷芯片，回滚后自动暂停便于细致巡检。
- **⚡ 1x ~ 1024x 演化快进**：八档倍速随意切换，**无头模式**跳过渲染纯算内核，配合 1024x 可以在一杯咖啡的时间里看完一个王朝的兴衰。
- **💾 本地文件直写与自动续演**：利用现代浏览器的 File System Access API 直写用户磁盘 `.json` 存档，彻底突破浏览器 5MB 配额限制；30 秒自动保存，开新档自动写盘，打开游戏一键重授权自动续读旧档。
- **☀️/🌙 浅色明亮与深色双主题**：顶栏一键在经典暗夜底色与通透柔和的明亮模式（`theme-light`）间无缝切换，偏好本地持久化。

整个过程依然由那个 Rust 确定性内核驱动——同一个种子，跑一万次也是同一段历史。

### 9. 🌍 动态季节光照、地形生态与造物者之眼

- **☀️ 动态季节光照引擎**：光位由快照驱动，一年扫 360°——春东 / 夏南 / 秋西 / 冬北，高度角与光强随年相连续演化；盛夏最亮、隆冬最弱，色温随四季与气温冷暖微调。地形受光、水底石光与水面波光统一联动，快捷键 **L** 一键开关。

## 🎮 三分钟上手

### 开玩

```bash
node frontend/server.js
```

> ⚠️ **必须使用 Chrome 或 Edge 打开**：游戏存档依赖 Chrome 的 File System Access API 直写磁盘 `.json` 文件，Firefox / Safari 等浏览器无法建立存档、会被启动门禁阻断。

然后打开 Chrome 或 Edge 访问 `http://localhost:3000`。无需复杂打包、无需安装外部依赖。

> 🎮 **不想本地搭建？在线直接游玩**：<https://xn--fiqs8s171bcnq.com>

> - 首次进入或重置时，会弹出建立/连接本地存档文件的提示，选择或新建一个 `.json` 文件即可开启世界，数据永久保存在你的电脑磁盘中；
> - 若 3000 端口已被占用，说明服务已在后台运行中，直接浏览器访问即可。

## 🧠 技术底座

| 层级 | 技术实现 |
| :--- | :--- |
| 计算内核 | Rust 确定性内核（60Hz 固定步进，`WorldRng` 全局共享，同种子逐字节可复现，Checkpoint + Replay 毫秒级时光倒流） |
| 桥接层 | 零依赖 WebAssembly 导出层 + **FABS 定长二进制帧快照**（23× 压缩 vs JSON，JSON 仅调试回退）|
| 表现层 | 原生静态前端（ES6+） + 双主题 Canvas 渲染管线 + 动态季节光照 + 微观水生生境 |
| 存储引擎 | File System Access API 原生文件磁盘直写 + IndexedDB 句柄持久化 + localStorage 降级三槽位 |
| 可调超参 | **233 个**参数集中于 `frontend/js/config.js` 及拆分配置文件（含升级成本矩阵；光照 / 渲染为独立纯前端配置），与 Rust 内核 `SimConfig` 字段一一对应，改完刷新即生效，无需重新编译 |
| 质量门禁 | `test-wasm.js`（确定性 / 防越界 / 防 NaN）+ `test-determinism.js`（6 大矩阵）+ `config-check.js`（超参对齐）+ `test-snapshot-bin.js`（FABS ≡ JSON）+ `diagnose.js`（无头诊断） |

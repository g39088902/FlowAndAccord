7机制归因与结论

  • 生育节奏是人口更替的硬杠杆：v1.19.0 中创始代寿终后出生率不足以更替（每对夫妇终生 1~2 孩）；妊娠+产后周期减半后，已婚女性在可孕窗口内可多生，出生率显著抬升，4/5 种子净更替转正。
  • 与 b16 求偶前置正交协同：v1.19.0 解决「男性不结婚」（求偶被备料压制），v1.20.0 解决「结了婚生得慢」；两者叠加后 30ks 末平均存活 ≈ 40.4 人（v1.19.0 ≈ 5.2 人），提升约 7.8×。
  • 剩余风险点 ① seed 1 灭绝：整局仅 4 次婚姻，属婚姻供给侧坏运气；若继续压榨，需观察求偶成功率/配偶匹配逻辑，而非再调生育节奏。
  • 剩余风险点 ② 性别失衡苗头：seed 20260903 末态 29 男/20 女、大量男性处 SeekingCourtship，说明成年男性供给充足而适婚女性相对紧缺，后续性别出生率（0.5 均匀）可能放大该缺口。
  • 口径说明：死亡仍以自然寿终为主（非自然每种子 0~3 例）；seed 42 流产 17 次偏高（其高生育基数下的伴随现象）。

8数据口径与方法

  • 引擎：本仓库 frontend/rust/sim_wasm.wasm（本次改动后重编译双副本同步，879,172 B），Node WebAssembly 无头驱动，world_create(60, 764.0, seed, 20) + 生产配置注入（含 b16 前置决策序 + 450s 生育参数）。
  • 推进：world_tick_steps(512, 1/30) 循环至 900,000 tick；每 ~2ks 采样一次快照。
  • 本次改动超参：AGENT_PREGNANCY_DURATION 900→450s、AGENT_POSTPARTUM_COOLDOWN 900→450s（config.rs const 与 config.js 同步，config-check 无漂移）；AGENT_MISCARRIAGE_COOLDOWN 维持 450s 不变。

## 1. 目标与现有基础

让“这个家庭有多少资源”进一步变成“家里的每个人今天怎样生活，又怎样互相影响”。日常行为应产生可观察的时间成本、关系变化和长期后果，让玩家能够记住一个人、理解一个家庭的处境，并期待他们接下来的生活。

现有的生存代谢、真实搬运、家户账本、私宅、婚姻、出生、继承与族谱提供了基础。新增内容优先连接这些机制；具体实现以源码和现状文档为准，本文不重复固定数值与字段定义。

## 2. 八个深化方向

### 2.1 家庭分工与照料（优先）

**生活变化**：家庭成员会根据身体状态、路程、擅长事项和眼前需求，自主承担采集、做饭、育儿或照料。

- 配偶劳累时，另一人可以承担更多劳动。
- 幼儿和需要照料的老人增加，会减少家庭可投入外出的时间。
- 做饭与照料可以由不同的成年成员承担，不按性别固定分派家务。
- 家庭出现劳动力缺口时，能从生活记录中看到是谁承担了额外负担。

**可能出现的故事**：父亲远途采石，母亲连续照料幼儿，祖母帮忙做饭，让母亲终于有时间补水。此例是目标体验，不是预设剧情。

**最小起点**：照料一名家人会占用自己的行动时间。首期先验证照料与采集的取舍，再扩展完整家务种类。

### 2.2 饮食与厨房

**生活变化**：粮食经过处理成为一顿饭，制作和分享食物进入家庭生活。

- 生食快捷，熟食需要原料、燃料、设施与制作时间。
- 一次烹饪可供应多人，体现共同生活的效率。
- 后续引入保鲜、晒干、腌制和储藏，形成季节性准备。
- 共同进餐提供相处机会；晚归者可能独自吃剩饭。
- 节庆或待客可以消耗更多食材，形成自主支出选择。

**核心取舍**：现在出门采粮，还是先将现有粮食做成更合适的饭？

**最小起点**：一条“原粮 → 熟食”加工链。加工消耗、产出和进食扣减都需要明确记账，避免原粮与熟食重复计入可用储备。

### 2.3 作息与闲暇

**生活变化**：起床、劳动、用餐、休息与相处形成日常节奏，地图上的活动随时间变化。

- 清晨取水、傍晚返家，远途劳动可能错过家庭活动。
- 连续劳作产生恢复需求；后续可区分睡眠欠账与即时体力。
- 家庭储备充裕后，有人选择闲暇，有人继续积累财富。
- 严寒、身体不适等条件影响当天计划；天气种类扩展另行设计。

**核心问题**：富裕能否换来更多休息与陪伴时间？

**前置条件**：先梳理昼夜、季节、年龄、孕育和决策节拍的压缩比例。遵守现有固定 `simulationDt` 与决策节拍契约，不能通过改变积分步长解决生活节奏问题。首期可先用一个观察时段展示家庭活动，“一家人的一天”不预设已经存在完整昼夜系统。

### 2.4 熟人关系与互惠

**生活变化**：人物记得具体接触过的人，过去的帮助影响下一次选择。

- 共同劳动、同行和进餐积累熟悉与信任。
- 缺粮时优先向熟人求助，对方根据余裕、关系和自身需求决定是否帮助。
- 赠食、照料、失约与争执留下有限的重要记忆。
- 长期单方面索取可能使关系疏远。
- 后续求偶可考虑相处经历、信任和生活是否合拍。

**可能出现的故事**：前年邻居送来过冬木柴，今年自己有余粮时，优先帮助对方。

**最小起点**：一类求助与赠予行为，以及对应的关系记忆。送物应经过真实搬运和交付；关系采用稀疏记录，仅维护实际接触过的重要对象，避免全人口两两更新。

### 2.5 童年、学习与衰老

**生活变化**：人生阶段改变能够做的事情，以及对他人的依赖。

- 幼儿依赖照料，儿童玩耍探索，少年跟随成人学习。
- 技能通过实际劳动增长，通过共同劳动传授。
- 成长经历影响成年后的擅长事项。
- 老年人逐渐减少远途重体力劳动，转向加工、照料或传授技能。
- 孤儿和失去劳动力的家庭可能获得亲属、邻里或公共支持。

**核心价值**：代际传承包含房屋、财富、手艺和社会关系；玩家会关心孩子跟谁长大、学会了什么。

**最小起点**：一种劳动技能和一种跟随学习行为。年龄阶段划分、照料责任与技能成长速度须单独校准，不一次引入完整教育体系。

### 2.6 房屋内部与生活用品

**生活变化**：房屋既是家庭资产，也是被具体使用的生活空间。

| 设施或物品 | 对生活的影响 |
|---|---|
| 床铺、被褥 | 睡眠恢复与御寒 |
| 灶台、餐桌 | 做饭、共同进餐与待客 |
| 水缸、储藏架 | 取用便利与食物保存；具体库存边界另行设计 |
| 工具、背篓 | 劳动效率与搬运能力 |
| 独立睡眠空间 | 拥挤、隐私与家庭扩张需求 |

**可能出现的目标**：孩子多了添床，老人怕冷补屋顶，工具磨损后安排修理。

**最小起点**：房屋拥有少量功能位置，人物可以实际使用。自由装修与室内网格放在后续评估；设施不能另建一套与家户账本冲突的家庭储备真相源。

### 2.7 身体状况与康复

**生活变化**：暂时的身体困难改变劳动安排，并产生照料关系。

- 长途搬运后劳累，短期减少重活。
- 轻伤或受寒需要休息、食物与照料，逐步康复。
- 病人与照料者同时减少外出，家庭储备因此承压。
- 观察界面说明病情、照料、劳动减少与储备变化的联系。

**核心取舍**：谁来照顾，其他成员如何撑过这段时间？

**最小起点**：一种可恢复的身体状态。当前健康值承担寿命倒计时职责，可恢复状态需要独立表达；与[狩猎与防御规划](./18-plan-conflict-hunting-defense.md)中的生命力设计统一边界，避免重复建模。

### 2.8 生活记忆与仪式

**生活变化**：玩家能够看到、追踪并回看日常行为的意义。

- 人物近期记录展示和谁吃饭、为何疲劳、今天帮助了谁。
- 家庭记录保留第一顿熟饭、孩子第一次帮忙、重要授艺等节点。
- 婚礼、成年、搬家、葬礼等低频聚会真实占用时间与物资。
- 少量重要物品记录来历，例如父亲留下的工具。

**记录示例**：“阿禾留在家中照顾生病的母亲，因此没有完成原定的取水。傍晚，邻居送来了水。”只有相关行动与交付确实发生时，才能生成这段描述。

**最小起点**：结构化行为事实、原因与受影响对象，加上可跳转的人物和家户入口。复用长期路线图的家族时间线方向；模板文本优先，生成式文本仅可润色事实。

## 3. 建议首期：一家人的一天

### 目标

在一个家庭、一个可观察时段内，让采集、烹饪、照料之间产生实际取舍，并让玩家理解每个成员的选择。

### 最小范围

1. 增加一条原粮加工成熟食的链路，明确原料、燃料、耗时与产出。
2. 为幼儿表达有限的照料需求，先校准未满足时的反馈与生存平衡。
3. 成年成员通过自身决策选择采集、做饭或照料；处理重复承担同一事务的冲突。
4. 家庭观察面板显示成员在做什么、为什么这样选择，以及物资和照料结果。

首期暂缓完整昼夜、食谱大全、复杂疾病、全套人格、室内自由装修和长篇生成式日记。具体数值、照料失败后果和任务协调协议需在实现前形成技术规格。

### 观察场景与验收信号

| 场景 | 希望验证的现象 |
|---|---|
| 储备充裕且有幼儿 | 家中有人照料或加工，成员仍有合理休息机会 |
| 储备下降且有幼儿 | 采集与照料形成可解释的取舍，不出现全家永久等待 |
| 多名成人同时可做饭 | 不重复扣料，不因抢占导致物资凭空消失 |
| 照料者需要紧急自救 | 高优先级生理需求可以中断任务，照料缺口有明确反馈 |
| 保存后继续与读档后继续 | 相同输入下行为、物资和记录保持可复现 |

玩家体验验收关注：能否说出一个成员的名字、他最近做了什么、为什么这样做，以及这对家庭有什么影响。观察场景用于临时诊断与人工体验，不要求将固定故事结果保存成持久化单元测试。

## 4. 建议扩展顺序

| 阶段 | 内容 | 进入下一阶段的依据 |
|---|---|---|
| 第一阶段 | 家庭分工、基础做饭、幼儿照料、近期生活记录 | 一家人的日常选择已可读，生存与资源闭环稳定 |
| 第二阶段 | 邻里求助、赠予、熟悉与互惠记忆 | 家庭内部机制稳定，跨家庭互动具有明确动机 |
| 第三阶段 | 技能学习、年龄分工、基础生活用品 | 日常行为已经提供足够的学习与使用场景 |
| 后续深化 | 康复照料、作息闲暇、仪式与重要物品传承 | 时间尺度和性能允许，新增机制能形成可观察后果 |

## 5. 实施约束与风险

- **Agent 自治**：所有“做什么、去哪里”的选择仍由决策引擎产生。家庭协调可以提供需求和事务占用事实，不能由系统扫描后强制派工。
- **优先级与中断**：新分支保持条件自包含，不写死策展顺序；做饭、照料和社交不得阻止紧急生理自救。中断后的原料、进度与占用释放必须有明确结算规则。
- **经济一致性**：家庭储备仍以家户账本为权威。加工、搬运、赠予与消费明确扣减和入账位置；新增物资种类须评估账本、市场、税收与存档影响。
- **确定性与持久化**：影响决策的技能、关系、记忆和任务进度必须纳入相应存档契约；随机来源与遍历顺序遵守全局确定性约束。
- **快照与观察**：新字段按根 AGENTS.md 的快照同步链和影响矩阵落地；界面展示真实事实，不能从标签臆造行动原因。
- **时间与性能**：先校准活动时长，再扩充行为数量；关系稀疏存储、事件限制保留量、界面按变化刷新，避免逐 tick 全图配对。
- **生活压力**：新增家务和照料会减少采集时间，需观察不同家庭规模、季节与路程下的生存变化，避免内容细化只增加负担。
- **验证与文档**：实施时遵循对应局部 AGENTS.md，按改动范围完成 WASM、确定性、快照、配置及前端门禁；仅在机制实际落地后更新现状文档。

每项新增内容都应回答：人物因此多了什么真实选择，付出了什么成本，影响了谁，玩家又从哪里看见这些后果？

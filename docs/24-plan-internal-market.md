# 内部市场方案：黄金本位、居民互通与生存交换

> **整理日期**：2026-09-09。

> **入口**：[文档导航](./README.md) · [长期路线图](./11-plan.md)。

## 1. 设计目标与现状依据

让缺水缺粮的家庭有机会用积存的木材、石料和黄金换命；让水粮富余的家庭在木石金采集断流时，用自己的余粮换回建材或黄金。内部市场负责跨家庭、跨时间调剂真实存量，外部市场继续提供世界之外的水粮木供给。

典型故事：甲家缺水，但有一袋石料；乙家有余水，却找不到石料。甲把石料卖进市集，获得的黄金直接用于买水；乙随后卖水买石。双方不必同时到场，市集库存承担交易时间差。市场不能解决全社会已经没有水粮的物理短缺，也不保证没资产的人都能获救；无偿救济仍由现有社会互助机制承担。

### 1.1 与当前实现的关系

- 当前外部榷场只向居民出售水、粮、木，支付黄金流向外部；支付支持家户账本与随身黄金协同。详见[外部市场现状](./current/16-market-pricing.md)。
- 当前采购已经下沉为水粮木资源意图的 L2 策略；以[决策现状](./current/06-motivation-ai.md)及 `decisions/market.rs` 为依据，不能照旧市场文档复活独立 b15 商贸需求。
- 家庭储备唯一真相源是家户账本，行囊是已经提取并正在搬运的物资。本文不恢复房屋 pantry 仓库。
- 本方案增加内部交易目的地和执行策略，不改马斯洛需求的意义，不新增全图扫描后强制派遣的“救命管理器”。

### 1.2 内外市场分工

| 维度 | 外部市场：边境榷市 | 内部市场：居民市集（拟新增） |
|---|---|---|
| 对手方 | 世界外商贸供给 | 由真实储备支持的内部做市池 |
| 货物来源 | 既有外部补货规则 | 有限开局资本、居民出售及明确记录的注资 |
| 买卖方向 | 居民用黄金买水粮木 | 水粮木石分别与黄金双向交换 |
| 黄金去向 | 流出本地经济 | 留在居民行囊与内部池之间流转 |
| 价格依据 | 既有库存幂律价格 | 各资源与黄金的恒定乘积池 |
| 运输 | 既有远程黄金支付、购货装袋 | 出售物和支付黄金均需实际携带到场 |
| 生存功能 | 引入额外生存资源 | 让家庭已有资产转成可用生存资源 |

首期全图只设一个独立居民市集，接入一处营地附近的可达路网，所有居民可访问。独立类型、图标、库存、流水和 ID，不复用外部 `Market` 的再生逻辑，也不混入免费采收 NodePool。先验证经济闭环，再考虑每营地一个市集；多个市集会引入地区价差与运输贸易，属于后续范围。

## 2. 谁在什么情况下交易

### 2.1 濒危交换：木石金换水粮

触发来自原有解渴、觅食或家庭水粮储备需求。人物已经进入饥渴警戒，或预计现有补给撑不到下一次正常获得水粮的时刻时，内部市场成为候选策略。不能等生理值归零才启动，也不能机械要求全图所有水源都枯竭：存在水源但赶不到，同样需要求生选策。

可行性必须在策略内部完整检查：

1. 人物在世、非胎儿且有自主交易资格；水粮缺口尚未被行囊、在宅可食用储备或可及时到达的自然点解决。
2. 有本人可出售物资，或有权在家提取家户物资；有可达市集、可成交库存和足够预算。
3. 将回家、装货、赴市、结算等待全部计入首次获得水粮的时间，并留安全余量。家中有钱不等于途中可用。
4. 在可活着到达的方案中，先满足最紧迫生理缺口，再考虑成本与返程储备。更便宜但赶不及的市场不可胜出。

出售候选为石、木、金，按满足最低救命量所需的资产牺牲选择组合：默认先用无近期用途的石料，再用超过供暖/修缮保留量的木材，并与黄金采购方案比较。不得仅因“有石头”便倾销全部建材。危机尚未解除时，每次只出售足以支付下一笔有效救命购买的数量。

若黄金更便宜或运输更及时，可以直接携金采购；黄金始终是支付媒介，“出售黄金”在玩家语义上就是花黄金买资源，不另造一个黄金商品价格。

### 2.2 反向交换：余水余粮换木石金

木、石、金的储备需求仍由既有意图产生。首期仅在该人物对目标资源没有可达且触发器开放的采集点，且家中水或粮存在可出售盈余时，选择内部交换。木、石、金任一品类断流即可，不要求三种一起枯竭；目标资源在市场也必须有可交易库存。

自然资源“枯竭”与市场“缺货”是两个判据：森林采不到木，但市集有别人卖来的木，才存在交换价值。黄金采集断流时，可卖水粮获取池中黄金；市集不会因为缺金而发行货币。

家庭出售上限按人口和预计耗用计算：

`可出售量 = max(0, 家户余额 − 保护储备 − 已承诺未提取量)`

保护储备取既有补货停止阈值与家庭安全期耗用估计两者的较大值，并覆盖往返期间吃喝、寒期烧柴、明确待结事务。预测使用游戏时间和现有消耗参数，不把现实秒直接当作游戏小时。无可靠预测的第一阶段采用保守阈值，不假设“每户需求相同”。

普通交换只有超过保护储备及出售启动余量才启动，余额降至保护线便停止；使用滞回与失败冷却，避免“卖到短缺 → 马上补货 → 再出售”。任务结束后实际买入量达到原需求目标即退出，不因行情有利而无限贸易。b13 积累财富仍保留原有住宅等级等守卫，不以卖水粮绕过它。

### 2.3 家庭权限与救急边界

- **常规交换**：首期沿用家户户主支配家庭资产的规则。
- **紧急自救（本方案明确新增的权限）**：有自主行动能力的成年家庭成员可在家提取一笔受限救命预算；仅用于本人水粮自救与必要返程量，不获得无限支配家财权限。非户主使用这项权限必须留下用途、原家户与预算记录。
- **同户协同**：同一时刻至多一笔有效的家户取货任务；预约只限制尚未提取的余额，不计作第二份库存。其他成员可消费救命水粮，不能为保全交易预约而饿死；消费导致预算不足则缩单或取消。
- **无家户者**：成年人物可用合法持有的随身物资自救，不凭空获得家户提货权；该权限作为拟新增能力实现。儿童和胎儿首期通过家庭补给及已有照料/救济受益，不单独远行经商。
- **濒危变卖底线**：石料、黄金可突破普通储备保护；木材仍保留安全期供暖最低量。若还救不起，明确记录“保留供暖后资产不足”，不暗中扣走全家的最后燃料。

## 3. 市集资本与库存来源

### 3.1 四个资源—黄金池

建立水/金、粮/金、木/金、石/金四池。每池有独立资源储备 `X_r` 和独立黄金储备 `G_r`；市集黄金总量是四个 `G_r` 之和，不是四池各自都能花的同一笔钱。只有资源与黄金可以直接报价，不设水/粮、木/石等独立定价交易对。

池库存是市场资产的唯一真相源；若通过账本容器保存，则直接以该余额结算，展示层只派生汇总，不另外维护可独立增减的“市场总仓库”。市集运营资产与营地公仓、国王私库分离。

### 3.2 冷启动与资本归属

首期建议把市集设为地区公共经营资产，采用**创建世界时一次性配置的有限开局资本**。它属于世界初始资源禀赋，必须计入初始黄金与物资总量、展示并随档保存；绝不在缺货、重置缓存、读档或换国王时补发。对照实验使用相同全世界初始总量，不能因多给了水粮就宣称市场改善了分配。

开局四池分别配置正的资源、黄金储量。以下仅为可核算的演示资本，不是待直接写入配置的平衡默认值：

| 池 | 资源初始量 | 黄金初始量 | 初始边际价格（金/单位） |
|---|---:|---:|---:|
| 水/金 | 200 | 20 | 0.10 |
| 粮/金 | 200 | 20 | 0.10 |
| 木/金 | 200 | 40 | 0.20 |
| 石/金 | 200 | 60 | 0.30 |

这组资本合计 140 金，不能误记成“市场只有 60 金但四池共用”。允许把初始资本配置为零；零侧池保持关闭，不能以虚拟黄金启动交易。

后续若扩展居民出资或公仓注资，必须明确权属及真实转移：居民由自主任务搬运投入，公仓出资需要公共规则与配送路径。首期不启用补仓、自动抽税注资、LP 份额交易或赎回。未来增加流动性时单独定义双边同比注资规则；不能通过重设 `k`、平移黄金余额或价格钳制暗造资本。

手续费留在对应池，属于市场资本，不自动进入国王家户。地区无主时市集既有自动兑换可继续，注资与提取等管理性动作冻结；这一经营资产规则须与公仓无主冻结明确分开。市集关闭时保全资产并停止新单，不清零归虚空。

## 4. 自动做市与黄金计价

### 4.1 定价原则

每个资源池采用恒定乘积 AMM：`X_r × G_r = k_r`。无手续费的一笔交易前后乘积不变；手续费留池时乘积可以增加，不能把启动时的 `k_r` 永久写死。边际参考价为 `p_r = G_r / X_r`，黄金价格恒为 `p_gold = 1`。

恒定乘积和输入侧手续费参考 [Uniswap v2 白皮书](https://docs.uniswap.org/whitepaper.pdf)；池余额决定成交价格的原则参考[官方定价说明](https://developers.uniswap.org/docs/protocols/v2/concepts/pricing)。以下运输、救命预算、公共资本和决策规则为本项目设计，不照搬链上金融产品。

卖入某资源，资源变多、池中黄金变少，该资源金价下降；买走某资源则反向涨价。因此水粮大量入市时水粮趋廉，木石不断被买走时木石趋贵。黄金没有独立再生，持续卖货换金会逐渐消耗对应池的黄金流动性。

### 4.2 可执行报价公式

设交易前余额 `X > 0, G > 0`，输入手续费率 `0 ≤ f < 1`，`a = 1 − f`。首期可试验 `f = 0.003`，所有数值需经长程仿真校准。

| 操作 | 输出/成本 | 真实余额更新 |
|---|---|---|
| 卖入 `q` 单位资源 | 收金 `g = G × a q / (X + a q)` | `X' = X + q, G' = G − g` |
| 支付 `g` 金买资源 | 得货 `q = X × a g / (G + a g)` | `G' = G + g, X' = X − q` |
| 恰好买到 `q` 单位资源 | 所需金 `g = G q / [a (X − q)]` | 要求 `q < X`；按真实输入更新 |
| 卖资源恰好筹到 `g` 金 | 所需资源 `q = X g / [a (G − g)]` | 要求 `g < G`；按真实输入更新 |

手续费包含在真实输入中，不能在上述更新之后再扣一次。`p_r` 仅供展示和小额估值；成交必须使用完整曲线，不能用 `q × p_r` 批量成交，也不能按出发时价格冻结至到场。

### 4.3 实物换实物：黄金作为结算中介

`出售 A → 从 A/金池获得 g → 用 g 向 B/金池购买 B`

这是一笔原子复合交易：先在临时状态计算两腿，检查最小收货量、支付上限、池余额、人物资格与可装载量，再一起提交。第二腿失败则第一腿也不发生，防止人物卖掉救命资产却只换回无法使用的报价。

黄金真实从 A 池转入 B 池，通过交易暂存账户过账且结算结束余额归零，无须要求穷人先有黄金。黄金作为最终目标时，直接把卖货所得放入随身黄金；有未使用黄金余款时归交易者，不被市集吞掉。同一笔中介黄金不得同时记入人物资产和目标池。

例：使用 §3 的演示池，为易手算暂时关闭手续费。人物卖出 20 木，获得 `40×20/(200+20)=3.63636` 金；将这些金全部买水，可得 `200×3.63636/(20+3.63636)=30.76923` 水。木池变成 `(220 木, 36.36364 金)`，水池变成 `(169.23077 水, 23.63636 金)`；两池总黄金仍为 60，人物资产只增加实际收到的水。真实启用手续费时使用 §4.2 重新算，所得会略少。

### 4.4 “不会出现三角套利”的适用范围

同一状态下，资源 A 换 B 的边际比价只由 `p_A/p_B` 派生。于是 `p_A/p_B × p_B/p_C × p_C/p_A = 1`，不存在三张独立牌价相互矛盾产生的三角差价。但这个等式只是边际价格一致性，不能替代有限交易量的结算规则。

内部兑换图只有以黄金为中心的四条边，所有交易实时更新余额；没有外部交易或注资插入时，沿此树状图完成封闭循环必须往返经过同一池。无费用、精确算术时逆向交易恢复原状态；加入非负手续费及保守舍入后不能凭空增值。验收须覆盖有限量的 A→金→B→金→C→金→A，不能只检查牌价相乘。

必须同时满足：无重复计入的黄金储备、无独立交叉报价、无过期报价执行、无负手续费、无向交易者有利的舍入、无可领取的交易补贴。首期不增设直接资源交易对，也不新增独立投机获利意图。

**内外市场之间可能存在价差。** 黄金计价不能消除外部补货、路程和不同机制导致的价差；后来增加多个内部市集也会产生地区价差。这是另一类贸易机会，不宣称“整个世界绝无套利”，也不以把内部价格强行钉到外部价格来掩盖。

### 4.5 流动性与精度保护

- 每侧设最小可交易余额；触及下限仅关闭对应交易方向，库存仍存在。任何输出严格小于可用储备，不以极高报价代替缺货状态。
- 首期建议每笔最多取走目标池可用库存的 10%；大需求分笔，每笔按新库存重报价。救急允许小于外部市场 5 单位步长的有效成交，避免“一口水买不起整包”。
- 建议市场结算采用固定最小计量单位与宽整数中间乘积，输入所需量向上舍入，输出向下舍入。与现有浮点账本、行囊交界处必须单次转换并保留可追溯余量，禁止反复转换套利。
- 报价携带市场修订号、最大输入和最小输出；任何余额变化递增修订号。修订不符先重算，不盲目照旧成交。
- 同 tick 以既有稳定 Agent 顺序处理，不依赖线程完成顺序或哈希迭代顺序；每人每交互阶段最多一笔，其他人交易后后一笔必须读新余额。
- 池中物资首期没有额外腐坏或自然再生。未来加入腐坏时它属于明确消耗事件，必须重算可执行余额并入守恒统计。

## 5. 黄金与外部市场如何比价

“黄金比价”比较的是**同一份黄金能在内外两市买到多少目标物资**，而不是创造第二种黄金汇率。只对双方共同提供的水、粮、木比较；石料没有外部采购报价，黄金本身也没有可向外部出售的独立商品行情。

对相同目标量 `q` 计算：

- `C_in(r,q)`：内部按整条 AMM 曲线、手续费、单笔限额和当前流动性算出的累计黄金成本。
- `C_out(r,q)`：按外部现有离散成交、自救规则、库存变化与黄金扣减逻辑逐笔模拟出的成本。不能拿外部当前单位价直接乘大单量，也不能误把其定价改为 AMM。
- `T_in / T_out`：当前位置到首次获得救命量的预计游戏时间；内部包括必要的回家提款装货，外部沿用既有远程黄金支付优势。

先排除超出存活时间、库存不足、预算不足或不可达的路线。危机下按“及时获得最低救命量 → 更早获得 → 更少牺牲家庭资产”排序；常规交易比较同量成本，再以路程和固定 ID 打破平局。用于维持原目的地的价格切换滞回只约束普通交易，不能阻止危机抢占。

比价例：忽略手续费且水池为 `(200 水,20 金)`，购买 20 水需要 `20×20/(200−20)=2.22222` 金。若外部逐笔模拟需要 2.10 金且同样赶得及，则可选外部；若外部虽便宜却来不及，则选内部。这里 2.10 只是场景输入，不是现有固定价格承诺。

外部报价只供选策，不直接改内部池余额或 `k`。人物可以先在内部卖木石筹金，再赴外部买水，但两地之间不能原子结算：必须实际携金赶路，到场再报价，承担价格变化和耗时风险。濒危时只在整条路线可及时完成且直接内部换水不可行或明显更差时采用；首期可先只实现内部复合自救与直接黄金内外比价，把跨市两段任务放到第二阶段。

## 6. 搬运、执行与记账

### 6.1 一次内部交易的完整过程

`资源需求 → 选择内部交换 → 必要时返家 → 装载出售物 → 前往市集 → 重报价 → 原子交易 → 就地自救/装袋 → 返家卸货`

- 在家装货时，按物理装载速率从家户账本扣除并加入行囊；预约本身不扣账。沿用每类独立容量，不能把四类 50 单位误当作共享 50 单位。
- 只有到家且装载成功的物资才可出售。木石水粮均不远程扣家庭余额，黄金同样实际携带；装载黄金需有数量预算，不能一次搬空金库。
- 交易优先使用本次授权货物，计划注明哪些行囊余额可出售，避免顺手卖掉另一个生存任务留下的口粮。
- 在市集先将购买的水粮中必要部分按现有生理转换规则就地消费，其余装袋。消费量也必须真实扣市场库存并支付；交易货物减少与生理恢复分开记录，不将“补满生理槽”直接当作同数量物资。
- 返回家宅后按正常卸货规则入账。未卖出的货物随身返回，不能在取消任务时直接加回家户账本。
- 若同品类出售后又买回，拒绝作为单任务计划；无有效收益需求或无可成交项即退出，不在市场无限驻留。

### 6.2 事务与守恒

建议增加内部市场账本引用、取货/退货原因、内部成交记录及短暂结算中介；具体类型名实施时确定，不复用外部 `Void` 流向。

| 事件 | 源 | 目的 | 守恒要求 |
|---|---|---|---|
| 家庭提货 | 家户账本 | 人物行囊 | 家户减、行囊同量增 |
| 卖资源 | 人物行囊 | 对应市场资源池 | 资源同量转移，支付黄金来自该池 |
| 买资源 | 市场资源池 | 人物行囊/现场消费 | 已购买量只分配一次 |
| 黄金中介 | 卖出池黄金 | 买入池黄金/人物余款 | 两腿合计黄金守恒 |
| 卸货/未售退货 | 人物行囊 | 当前合法归属账本 | 物资到达后才入账 |

内部市场不新增全世界黄金，也不销毁黄金。水粮等只有真实生理消费、既有耗用和将来明确实现的损失会减少；外部采购按原规则单独统计出入世界的流量。手续费只是池内留存，不能同时记成系统消耗和市场收入。

### 6.3 中断与社会关系变化

- 途中被更高需求抢占：释放未提取预约，保留已携带货物，以当前位置平滑改道；不重置库存或瞬移回家。
- 人物死亡：取消任务和预约，随身物资只走既有死亡资产处置一次，不再以“订单退款”复制回旧家户。若既有处置会消耗物资，记录实际损失而非假定全部继承。
- 家户解散、分家、改嫁：失效的未执行提货权立即取消；已取货保留来源与委托归属，按既有继承/财产规则结算后再决定能否继续使用，不保留指向已解散家户的扣账引用。
- 市场缺货或价格超限：本次无任何资产变化，允许缩小到有效自救量；仍不成交时交回策略层选择其他方案。失败冷却与库存修订关联，不能永久拉黑重新有货的市集。
- 返程中家宅消失：目的地重新按当前合法归属选择，行囊物资不因此清零。

## 7. 决策与数据接入边界

L1 继续回答“解渴、觅食、储备木石金”；L2 比较自用、采收、外部采购、内部交换；L3 执行回家、装货、行走、成交、自用和卸货。执行中的交易计划存入 `ActiveTask` 及其策略阶段，通过统一 transition 入口推进，不能另造与之竞争的状态机。

紧急自救与普通补货共用报价与结算器，区别在需求目标、权限和路线可行性。交易也不属于瞬发意图：即使现场单笔结算原子完成，前往和搬运仍是持续任务。维持现有错峰决策、固定 dt 与 tick 阶段，不新增一个市场线程自行决定居民去向。

建议持久化以下最小状态：

| 所属 | 状态 |
|---|---|
| 市场 | 稳定 ID/地点/管理归属、四池真实余额、启用状态、余额修订号、有限交易流水与累计统计 |
| 交易任务 | 来源意图、目标资源与剩余量、市场、出售预算、货物来源/委托归属、阶段、最小收货量/最大支出 |
| 家户 | 唯一取货预约及剩余额度、失效判据；实际库存仍在原账本 |
| 人物 | 普通出售滞回、失败冷却及失败时市场修订号；已提取货物仍在原行囊 |

报价是从余额重算的只读结果；出发时信息仅作计划，不能作为到场成交承诺。首期允许沿用全局只读市场信息供选策，这属于模型简化，UI 应标为“预计”；后续记忆或信息传播可以改变已知行情，但不能改变真实成交余额。

全部影响行为的状态须随档持久化，读档不能重发启动资本、重提货、重成交或丢失半段任务。快照新增字段按 `snapshot.rs → world_snapshot.rs → snapshot_bin/encode.rs → snapshot-bin.js + rustworld.js` 同步，涉及枚举还要同步二进制字典。应用版本和存档格式如何升级由未来实现时按实际结构变更决定，本规划不改变当前版本或存档兼容性。

新增参数集中进入既有配置体系：开局各池资本、交易费率、储备下限、单笔限额、最小计量单位、救急安全余量、家庭出售保护与滞回、取货速率、报价切换阈值、失败冷却。优先复用已有生理警戒、容量、耗用与运输参数，不维护另一套冲突的默认值。

## 8. 玩家如何看懂市集

市集 Inspector 展示水粮木石储备、各池黄金及黄金总量；行情统一使用“金/单位”，同时提供固定数量的实际买入价与卖出所得，不能只展示 AMM 边际价让玩家误判。

人物卡解释本次行动：“缺水，家中有石，带 12 石去市集换水”“家中余粮，金矿断流，出售余粮储金”。黄金采购同时显示内外预计成本、时间与最终选择原因，例如“榷市更便宜，但市集能先喝到水”。

成交记录保留人物、家户、输入品类/数量、实际中介黄金、输出品类/数量、手续费、现场消费、池修订号；一笔复合交易关联两腿，防止被看成两笔独立获利。显示无货、黄金流动性不足、预算不足、路线来不及、行情变动等明确失败原因。

宏观观察按家庭记录净卖出资产、净买入生存物资、濒危交易后存活情况、池黄金变化与外部黄金流失。“救急成交”不是“成功救命”，必须观察交易后的生存结果。

## 9. 实施阶段与验收

| 阶段 | 范围 | 完成条件 |
|---|---|---|
| P0 经济模型 | 单市集四池、有限资本、双向报价、原子换货、舍入与守恒 | 演示账目可复算，封闭循环不能获利，无零库存除法 |
| P1 最小生存闭环 | 家户提货、木石金换水粮、现场自救、直接黄金内外比价、存档与基础观察 | 至少一个濒危家庭实际携货成交、自救并带余货回家；权限/中断不复制资产 |
| P2 双向资源循环 | 余水余粮换木石金、家庭保护、失败退出；跨市筹金采购 | 断流资源需求能通过居民库存解决，出售不导致机械补货震荡 |
| P3 长程平衡 | 多季节多代、资本与费率敏感性、财富分配、市场关闭场景 | 结论区分库存注入效应、再分配效应与外部进口效应 |

实施时至少验证：

1. 无金有木/石家庭能完成两腿自救；第二腿失败，两边余额全部不变。
2. 富余水粮家庭在木/石/金分别断流时可换货，家庭保护量不被突破；无需求时不纯粹倒买倒卖。
3. 池内无水、无粮、黄金触及下限、容量不足、极小交易、大单分笔均可有限步退出，无负余额、NaN 或虚空补货。
4. 相同目标量下内外成本比较准确；更便宜但来不及的路线不被选中；外部库存变化后按其实际规则重新报价。
5. 同户多人取货、途中死亡、分家、家户解散、家庭吃掉预约粮食和途中存读档，均不超额取货、不重复结算、不遗留永久预约。
6. 所有封闭交换循环在无外部干预下收益不为正；每次交易前后逐资源核对行囊、家户、市场、消费和明确外部流量。
7. 同种子、连续/分批推进、存读档续跑保持确定性；只读报价/观察不消费 RNG，不修改余额或缓存中的行为状态。
8. 对比“无内部交易”“同量物资保留在家庭/公仓”“四池市场”三组，控制初始总资源与黄金一致；观察多季节、至少三代的死亡率、家族存续、财富集中、救急后存活与内部成交比例。单列灭绝样本，不把灭绝当作财富均衡。

按项目要求只使用临时经济验证脚本验证公式与极端场景，实施阶段完成后删除；长期回归复用既有 WASM、确定性、快照、配置与前端门禁。性能以同种子同规模基线配对，报价只在决策/交易发生时计算，避免每 tick 全人口扫描全部市场或全量重新寻路。

## 10. 首期明确不包含

信用借贷、负库存、凭空铸金、自动按外部价重置池子、随时赎回公共资本、独立套利机器人、跨营地多个内部池、无偿救济和新的税收政策都不在首期。它们会改变风险、分配或流动性约束，后续必须单独设计，不能以“完善市场”为由隐式加入。

本方案最终希望形成的是：家庭积累的建材可以在危机时换来生存，幸存家庭的余粮又能换回生产资料；黄金给所有交换提供共同尺度，真实库存和真实搬运给这种交换保留边界与代价。

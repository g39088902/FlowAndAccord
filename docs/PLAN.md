## 1. 项目愿景

构筑一个**微观空间动线 × 自发生态演化 × 显式产权账本经济 × 现代混合政体光谱**深度交织的社区尺度微型社会——居民依据欲望线自发筑屋拓路，资产归属于有管理者的账本主体，统治者兼具民意/技术/资本/强制/宗法/意识形态六维权力，在有限寿命与精力约束下经历执政登顶与在野流变。

**核心设计哲学**：
- **确定性涌现**：纯规则内核驱动多智能体，长期演化不可预测但可复现（同种子逐字节一致）；
- **账本即权力**：资产负债表即社会结构快照，任何资源流动都是主体间显式 Transfer（可审计、可追溯）；
- **非互斥混合政体**：告别"纯民主 vs 纯独裁"二元标签，统治者可同时动用选举、算法、专利、武力、宗族多种合法性来源。

## 3. 未来里程碑（规划态）

> 账本经济 M2（v1.1.0 旁路记账/分家继承）、M3（v1.2.0 宗族）、M4（v1.3.0 地区王国）已全部落地，详见 [docs/current/12-ledger-system.md](./current/12-ledger-system.md) 与 [docs/PLAN_LEDGER_REFACTOR.md](./PLAN_LEDGER_REFACTOR.md)。以下为尚未实现的未来方向。

### M5 · 专利经济与痛点动态发明 → v1.4.0

**核心目标**：引入"痛点倒逼发明"机制，民间野生黑科技带来高回报高风险的投机博弈。

- 痛点追踪（拥堵/噪音/资源瓶颈）自动聚类生成科技方案；
- **民间野生黑科技**：底层居民突变发明高商业回报但伴随治理副作用的技术（如"下水道高压蒸汽穿梭车"）；
- 天使轮注资：玩家/家庭可用私产低价注资野生发明家，成功获垄断分红，失败承担舆论冲击；
- 专利股权确权写入资产负债表，支持在野做空收购、垄断收费或特权征用；
- **前置依赖**：M2 账本体系（专利授权计费、救济、工资、分红等一切主体间交易才有归属与可审计的资产负债表）。

### M6 · 六维政治资本与混合政体 → v1.5.0

**核心目标**：统治者权力从"单一国王"升级为六维连续政治资本向量，复合形态与特权法案解锁。

- **六维向度**：民意 Civic / 技术 Tech / 资本 Capital / 强制 Dread / 宗法 Dynasty / 意识形态 Hegemony（各 0~100）；
- **固定年化指数衰减**（基准 8%/年）：高存量与多向度自然导致维持成本激增，杜绝"全知全能数值全满"；
- **复合统治者形态**：多维高阈值组合激活（镀金民选市长 = 高 Civic+Capital；民粹凯撒 = 高 Civic+Dread+Hegemony 等），LLM 动态生成民间诨号；
- **特权法案矩阵**：多维阈值交叉解锁（智慧绿波、私立收费站、人民卫队、王家御道等）；
- **执政与在野流变**：下台保留私产，可选择幕后操盘复仇 / 隐退食利躺平 / 自由读档。

### M7 · LLM 认知总线与生成式社交 → v1.6.0

**核心目标**：异步 LLM 层承担叙事生成——希腊合唱队、议会辩论、NPC 心声日记，核心循环仍由模板即时兜底。

- **双轨响应**：核心事件由模板引擎 0ms 即时返回，背景叙事由 LLM 异步润色；
- **希腊合唱队**：街头小报头条、酒馆打油诗、名流沙龙议论，以尖锐笔触点评政策矛盾；
- **议会大辩论**：重大法案/大选前触发语言攻防对决，玩家按六维向度打出不同特权论据；
- **NPC 心声日记**：剥离数值 Buff 功利绑定，聚焦真实价值观认同与立场冲突（如工会领袖在你向财阀妥协时写下"既心疼又失望"）；
- 生成式 2D 立绘与阶级微表情。

### M8 · 内核架构演进（ECS + 零拷贝快照）→ v2.0.0

**核心目标**：性能与可扩展性升级，为数千实体与复杂社会经济模拟奠定基础。

- **ECS 内核重构**：从当前 `Vec<Agent3D>` 结构体数组迁移至 ECS（hecs/bevy_ecs），组件化实体、系统调度；
- **零拷贝快照**：从当前 JSON 序列化迁移为双缓冲共享内存快照 + Hermite 时间戳插值，消除 WASM 边界序列化开销；
- **sim_cli**：命令行调试、性能 Benchmark 与大批量蒙特卡洛仿真；
- 详细架构愿景见 [docs/ARCHITECTURE.md](./ARCHITECTURE.md)。

## 4. 跨里程碑核心设计原则

| 原则 | 说明 |
| :--- | :--- |
| **确定性红线** | 一切随机消耗走 `WorldRng` 按 agents 顺序消费；新增机制不破坏 `tools/test-wasm.js` 同种子逐字节一致性 |
| **新旧分离** | 新经济/政治系统与现有房屋/仓储/决策逻辑完全分离，通过旁路观测记账，不做兼容层迁移 |
| **Agent 自主决策** | 系统只当"物理规则执行者"，一切"做不做、何时做、在哪做"来自 agent 自己的需求评估，严禁扫描全图强制指挥 |
| **超参集中化** | 全部可调参数走 `config.rs`（命名 const + SimConfig 字段 + Default 映射三处）+ `config.js`，改完必跑 `config-check.js` |
| **持久化测试禁令** | 不持久化单元测试，临时验证后删除；长期验证只依赖 `node tools/test-wasm.js` |
| **快照三处同步** | 新增字段须同步 `snapshot.rs` → `world.rs::generate_snapshot()` → `rustworld.js::_applySnapshot()` |

## 5. 核心风险与应对

| 风险 | 应对策略 |
| :--- | :--- |
| 六维心算导致认知超载 | 具身视听表征（街景/声景/NPC 行为替代纯数值）+ UI 只高亮当前主导复合形态 |
| 下台导致挫败与厌恶 | 开放式多轨：不强制复仇，可隐退食利或自由读档 |
| 维度全满导致数值通胀 | 固定年化指数衰减 + 寿命约束，高存量维持成本激增 |
| 恋爱社交沦为数值买卖 | 剥离 Buff 绑定，强化微表情与日记中的真实心理挣扎 |
| LLM 复合语气紊乱 | 结构化 Prompt 多权重插值（如 70% 科学论述 + 30% 皇家威严） |
| 记账/换届破坏确定性 | 钩子纯观测、不消耗 RNG；tick 尾段独立追加；排序并列取 id 小者 |

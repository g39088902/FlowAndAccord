## 2. 已核对的技术事实与公共缓存约束

以下为 2026-09-14 源码核对结论，供后续验证与修复直接引用：

## 3. 样板选取与受控夹具规则

1. **两条验证路径**：受控视觉路径（临时夹具复刻到独立位置、走生产绘制管线）+ 真实世界路径（保留原始坐标、实际页面与快照推进）。夹具移动时必须重取落点真实地表高程，并标记为「视觉夹具」，不与真实世界截图混用。
2. **选样规则**：seed 42 为搜索起点；落叶 Tree / 落叶 Bush 按 `kind` + `AccentModel.get(accent).evergreen === false` 筛选；岩石必须 `Boulder`（不能用 RockCluster 代替）；优先枝形清楚、无遮挡、非边界个体；另选真实坡地/视口边缘补充；无合适对象换种子，不编造 ID。
3. **夹具选址硬判据**：S4-03 景观遮罩会把落入 POI 保护区/景观重叠区的 accent **静默隐藏**（`LandscapeMask.accentHidden`，render_depth_queue.js:387）——选址必须先 `LandscapeMask.sync(sim)` 再以 `accentHidden(clone) === false` 复核，否则克隆体不出图且无报错。
4. **身份记录**：保存 `kind/id/x/y/z/scale/rotation/tint`、模型细节阈值、季相 profile 与配置；所有季节/镜头对照保持同一对象身份（个体哈希造成的季相偏移用「同对象跨季对照」口径消除）。
5. **夹具卫生**：仅在开发会话内存在，退出时恢复函数/相机/配置/输入引用并核对 accents 数量复原；不得改 Worker、`_applySnapshot()` 或存档季节字段伪造端到端通过。

## 4. 四季、镜头与受光验证指引

### 4.1 季相采样

统一 `SimTreeTint.sample()` + `yearPhase()`；季分箱中心春 0 / 夏 0.25 / 秋 0.5 / 冬 0.75。四季中心之外补初春、晚春、初秋、深秋；每个季节交界取 `progress=1−ε` 与次季 `progress=ε`（ε=0.001），**并单独扫过春季中部的年度相位回环**。数值采样用独立只读对象 `{currentSeason, seasonProgress}`，不写回真实 `sim`。

判定要点：同株春芽/夏冠/秋色/冬枝可辨；Bush 保持基生多茎形态；先变色后减叶、叶簇仍挂真实枝条、无整冠半透明冠云；普通落叶树冬 `leafDensity` 0~0.05（叶量参数不是像素覆盖率）；岩石材质不随植被季相变色（真实光相导致的明暗允许）；常绿对照个体冬季轮廓不变。

### 4.2 镜头矩阵

主矩阵 = **四季 × 四方位 × 两档俯角 × 三档缩放 = 96 视图**；三对象同框可共同评分，分镜头时必须逐对象覆盖。建议初值 `rotZ = 0/π/2/π/3π/2`、`rotX = 0.45/1.25`、`zoom = 0.6/1.5/3.5`，并按对象实际屏幕尺寸核对 `accentDetailLevels()` 三档全覆盖——不能仅凭 zoom 数字宣称覆盖。每组记录 `panX/panY/rotZ/rotX/zoom`（注意 pan 为**屏幕空间偏移**，居中换算同 render_canvas.js:166 跟随逻辑）。另做整圈连续旋转、细节阈值两侧往返缩放、四边视口移入移出、坡地接地与道路/房屋/人物上下文误覆盖检查。

### 4.3 受光变量分离

固定季相与相机、热调 `SIM_LIGHTING.azimuthOffsetDeg` 变世界光向（等光照稳定再截图）；固定季相与世界光转相机（暂停或固定光输入，防 `SimLighting.update()` 覆盖）；补光向接近视线的退化位（簇亮部平滑回冠心，无归一化抖动）与动态光开→关→开。

## 5. 生命周期与缓存验证清单

| 场景 | 必须记录的结果 |
| :--- | :--- |
| 真实四季推进 | 植被随真实快照变化；叶量不读取平滑光相 |
| 暂停/继续 | 季相与模型不漂移（光照收敛慢单列，不误报成落叶漂移） |
| **LOAD** | 用实际 **Chrome** 存档入口载入同版本档；记录 LOAD_RESULT、对象/季相/模型重建、选择与镜头状态（**待补测项**） |
| REWIND | 回到记录 tick 后对象几何/季相/可见簇精确复原，无未来缓存残留 |
| RESET / READY | 新世界身份生效；不按相同 profile 或 epoch 误复用旧模型 |
| 冷暖缓存 | 暖缓存 vs 清理重建：几何摘要一致、画面无差异（光照先稳定） |
| 高倍速 | 无频闪/错误缓存/输入失效；记录 tick/s，不用降 tick 掩盖渲染成本 |
| 交互/共享模型 | 选择/跟随/关 Inspector（关必须同时停跟随）；资源景观共用模型无回退 |

REWIND 同路径证据与 `test-determinism.js` 存读档套件只能作为 LOAD 的补充，不能写成已通过；`?nogate=1` 只适用非存档验证（边界见根 AGENTS.md §4.0 与 [06 号](../../current/tech/06-snapshot-and-save.md) §4.2.1）。静态通道契约与模型清理规则见 [07 号](./07-terrain-art.md) 状态机节，不在本文重复。

## 6. 性能测量口径（复测时沿用）

- **场景**：P1 初始·固定 / P2 初始·连续旋转 / P3 高密·固定 / P4 高密·连续旋转；高密档记录人口/房屋/实体/可见数量并 rewind 对齐同 tick 起点。
- **计时边界**：整帧主线程（只计实际绘制帧，rAF 门控提前返回不计入）；渲染与 UI（`tickEnd`→帧末）；统一队列完整包裹 `drawWorldEntities()`（含阴影入队/排序/分发/绘制）；装饰归因按单帧累计成样本，**不对单次 draw 求 p95、不把各模块 p95 相加**；吞吐 = 真实 tick 增量/墙钟秒。HUD 平滑均值不冒充 p95。
- **统计**：预热 ≥12s、每场景正式采样 ≥60s、建议 ≥3 轮交替顺序；p95 固定 nearest-rank（升序下标 `ceil(0.95×N)−1`）；保存原始毫秒序列 + p50/p95/p99/均值/最差。
- **预算引用**：07 号 §11.3（渲染/UI p95 ≤16ms；新增绘制 p95 增量 ≤3ms；吞吐回退 ≤5%；视觉缓存 ≤64MiB；首帧单列）。超标处置顺序与「确需调预算先实测后经用户明确接受」的纪律见该节，不在本文重复。
- **仅现状归档时**（未改代码）：报告绝对耗时 + 波动区间，不伪造「新增为零」；不同环境/口径（面板可见性、驱动方式）的绝对值不可直接对照。

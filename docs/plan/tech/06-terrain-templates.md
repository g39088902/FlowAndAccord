# 06. 地图类型与统一地形生成规划

> **状态**：规划。当前实现、旧模板算法和历史验收证据以 [14 号现状文档](../../current/tech/14-terrain-and-network.md)及 [变更记录](../../current/01-changelog.md)为准。本文件只定义地图类型的目标和通用验收；实现契约见根目录 [统一地形生成器设计](../../../TERRAIN_FIELD_COMPILER_DESIGN.md)。
>
> **决策（2026-09-24）**：取消一切“为某张地图或某种地貌另写生成分支、注入器、专用几何算法”的待开发计划。已有代码仅用于迁移期兼容与回归。新增地图和局部地貌以数据配方、通用地理过程和约束表达；体素是目标地图表示。历史方案可从 Git 历史查阅，不再是施工依据。

## R.0 统一生成器方向

```text
种子 + 地图配方 + 约束
  → 通用地形场与地质、水文、土壤过程
  → 通用有效世界校验与有界重试
  → 地形事实（水、地表、材料、通行、可建、植被资格）
  → 高度场兼容视图 / 体素块
  → 游戏逻辑查询与 WebGL 表现
```

- 地图类型是结果目标和参数组合，不是 `generate_<地图名>()` 代码入口。
- 湖泊、瀑布、牛轭湖、峭壁、盆地、冲积扇和山口由同一批可复用过程产生；仅当缺少通用过程时才新增通用算子。
- 水的可达性和地下水先决定土壤湿度，再决定植被资格与地表材料；缺水区域不得由模板名或贴图逻辑直接变成草地。
- 游戏系统只查询已生成的地形事实，不在 tick 或选址逻辑里补造地形。
- 旧 profile、旧生成器版本和固定种子结果在迁移期用于存档兼容与回归；新配方过门禁后才切换默认入口。

## R.1 地图类型与体验目标

| 类型 | 当前状态 | 目标地形事实与体验 | 配方约束重点 |
| :--- | :--- | :--- | :--- |
| 山口、两岸河谷 | 已有高度场实现 | 山口绕行；两岸经浅滩相连 | 坡度、连通、水源、路网成本 |
| 草原、半坡林地 | 已有高度场实现 | 开放选址；坡脚与林缘的慢行取舍 | 水分支持草甸；林木不虚构阻路 |
| 台地、盆地、冲积扇、火山湖 | 已有高度场实现 | 高差与入口、低地生活带、扇面沟谷、环湖路径 | 可建面积、出入口、排水、取水和岸带 |
| 山脚湖、瀑布、牛轭湖、峭壁 | 部分旧子特征已实现 | 局部地标与真实绕行、水系、遮挡 | 必须由通用水文/侵蚀/岩壁过程产出真实几何；不得单独开发模板注入器 |
| 沙漠绿洲、喀斯特、三角洲、海湾、半岛、峡湾、海岛 | 远期目标，未有完整规格 | 干旱聚落、地表及地下水、分汊、海陆边界与孤岛生存 | 先补通用干旱、溶蚀、分汊、海水/淡水、多层导航能力，再定义配方和验收 |
| 盆地群峰、山嘴与峡谷出水口 | 盆地现状的质量目标 | 避免外围平顶，形成起伏山系、盆底汇水和可通行出口 | 由通用地质结构、侵蚀、汇流与约束求解；不重构 `basin.rs` 为另一套盆地专用公式 |

当前已有地图的精确 profile、参数和存档规则见 [14 号现状文档](../../current/tech/14-terrain-and-network.md)。表中的远期类型是验收目标，不代表已排期开发独立模板。

## R.2 实施顺序

1. **UGC-00**：冻结现有世界的种子、字段、存档和性能基线。
2. **UGC-01～03**：实现通用地形场、水文、土壤和材料过程；用同一编译器迁移现有静态地图配方。
3. **UGC-04～05**：接入稀疏体素块、兼容的顶部地表查询、存档和 WebGL 网格。
4. **UGC-06～10**：增加地层、断层、静态地下水、剖面诊断与多层寻路，支持洞穴和悬挑的真实语义。
5. **UGC-11～12**：外部地理数据适配与远期专业物理扩展。
6. 在相应通用能力通过门禁后，再增加地图配方；配方不能增加地图专用 Rust 生成分支。完整输入输出、失败码和任务卡见[统一地形生成器设计](../../../TERRAIN_FIELD_COMPILER_DESIGN.md)。

动态水文和社会改造属于后续独立能力：变化以体素块增量存档，由游戏逻辑消费；不恢复逐模板的动态地形代码。

## R.3 每张新地图的验收

- 同种子、配方和版本生成相同地形事实；原有地图的变化须有明确版本和存档处理。
- 水体、水源、地下水、土壤湿度、植被资格、材料与颜色可追溯；干旱区不得无水长草。
- 可行走连通、合法出入口、可建面积、真实取水和资源距离达到配方约束；失败有稳定原因和有界重试。
- 体素形态的悬挑、洞穴、水面和地层与碰撞、导航、渲染一致；未接入多层导航前不得暗示地下可达。
- 旧 profile 的历史回归、WASM/native 确定性、存读档、WebGL 视觉和性能按 [统一设计的验收矩阵](../../../TERRAIN_FIELD_COMPILER_DESIGN.md)执行。
- 视觉样板只能证明表现质量，不能替代地形物理事实验收。

## R.4 与地形美术的边界

[07 号地形美术规划](./07-terrain-art.md)只消费地形事实和材质字段。山脚湖、瀑布、牛轭湖等专属景观在通用生成器产出对应真实特征后解锁；表现层不得依靠模板名、选择器命中或视觉补丁伪造水体、绿洲、道路或可通行空间。

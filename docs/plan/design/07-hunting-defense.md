# 07. 狩猎、防卫与公共庇护设计

> **状态**：优化后的规划设计，尚未实现、未排期（M18）。

> **关联**：[长期路线图](./01-roadmap.md) · [日常生活](./02-everyday-life.md) · [当前观察设计](../../current/design/05-observation-ux.md)。

## 1. 体验目标与机制取舍

让武力连接家庭生存与公共庇护：猎人冒险带回过冬物资，居民在危险面前选择避难或守卫，公仓以实际支付承担保护居民的责任。玩家应看懂一次出猎为何值得、一个人为何没有参战、一次成功防守让哪些家庭付出了代价。

核心循环是“发现缺口 → 权衡风险 → 自主行动 → 真实搬运或防护 → 家庭与公共账本发生变化 → 恢复生产”。击杀数量不能替代安全、营养与家庭延续成为成功指标。

| 设计问题 | 本稿选择 | 形成的取舍 |
|---|---|---|
| 有武器就出猎，缺少停止条件 | 武器只提供能力，食物或保暖缺口才提供动机 | 采集、采购与狩猎竞争同一目标 |
| 性别、力量与私宅一刀切资格 | 成年、身体能力、装备与风险决定资格；家户权限另验 | 无宅者可守卫，也可在现场自食；不因此获得家庭装袋权 |
| 猎物无限再生、追逐没有终点 | 有限生态补充、有限追逐与放弃冷却 | 高收益需付出时间，过猎降低未来收益 |
| 固定刷寇并直接扣掉库存比例 | 有恢复窗口的有限事件，接触、破门、装运逐步发生 | 防守可以减少损失，不必歼灭对方 |
| 全营瞬时参战、全员离家 | 局部警报、个人守卫判断与家庭外出名额 | 公共安全与家庭照料争夺劳动时间 |
| 按最后一击付赏 | 有限预算内按有效护民贡献结算，伤亡救助独立于胜败 | 守住人、带回物资与安全撤退也有价值 |

## 2. 狩猎：有目标的风险生产

### 2.1 为什么出猎，何时不出猎

狩猎首先服务于两类目标：家中可及时食用的储备不足，或寒期有效供暖需求超过可维持的燃料储备、仍有保暖用品缺口。拥有木矛、力量高、季节改变都不是独立的出猎理由。

食物不足时，人物比较采集、合法采购与狩猎的往返时间、首次可进食时间、预计有效产量和风险。饥渴濒危者优先选择来得及救命的来源，不能因“肉更营养”走向遥远猎场。已有足够食物或保暖收益接近上限时停止为该目标狩猎。

资格由成年、可重劳动、生命力、伤势、体力、装备和路线共同决定，不设额外男性专属门槛，也不保留固定力量值的一票否决。力量连续影响效率与承险能力；孕育、衰弱等限制通过共用身体能力规则表达。常规计划还须有可行的返程和安全余量。

没有家宅者仍遵守既有现场自饮自食规则：可选择可负担的现场猎食，不为不存在的家户装袋，不自动拥有公共交货权限。运输委托在后续具有明确货主与授权时再开放。

### 2.2 生态与猎场

首期只引入一种温顺食草动物，以有限兽群表达栖息地容量。它们在合法栖息范围内活动，受惊后逃向可达的安全位置；不跨水域、陡坡或障碍瞬移。动态动物不充当可无限采收的普通资源点。

- 补充速度受栖息地容量、当前存量与季节影响，有繁殖/外来迁入的明确来源，不在猎人离开或刷新画面时重生。
- 低存量时暂停普通出猎候选，恢复到较高门槛后再开放，避免围着最后一只猎物反复出发。灭群后的恢复仅来自配置允许的边界迁入；没有合法入口就保持空缺。
- 猎场不消耗既有浆果、水源库存，除非将来明确接入食物网；初期避免改变所有基础采集的供给。
- 猛兽后置：只在标明的栖息区域形成局部风险，有追击边界，脱离接触即可退回，不全天候追人横穿世界。基础自救可用后才开放主动伤人。

### 2.3 一次出猎的全过程

```mermaid
flowchart LR
    A[食物或保暖缺口] --> B[比较可行来源]
    B --> C[准备装备与出发]
    C --> D[有限追踪]
    D --> E[接触与捕猎]
    E --> F[处理猎物并装袋]
    F --> G[返家逐步卸货]
    D --> H[失联或预算耗尽]
    E --> H
    H --> I[放弃并重新决定自救或返程]
```

一次任务设追逐时间、距离、接触次数和返程体力预算，任一耗尽即放弃。目标不可达、伤势加重或生理告急时同样退出；同一失败目标短期冷却，防止连续掉头与反复投掷。家人补足缺口后停止追加捕猎，已有物资仍保留并选择合法处置。

捕猎至少区分“接近成功”“命中造成伤害”“目标死亡或逃脱”，不以一次随机胜负直接兑换整头猎物。温顺动物主要让猎人损失时间与体力，致命反击属于后续猛兽的差异；不把每次猎鹿都设计成生死赌博。

猎物死亡后留下有限、可耗尽的待处理产物。处理需要时间，搬运受肉与兽皮各自容量及携带状态限制；装不下的部分留在现场，经过保存期限会腐败。多人可接近同一兽群，但同一只猎物首期仅接受一个有效捕猎占用，尸体处理也须避免重复产出。首期不加入队形与协同包抄。

### 2.4 肉、兽皮与装备的完整成本

| 产物或资产 | 收益 | 成本与停止条件 |
|---|---|---|
| 生肉 | 按实际食用量提供营养，也可接入后续烹饪 | 独立库存，处理、搬运与腐败均有损耗；不额外叠加饱食衰减减缓 |
| 兽皮 | 减少寒期实际燃料需求 | 收益随已覆盖保暖需求递减，保留最低燃料消耗；没有缺口就不为囤皮无限猎杀 |
| 木矛等装备 | 提高捕猎与自卫能力 | 制作扣真实材料并占用劳动，使用磨损，失效后不能继续获得加成 |

肉、熟食与普通粮分别计量；“可食用储备”只是营养折算视图。肉的腐败同时覆盖尸体、行囊和家户，搬运、卸货、读档不能刷新期限。首期不要求烹饪、冷库或新增市场池，生肉直接食用即可构成闭环。

兽皮存放在家中时可贡献基础保暖，效果考虑家庭需求与数量并限幅；投入被褥或装备后扣除原皮，效果转由实际用品承担。同一张皮不能既算仓储保暖，又算衣物与被褥。供暖收益只降低既有燃料压力，不凭空新增“缺柴冻死”规则。

## 3. 流寇：能预警、能止损、能结束的危机

### 3.1 生成与恢复窗口

首期仅外部流寇，且第一次可致伤入侵必须晚于基础逃生、房屋庇护与自主守卫能力。无须已有国王或建好高级工坊；无政体时依靠个人守卫，不能产生无付款人的公共赏金。

生成采用“基础成长保护期 + 上次事件恢复期 + 当前承受能力门槛 + 有上限的事件规模”。承受能力考察存活人口、可行动成人、近期伤亡与食物恢复；季节紧张可提高发生倾向，但不能绕过保护门槛制造连续灾难。规模在事件开始时冻结，不因玩家改善防御实时追加敌人。

初期全图至多一个活动入侵事件。流寇从可通行边界进入，不能出生在居民身旁、宅内或唯一救命资源点上；找不到合法入口则跳过。每团有有限人数、携带能力、停留时限和退路，不在交战中补兵。具体规模与时间由长程实验校准，不把原稿的固定人数、固定年数当作承诺。

成长保护与恢复期只抑制新入侵，不移除已经存在的危险。界面应能解释“尚在恢复期”“无合法入口”等事实；不声称按这些门槛就一定不会灭绝。

### 3.2 掠夺与撤退

流寇以取得物资后生还为目标，比较可见目标的距离、防御、可取物资与逃离代价。不能读全图隐藏家产后直奔最富家庭。首期优先劫取随身物资及破门取粮，攻公仓复用相同接触和搬运规则。

1. **劫道**：接近受害者后才有夺取机会；对方可以逃离、放弃一部分行囊止损，具备能力时自卫。交货必须在接触处真实转移。
2. **破门**：实际到达并持续破坏房屋防护，期间可被阻止。门未破不能扣家户账本，进入后按装载速度取货。
3. **离开**：装满、达到战利品目标、士气溃退、伤势严重或停留超时即撤离。黄金也受流寇单次劫掠额度约束，不继承族人无限金袋形成无限搬空。
4. **结案**：全体入侵者离境、死亡或失去敌对能力，且相关交战结束后结案；丢失目标只有“失联”，不算歼灭。

没有固定“瞬扣家户三至五成”的事件伤害。损失来自实际被搬走的物资，少量破坏只能消耗真实耐久；不给流寇设置库存保护的秘密豁免，也不允许其无成本反复搬空全图。

## 4. 预警、避难与守卫

### 4.1 警报是信息

目击者产生带地点、时间和可信状态的报告，营地传播需要游戏时间。哨塔扩大有条件的探测与报告能力，不保证固定提前多少秒；无人值守或缺维护时显示失效原因。值守同样由个人自主任务产生，建筑本身不能兼任无限劳动力。

警报区分疑似、确认与失联。居民依据自己收到的危险信息和局部接触判断行动；玩家可在观察视图看到世界事实，但不会因此让所有人物获得全知。直接遇敌者不必等待全营传讯，仍通过统一决策入口处理自救。

警报解除需要最后目击超时且本地无持续接触。重新确认会刷新警报；迟滞避免一帧拉警报、一帧全员复工。事件结案和每处地方警报分别展示，不能把暂时平静伪装成流寇已离境。

### 4.2 有限庇护与退路

避难按“及时到达、路径风险、剩余容量、防护状态”选点，较高等级房屋通常更坚固，但不能吸引人穿过敌阵。优先可用自宅，再考虑允许接纳的邻宅或公共避难点；紧急接纳不转移房屋、户籍或继承权。

- 容量计入住者和有效到达预约，到门口需再次确认；老人、幼儿、重伤者有稳定的优先接纳规则。无路、满员或关闭时立即展示原因并重选。
- 原住者不被预约驱逐，幼儿不被当成能独自长途逃跑的成人。首期仅开放可自行移动者避难；不能移动者原地庇护，由守卫可选择保护其所在地，完整抱扶护送后置。
- 没有可达避难处时选择可达、危险较低的撤离位置；不默认“山林永远安全”，不瞬移入宅。
- 进入避难处不恢复饥渴、不复制食物。首期消耗本人合法携带物资、既有自宅消费或实际交付的公共救济；不能远程吃邻宅账本。庇护信息显示供给来源和预计可坚持时间。
- 房屋耐久不足、门被破坏或供给无法维持时重新求生；屋内不是绝对无敌区。

### 4.3 民兵守卫与家庭责任

任何满足成年、身体能力、可用装备与可接受风险的居民都可选择守卫，不以男性、单身或拥有私宅作为唯一资格。守卫家人、保护近邻或履行有预算的公共防务承诺可以形成动机。

常规动员保留家庭必要的采集与照料能力：有依赖成员的家庭，至少保留配置要求的可行动照护人；按家庭事实提供有限的外出守卫名额。多人同拍申请时只能成功占用实际名额，不能都认为“别人会留家”。只有一名劳动力时优先就近护家，不为赏金远赴集结点。直接遭袭的个人自救不受名额阻拦。

民兵围绕具体防护对象集合或拦截，首期采取可读的个人守卫行为，不设指挥官强制编队。等待同伴有时限；没有足够人员则选择近宅防守或撤退。追击不得超出保护区域与任务预算，敌人撤退后不能为了奖励追到地图边缘。

动员只扩大可申请范围、缩短允许的响应等待或增加预算激励，不能越过身体、生理与家庭守卫。参战者受伤、饥渴或明显不敌时可以退出。普通疲劳不得覆盖更迫切的逃生与补水需求。

### 4.4 战斗的代价与结束

攻击需要实际距离、可达接触、武器可用、动作间隔与体力，不靠动画帧持续扣血。装备、力量、当前伤势和局部人数影响结果；投入更多人有协作价值，但接触人数有上限，避免整群叠在一个点瞬间秒杀。

生命力表示可恢复身体损伤，伤势影响移动与劳动；休息和实际营养支持恢复，不能恢复自然寿命。首期轻伤、重伤与死亡足够，永久残疾、完整医疗和复杂招式后置。重伤导致退出普通战斗资格，不自动获得安全传送。

流寇因损失、负伤或目标不可得而溃退；守卫因保护目标已安全而结束任务。首期撤离即可结束冲突，不依赖俘虏与审判系统。无法撤离且仍在接触时危险持续，不能用“撤退状态”获得免伤。

## 5. 公仓兑现与战后恢复

### 5.1 先有支付能力，再形成承诺

每次事件单独记录可用防务预算、已承诺金额、实付与未付。预算来自真实公仓可支配余额，先保护基本公共救济，不允许国库负数或凭空铸币。

支出顺序为必要救济、伤亡家庭援助、有效守卫贡献奖励。援助不要求打赢：败退、局部失守或伤员幸存同样可能需要支持。功劳按本次事件内有效阻止伤害/劫掠、掩护居民脱离危险和成功守住目标记录，按人及事件封顶；最终一击不独占奖励，单纯站岗刷时长或反复接战不能无限刷钱和威望。

预算不足时同级按应付比例分配，舍入余额用稳定规则处理，明确显示应付、实付与差额。首期差额仅作事件记录，不自动变成无限累积债务；没有国王、公仓或合法付款主体时显示“无公共支付”，个人防卫仍成立。黄金划拨可沿用账本支付，食物救济必须真实运输与交付。

### 5.2 战利品与伤亡不重复结算

夺回物资记录来源，能识别货主的部分归还原所有者；搬回前仍是现场或行囊资产，不提前入公仓。流寇自带物资与受害者赃物分开，不能把归还他人存粮算成民兵奖金。

死亡只触发一次既有继承与家户结算；已经继承的行囊不能再生成一份尸体战利品。抚恤确认到合法受益家户或后续监护接收方，不向已解散家户盲目入账。孤儿救济是明确的需求与交付，不等于新增一套自动收养制度。

### 5.3 恢复生产也是结局

事后面板显示物资净损失、房屋损坏、伤亡、治疗/休息占用、劳动力离岗时长和公共支付，帮助玩家判断“守住了，但付出了什么”。人物通过日常需求自行修缮、休养与补货，系统不一键复原库存或把所有人强制送回工作。

下一次入侵需等待恢复门槛，已发生的经济后果持续存在。事件历史保存实际参与者、伤亡与受益者；没有实施的照料、护送、招安不能提前写成故事。

## 6. 玩家可调整什么

| 手段 | 可改变的条件 | 持续成本与限制 |
|---|---|---|
| 哨塔规划 | 视野覆盖与传讯节点 | 占地、材料、维护和自主值守人员；不会自动挡路 |
| 公共武器工坊 | 可制造/领取装备的地点与公共份额 | 实际投入、劳动、耐久与合法领取；不让全营瞬间获得装备 |
| 避难接纳规则 | 可接纳对象、公共供给授权 | 有限容量与实际食物；不驱逐原住家庭 |
| 常备预算与动员范围 | 防务预算上限、就近/辖区守卫范围 | 挤占公共盈余与生产时间；无法强征缺乏能力者 |
| 后续路卡 | 真实通行与防守位置 | 先完成动态道路失效与在途恢复；也可能拖慢居民撤离 |

首期界面以观察与少量公共预算规则为主，建筑规划晚于土地和公共施工授权；没有合法付款主体的政策不可直接扣家庭资金。玩家不能点击人物指定追杀或跨越权限免费建造。

本土犯罪与俘虏治理后置。贫困、无宅或单身本身不自动等同犯罪；未来需记录持续求助失败、救济可达性及实际暴力行为，再讨论落草。处决、拘押或招安的代价、证据和社会后果须另行设计，不保留“处决必涨威望”“苦役是免费生产”的无成本选项。

## 7. 观察与体验验收

| 观察入口 | 必须回答的问题 |
|---|---|
| 人物决策中枢 | 为什么狩猎/守卫/避难？为何放弃、不能参战或选择留家？ |
| 猎场详情 | 存量是否恢复、为何禁止普通出猎、目标与猎物剩余产物在哪里？ |
| 房屋与家户 | 庇护可用名额、进入路线风险、耐久、实际食物与保暖缺口是多少？ |
| 警报与地图 | 最后目击在哪里、多久前、谁已收到信息、是否仅失联？ |
| 公仓与事件卡 | 承诺多少、支付多少、谁获援助、谁的赃物尚未归还？ |
| 族谱与事件历史 | 谁负伤/阵亡、实际死因、关联家户与此役后果是什么？ |

默认地图只突出已确认的关键威胁、正在发生的冲突与选中人物；风险范围、视野与庇护容量作为可开关叠层。不能用高频全量重建破坏点击，也不按每次攻击刷屏。

验收用可构造场景观察因果，不要求某个固定种子永远演出同一故事：

- 浆果可用且出猎更慢时，人物仍能选择采集；家庭补足后不会因为有矛继续猎杀。
- 猎物不可达或逃远时有限退出；尸体被取完或腐败后没有第二份产物。
- 弱小聚落处于保护期时不刷寇；入侵开启时已经有可用避难与防守闭环。
- 多人抢同一避难名额、家庭仅一名照护人、全无可达避难处时，都有可解释的替代选择。
- 流寇退去但未被击杀也可结案；守卫停止远追，受害者损失等于真实转移与消耗。
- 公仓不足、战败、无政体与家户解散时不造钱、不吞掉记录，援助与奖励分开显示。
- 经历危机后，玩家能从一张事件卡追到一个人物和一个家庭，说出其选择及后果。

长程比较关闭模块、仅狩猎、加入小规模入侵三个阶段，分别记录人口与灭绝分布、伤亡原因、食物/燃料、野生种群、出猎收益、离岗时间和公仓支付覆盖率。新增机制必须证明有可读取舍，不能只看“平均人口更高”。测试规模与目标阈值由实现前基线确定。

## 8. 实施切片与暂缓范围

| 切片 | 完整交付边界 | 放行依据 |
|---|---|---|
| H0 身体与物资闭环 | 生命力/轻重伤、肉与皮、腐败、装备、搬运与供暖 | 恢复不改寿命，物资无重复，存读档连续 |
| H1 有限猎鹿 | 一种动物、独立出猎、有限追逐、尸体处理与观察 | 狩猎能停止，生态可恢复，采集仍有价值 |
| D1 最小入侵闭环 | 小规模外寇 + 局部预警 + 逃生/庇护 + 个人守卫 + 撤离结案 | 不依赖国王和高级设施也能应对；无远程扣账 |
| D2 公共庇护 | 家庭名额、预算援助与贡献奖励、哨塔/工坊 | 公共投入形成可观察的保护与成本，危机后能恢复 |
| 后续独立评估 | 猛兽、协同围猎、动态路卡、护送、内生犯罪、俘虏法 | 各自依赖齐备，并另做风险与长期平衡验证 |

每一切片都包含观察与存读档，不把防守安排在入侵之后补齐。本表是建议依赖顺序，排期仍以 [TODO](../../../TODO.md) 为唯一入口。

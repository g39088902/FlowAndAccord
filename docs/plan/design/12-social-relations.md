## 1. 核心诊断：关系尚未进入生产决策

当前世界里除婚育之外的「关系」机制不少（宗族、王国、帝国、拍卖、夺位），但存在一个共同的结构性缺口：

1. **制度性关系是被动的周期结算**：族税、族内互助、公仓税、救济、国王内帑、帝国公帑全部由 world tick 定时扫描划账（`tick_clan` / `tick_region` / `tick_empire`），Agent 既不选择纳税对象，也不选择救济对象。
2. **生产决策的候选集里没有「人」**：决策层（`decisions/`）L2 策略规划的候选对象只有 POI、外部市场、房屋和王位营地；没有任何分支会以「另一个 Agent / 家户 / 宗族」为目标或约束。
3. **婚姻是唯一例外**：成婚合并家户账本（谁的储备、谁去采、为谁备货），所以它能实际改变生产行为。要复制这个效果，就需要让「某个具体的人 / 家户」出现在另一人的候选策略、成本或收益里。

> **设计判据**：一个新关系机制是否「影响生产」，看它是否落进 §6 的五条传导管道之一；一个新关系机制是否「Agent 自治」，看它是否以自包含条件进入决策分支（范本：`B16Courtship` 的「魅力 → 距离 → ID」择偶），而非系统扫描指挥。

## 2. 现状盘点：已有机制中潜藏的关系张力

### 2.1 依赖通道（制度性、被动）

| 机制 | 现状 | 与生产的耦合 |
| :--- | :--- | :--- |
| 宗族互助 MutualAid | 族库 → 极贫家户拨付水粮（超参驱动周期结算） | 弱：只补血，不改变采什么、去哪采 |

| 道路踩踏 `wear_tier_bucket` | 0.50x~2.20x 寻路成本量化 | **强**：目前唯一的「陌生人匿名协作」——别人走的路你走得快，直接改 A* 成本与 APSP 查表 |
| 营地行政升级 | 辖内房屋数驱动营地 → 村 → 乡 → 镇 → 县 | 弱公共品：人人建房全员受益，但无人感知因果 |
| M19.4c 禀赋个性化 | 力量调装载速率、智力权衡路途 vs 牌价、豪绅户主市场代采 | 分工雏形，但仍指向外部市场，不指向人 |

| 机制 | 现状 | 与生产的耦合 |
| :--- | :--- | :--- |

### 2.3 关键事实

- POI 再生是**固定基准速率向储量上限恢复**（倍率仅由玩家生态大盘调节），**开采行为不损伤再生能力**（见 [02-ecology-poi](../../current/tech/21-ecology-and-poi.md)）——公地悲剧目前只有「存量被分」这一半，没有「资源被毁」那一半。
- 衰弱者（v1.47）饮食优先在家解决、依赖家户账本，但继承份额与赡养投入完全无关（自动平分）。
- [23 记忆](../tech/21-memory-system.md)的 `MemoryFact.subject` 已预留 `Group`（家户/宗族/地区）主体——面向「人群」的恩怨记忆有现成挂点。

## 3. 依赖关系方向（让生产互相咬合）

> 编号 A1~A3 为已有专项的「关系 × 生产」索引；A4~A6 为本文新增提议。

### A1. 内部市场（权威：24）

濒危家庭用木石金换水粮、富余家庭卖余粮换建材。由**售货员真人中介**在集市场地主持买卖订单簿撮合：各族挂出卖单/买单，售货员按价格优先/时间优先匹配成交，收取少量佣金。黄金留在居民间流转（卖家到手、售货员抽佣），不是外部 Void。**关系本质**：邻居的余粮成为你的救命资源，别人的断流成为你的销售机会。与好感度系统接通后，好友挂单在撮合中顺序优先、享受信任折扣；怨怼以上售货员拒绝撮合（生意不成仁义在）。**生产影响**：打破「每家自采五种资源」的全能模式；与 M19.4c 禀赋个性化接通后，比较优势分工自然涌现（高智力家户专职换购、高力量家户专职重采集）。传导管道：③ 分工与交换效率、④ 风险缓冲。

### A2. 熟人互惠与求助（权威：20 方向④）

缺粮时优先向熟人求助、赠予需真实搬运、长期单方索取则关系疏远。**关系本质**：「人情」成为可消耗、需维护的生存资源。**生产影响**：有可靠熟人网络的家户可调低备货阈值（与 23 记忆 M10「获得救济」的抵消机制同构），改变出行频率与行囊规划。传导管道：④ 风险缓冲。

### A3. 技能传承 / 师徒（权威：20 方向⑤ + 23 P3 家庭传承）

老人授艺、共同劳动传授。**关系本质**：别人的技能成为你的生产率。**生产影响**：直接改劳动效率——装载速率（M19.4c 力量钩子）、未来的加工/农业劳动系数均可作为传授受体。传导管道：③ 分工效率。

### A4. 农田换工与帮工（★ 新提议；权威底座：17）

17 已要求农田产出必须来自**真实到场劳动**（`labor_progress`），农忙季的劳动力缺口是天然的互助场景，但当前设计中**他人无法为我的田贡献劳动**。提议：

- **换工契约**：劳动力富余的家户成员可自主决策赴他人农田劳作，劳动进度计入田主批次，按约定比例分成（分成走 `transfer()` 双向流水 + 真实搬运交付，禁止远程划粮的镜像复制）；
- **触发条件自包含**：候选 = 血缘宗族内 / 熟人关系网络内 / 酬劳足够；田主无壮丁（孤寡、多幼儿）时优先级提升，形成「儿子多的家庭 ↔ 有田无劳力的家庭」的真实劳动力依赖；
- **前置**：17 农田 M2（自主生产闭环）落地后叠加；关系网络依赖 A2 或 23 的 Group 记忆。

传导管道：① 劳动时间再分配、③ 分工效率。

### A5. 生产资料共享（★ 新提议；衔接 18 的 `weapon_tier` 先例）

18 已引入装备等级（0 空手 ~ 3 猎弓）概念，可平移到生产资料：更好的斧头/箩筐/驮兽提升对应采集的装载速率或容量。提议：

- **工具耐久 + 借出**：工具可借给指定对象（真实交付），借与还构成信用关系；逾期不还或工具损毁产生敌对记忆（挂 23 的 `subject: Agent/Group`）；
- **生产影响**：贫穷但有人情的家户可以「借工具」替代「攒钱买」，富户通过出借收取实物利息（走 A1 内部市场或 A4 分成通道）；
- **红线**：工具是资产不是库存，须进快照四处同步链与存档；不得绕过家户账本另建储备真相源。

传导管道：③ 分工效率、② 资源获取权（间接）。

### A6. 赡养与继承预期挂钩（★ 新提议）

现状：衰弱者在家饮食消耗家户账本，但继承是自动平分，赡养投入不影响份额——「谁养老人」没有博弈空间。提议：

- **赡养投入记入继承权重**：对衰弱/伤病成员的照料时间与资源投入（复用 20 的照料占用记录）折算为继承分配的加权因子，替代纯人头平分；
- **关系本质**：老人持有的房产与升级投资（老人出建材）↔ 衰弱期照护（子女出时间）形成显性双向交换；不照料者份额流向照料者，代际依赖从背景行为变成可观察的家内契约；
- **风险**：改变继承权重是行为级改动，须同版本确定性长程实验（对照旧平分规则），并防止「临终抢照料」的策略性挤兑（照料须有持续性门槛，如按累计时长而非最后一刻）。

传导管道：① 劳动时间、⑤ 激励结构（继承预期）。

## 4. 敌对关系方向（谨慎引入，烈度递增）

> [18](../tech/24-hunting-defense.md) 已论证总原则：**直接内战会过早击穿微型社会的繁衍链条，应「外敌先行、内斗后置」，且优先用经济手段表达敌意**。编号 B1 为已有专项索引；B2~B6 为本文新增提议。

### B1. 流寇劫掠（权威：18，TODO 在办）

外部游寇劫道（抢运粮行囊）、围攻偏僻私宅（扣家户储备）、直扑公仓；Phase 4 本土流民堕落（极贫破产者黑化落草）。**最符合项目「制度实验」定位的涌现路径**：公仓救济没接住的人回头劫掠公仓——「制度失败产生敌对」的显性闭环。生产影响三重：直接剥夺生产成果、防御占用劳动时间、路网风险改变选路。传导管道：② 资源获取权、① 劳动时间、⑤ 激励结构（赏金/威望）。

### B2. 公地悲剧显性化（★ 新提议，成本低）

现状再生与开采行为解耦（§2.3）。提议：

- **生态损伤**：POI 储量长期低于阈值或单位时间开采量超过再生速率的持续期，压低该 POI 的再生能力或储量上限（有界、可缓慢恢复）；林木可叠加「幼林期」概念（砍秃后恢复更慢）；
- **关系效果**：同营地居民间产生「你把泉采干了」的真实冲突——不必有显式攻击行为，敌对通过资源稀缺、迁徙决策与 22 的共享资源池契约（多岸点引用同一水体系）自然表达；
- **前置**：与 [22 地形](../tech/25-terrain-templates.md)的「共享取水语义」合流设计；损伤判定不得消费额外 RNG，按确定性物理规则推进。

传导管道：② 资源获取权、④ 风险缓冲（备货阈值被迫上调）。

### B3. 水权与地界纠纷（★ 新提议；前置 17 + 22 T2）

17 已留伏笔（「未来真实灌溉须另接共享水池预算」）。提议：共享水池取水配额、上游截流影响下游灌溉产出、农田相邻地界的采光/通路争执。旱季争水是最前现代的生产冲突形态，且完全可用「配额结算 + 优先级序（稳定 ID 破平）」的确定性方式表达，无需战斗判定。传导管道：② 资源获取权。

### B4. 税政对抗与民意（方向已见于 [11-plan M15](./10-roadmap.md)；本文补充生产侧接入）

现状多层抽取叠加（17 落地后农业双税并存），被抽者无表达渠道。提议按烈度分档：

1. **用脚投票**：重税辖区的家户在立宅/迁籍决策中加入税负因子（自包含条件，不改既有分支守卫的语义）；
2. **抗税拒缴**：税负超过可支配余额保护线时按稳定 ID 顺序部分拒缴（新增 `TransferReason` 变体 + 流水留痕），触发国王威望/民意惩罚；
3. **废黜政变**：接入 M15 的政治资本六维（民意维度），国王下台/复仇/重新夺位路径。

生产影响极直接：税率改可支配余额，进而改备货、升级与农田投资决策。传导管道：⑤ 激励结构、② 资源获取权（间接）。

### B5. 宗族世仇（★ 新提议；复用 23 的 `Group` 主体）

绝嗣承继（族产被他族平分 `Legacy`）、拍卖抬价竞争（b17 输家对赢家）、夺位失败、争水冲突均可编码为面向 Group 的恩怨记忆（23 的 `MemoryFact.subject: Group` 已预留）。**关系效果**：世仇宗族间——内部市场对手价上浮、拒绝换工/借工具（A4/A5 的守卫条件读取恩怨记忆）、优先抢占同一 POI。**敌对通过经济而非战斗表达**，烈度可控。传导管道：③ 交换效率（负向）、④ 风险缓冲（负向）。

### B6. 偷窃与侵占（★ 新提议；18 Phase 4 的轻量前置）

无家者目前「现场自用不装袋」；绝望阈值（极贫 + 长期无救济接住）下可黑化为入室盗窃：真实潜行移动至目标私宅、按速率偷取家户账本实物装入行囊（全程真实搬运，账本走 `transfer()` 流水）。**闭环设计**：

- 抓获判定（在宅成员目击）→ 威望惩罚 / 宗族除名（18 已有「遭宗族除名的亡命之徒」设定）→ 除名者失去互助资格 → 进一步绝望 → 落草为寇（衔接 B1 Phase 4）；
- 这给「敌对」提供了从轻到重的完整光谱：偷窃 → 除名 → 劫掠，每一级的恶化都有制度原因可追溯。

传导管道：② 资源获取权（双向剥夺）、④ 风险缓冲（在宅看守与出行决策）。

## 6. 影响生产的五条传导管道

任何关系机制须至少落进一条管道，设计时先明确走哪条：

| # | 管道 | 机制示例 |
| :--- | :--- | :--- |
| ① | 劳动时间再分配 | 防御动员、照料赡养、帮工换工、赴市交易——与采集直接竞争体力与决策节拍 |
| ② | 资源获取权 | 水权地权、被劫被偷、公地损毁、封禁排他 |
| ③ | 分工与交换效率 | 内部市场、工具共享、技能传承（正和）；世仇拒交易（负向） |
| ④ | 风险缓冲 | 互助救济、熟人网络、信用——改变备货阈值与出行规划（即施密特触发器的有效带宽） |
| ⑤ | 激励结构 | 税率、赏金、威望、继承预期——改变可支配余额的边际用途 |

婚育只覆盖 ③④；§3/§4 各方向补全后，「关系 × 生产」在五条管道上均有表达。

## 7. 落地优先级与依赖

结合 [25 融合设计](../tech/20-integration-contracts.md)的依赖顺序（家庭预约 / 统一 L2 选策先行）与 TODO 现状：

1. **内部市场 P0/P1**（A1）——设计稿最完整，全部复用现有底座（家户账本、ActiveTask、真实搬运、TransferReason）；
2. **熟人求助赠予**（A2）+ **23 记忆 P0 事实先行**——关系数据先记录、行为效果后开启，并为 A4/B5 预铺关系网络；
3. **流寇 Phase 1~2**（B1）——外敌压力先行，公仓赏金/抚恤直接激活「税赋换安全」契约叙事；
4. **农田 M2 自主生产闭环** → 叠加**换工帮工**（A4）；
5. **公地悲剧 / 水权**（B2/B3）——等 22 T0 地表查询与 T2 河谷契约；
6. 远期：税政对抗（B4，接 M15）、宗族世仇（B5，接 23 P2）、赡养继承（A6）、工具共享（A5）、偷窃黑化（B6，接 18 Phase 4）。

## 8. 设计红线（全方向通用）

1. **Agent 自治**：一切关系驱动的「去哪里 / 做什么 / 与谁交易」必须以自包含条件进入决策分支（范本：`B16Courtship` 择偶序），严禁系统扫描强制派工、强制敌对或改写 `agent.state`（根 AGENTS.md §4.11.1）。
2. **确定性**：关系状态（好感/恩怨/契约/信用）随档持久化，新随机消耗一律走共享 `WorldRng`；换世界时关系缓存按既有跨世界失效判据清空。
3. **家户账本唯一真相源**：一切赠予、分成、赡养、偷窃必须走**真实搬运** + `transfer()` 双向流水；不得出现第二份库存或远程凭空调拨（周期税收是文档明示的唯一例外）。
4. **敌对烈度受控**：先外敌后内斗；内源性敌对优先用经济手段表达（世仇加价、拒售、拒换工、拒借），战斗判定是最后手段；任一敌对机制的引入都须以「不击穿繁衍链条」的长程存活实验为验收。
5. **快照四处同步**：关系网络、恩怨记忆、契约占用等新增状态遵循根 AGENTS.md §4.5 的 FABS 全链（`snapshot.rs` → `world_snapshot.rs` → `snapshot_bin/encode.rs` → `snapshot-bin.js` + `rustworld.js`）。
6. **融合设计接入**：涉及家庭可支配余额的新机制（A4 分成、A6 赡养、B4 抗税）须接入 25 的家庭保护线与预约契约，不自建第二套仲裁器。

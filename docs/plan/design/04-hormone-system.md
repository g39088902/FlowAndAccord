## 1. 设计目标与世界观定位

### 1.1 为什么引入激素

1. **行为的时间维多样性**：当前 Agent 的行为由「生理指标 + 配置阈值 + 记忆」决定，同一个人在相同处境下的反应是稳定的。激素引入**连续变化的内部化学基调**，使行为带有周期、余韵与后遗症——「他自从丧偶后像是变了个人」「入冬后全村都蔫了」「那孩子淘金淘疯了」从叙事变成机制。
2. **压力的生理代价**：18 号规划引入了外敌与战斗，但没有「长期处于威胁之下」的慢性成本。皮质醇把「战乱 / 重税 / 极贫 / 丧亲」转化为健康折损、记忆衰退与生育抑制——制度失败第一次能在**身体上**留下痕迹（呼应 [03 号](./03-social-relations.md) B4 税政压迫、B1 流寇）。
3. **关系的生理载体**：[03 号](./03-social-relations.md)诊断出「生产决策候选集里没有人的变量」。催产素是信任与联结的化学基础——婚姻共处、育儿照料、并肩御敌、赠予往来改变催产素水平，进而改变交易对象偏好、协作意愿与关系维持，使依赖关系不必依赖硬编码规则即可涌现。
4. **劳动与奖赏的真实动力学**：多巴胺阈值漂移天然表达「干劲」的起落与成瘾倾向（淘金 = 天然的变率强化赌博），内啡肽表达「冲刺—崩解」的劳动节律，避免所有 Agent 永远以同一效率工作的机械感。
5. **性别、生命周期与代谢的生理结构**：生殖轴（雄 / 雌 / 孕）给求偶竞争、受孕窗口、妊娠安稳、产后脆弱与更年期以连续的生理表达；甲状腺素作为基础代谢率总闸门，创造「快代谢—慢代谢」的个体能量策略差异与饥荒期的自适应节流——荒年谁活得下来，从此有了生理答案。

### 1.2 三层架构定位

```text
┌────────────────────────────────────────────────┐
│  决策层：马斯洛分支 b1~b18（唯一任务分派入口）   │  ← 激素只调制，不替代
├────────────────────────────────────────────────┤
│  ★ 调制层：四轴十一激素化学基调（本方案）         │  ← 阈值/成本/层级/生理速率的连续调制
├────────────────────────────────────────────────┤
│  生理层：饥渴 / 体力 / 健康(寿命) / vitality      │  ← 激素的源与汇
└────────────────────────────────────────────────┘
```

### 1.3 三大红线（不可逾越）

1. **调制不指挥**：激素严禁直接写 `agent.state`、派发任务或触发状态切换；一切影响必须以「分支自包含条件内的阈值 / 成本 / 速率调制」表达（根 AGENTS.md §4.11.1）。**临界求生守卫绝对性**：b1/b2 级饥渴自救不受任何激素压制——消沉的 Agent 可以躺平不升级、不积累财富，但绝不被动饿死。
2. **确定性**：首期激素动力学为**纯确定性函数**（事件脉冲 + 线性衰减 + 钳制；女性周期相位由出生 / 到达 tick 派生），不消耗 `WorldRng`；同种子逐字节一致是硬门槛。
   > **【已校订 v1.50.32】唯一例外——气质遗传（§3.3 第 3 维）必然改变 RNG 消费序列**。既有禀赋遗传在 `spatial/birth.rs:122-133` 用一个 `inherit` 闭包**逐性状消耗一次** `rng.gen_range(-delta, delta)`（当前 6 项：intelligence / strength / digestion_efficiency / libido / sleep_efficiency / life_expectancy）。追加 5 维气质后，若复用该闭包则消费序列变为 11 项——**这会改变 RNG 序列、使旧存档的后续模拟不可复现**，与本条红线直接冲突。
   > **因此气质遗传不得按"纯确定性、不消耗 RNG"描述**。已定方案：气质**复用既有 `inherit` 闭包并追加在 6 项之后**（消费顺序固定 6→11，写入 `birth.rs` 注释），同时**必须**① 重跑 `test-determinism` 与旧基线比对；② changelog 显式记录「本版本起 RNG 消费序列变更，旧存档模拟结果不可复现」；③ 评估 `SAVE_FORMAT_VERSION` 7→8 以阻断旧档静默偏差。**备选方案**（仅在不愿动 RNG 时采用）：气质纯父母均值派生、无变异，代价是**代际无遗传漂变**，「家族气质谱系」涌现效果大幅削弱。二者取舍见 §3.3。
3. **单一真相源**：激素不建第二份「健康 / 关系 / 储备」——它只调制既有系统的读数与阈值；效果总开关关闭时，行为与 RNG 消费与旧版**逐字节等价**（纪律同 23 记忆 P0）。

## 3. 数据模型与动力学

### 3.1 定长结构（零堆分配先例：`harvest_queue`）

```text
AgentHormones {
    dopamine: f32,            // 当下动力水平
    dopamine_threshold: f32,  // ★ 奖赏阈值（漂移实现"成瘾/空虚"，独立慢衰减）
    serotonin: f32,
    endorphin: f32,
    oxytocin: f32,
    cortisol: f32,
    adrenaline: f32,
    norepinephrine: f32,
    androgen: f32,            // 生殖轴：男性调制域，女性低水平恒定
    estrogen: f32,            // 生殖轴：女性周期 / 生命周期曲线
    progesterone: f32,        // 生殖轴：孕期抬升、产后崩落
    thyroxine: f32,           // 代谢轴：基础代谢率乘子之源
    // 慢性累计器（cortisol 慢性判定用，含衰减锚点 tick）
    chronic_stress: f32,
    // 事件余韵窗口（内啡肽崩解 / 肾上腺素事后疲劳 / 产后情绪脆弱，各为 tick 计数）
    crash_timers: [u32; 3],
}
```

### 3.2 更新模型（每 tick，代谢阶段末尾）

```text
level' = clamp( level + Σ pulses(events_this_tick) − decay_rate × dt × (level − baseline), 0, 100 )
```

- **脉冲**：世界结算事实驱动（完成装满行囊、成交、登基、丧偶、遇袭、受孕、分娩……），脉冲量 = 事件基础量 × 反应度，全部确定性；
- **衰减**：向基线的线性回归，各激素独立速率（肾上腺素秒级、内啡肽分钟级、多巴胺小时级、阈值以「游戏日」级慢衰减；生殖轴基线随性别 / 年龄 / 孕程走**慢曲线**而非固定值）；
- **挂载点**：`tick_phase_metabolism_and_child` 末尾（遗物归户 2.5 先例之后），决策阶段读取当拍更新后的数值。
  > **【已校订 v1.50.32】脉冲注入时序需分两类，不能一律等到阶段末尾**。该函数（`world_tick.rs:161-206`）内部实际顺序为「代谢循环 → **`execute_pending_childcare()` 受孕结算**（`:198`）→ 2.3 胎儿建号 → 遗物归户」。**受孕 / 分娩 / 成婚 / 登基等最关键的生殖轴与重大事件脉冲源发生在阶段中段**，若一律等到末尾统一结算，当拍受孕产生的 PROG 脉冲会延迟一拍生效（分娩同理）。
  > **定案**：① **即时脉冲**（受孕 / 分娩 / 成婚 / 登基）在事件执行点内立即注入；② **常规脉冲**（卸货装满、自食、休整、团聚、丰收等）在阶段末尾统一结算。二者共用同一注入函数，避免双写。

### 3.3 基线构成：性别、年龄与气质禀赋

基线不是常数，由三个确定性维度合成：

1. **性别二态（生殖轴专属）**：雄激素基线仅男性入调制域；雌激素 / 孕激素基线由女性年龄曲线定义（青春期抬升 → 育龄平台 → 更年期衰减）；女性雄激素与男性雌孕激素保持低水平**不入调制域**，避免为无对应机制的性别引入噪声。
2. **年龄曲线**：雄激素随高龄缓慢下滑（少壮好胜 → 老来恋家）；女性生育年龄窗与雌激素衰减对齐（§4.9）。
3. **气质禀赋（可遗传，复用 [10 先天禀赋](../../current/tech/10-agent-life-cycle.md)的遗传混合规则）**：
   - `多巴胺反应度`（奖赏敏感）、`皮质醇易感性`（压力脆性）、`催产素依恋倾向`（联结敏感）、`血清素稳定性`（情绪基线漂移幅度）；
   - ★ `代谢气质`（甲状腺素基线漂移）：天生快代谢（劳动快、恢复快，但饥渴消耗高、冬季供暖需求高）↔ 慢代谢（省粮耐饥，但迟缓恢复慢）——**一个维度创造人口的能量策略多样性**，荒年慢代谢家族更易存活、丰年快代谢家族扩张更快；
   - 生殖轴基线由性别 / 年龄定义，**不设气质维度**（避免把生育力做成可育种属性）。
   - **【已校订 v1.50.32】遗传的 RNG 代价必须预先定案**（原稿未提，导致与 §1.3 红线 2 冲突）：见 §1.3 红线 2 的校订注。**默认方案**＝复用 `birth.rs` 既有 `inherit` 闭包、追加在既有 6 项之后（消费序列 6→11），**接受基线变更**并履行三项配套（基线比对 / changelog 声明 / 评估存档版本号 +1）。**备选**＝纯均值派生无变异（不动 RNG，但代际无漂变）。本稿**推荐默认方案**，因为「家族气质谱系」的涌现正是本维度的核心价值（见下段），无变异则谱系无法形成。

效果：家族几代选择性婚配 + 遗传 → 「工作狂家族」「将门虎子（低皮质醇易感）」「商贾世家（高催产素信任网络）」「荒年饿不死的慢代谢宗族」的**气质谱系**涌现，与既有力量 / 智力 / 魅力禀赋并列进入择偶与叙事。

### 3.4 耦合矩阵（激素间相互作用）

| 耦合 | 方向 | 生理依据 → 机制表达 |
| :--- | :--- | :--- |
| 皮质醇 → 血清素 | 抑制 | 慢性压力侵蚀情绪 → `chronic_stress` 高位时血清素基线临时下调 |

## 4. 逐激素机制详设

### 4.1 多巴胺 DA —— 动力、奖赏与阈值漂移（双刃剑）

- **奖赏事件**（装满行囊卸货、升级竣工、拍卖竞得、登基、成婚、分娩、市场大额成交）→ `dopamine += pulse`；连续小幅奖赏（现场自食、小额成交）→ 小脉冲。
- **有效驱动力**：`drive = clamp(dopamine / dopamine_threshold, 下限, 上限)`，映射为劳动启动门槛与连续作业意愿的调制乘子（§5 钳制）。
- **★ 阈值漂移（成瘾 / 空虚）**：每次奖赏使 `dopamine_threshold += 脉冲 × 漂移系数`，阈值以游戏日级慢速率回落至基线。**变率强化**天然存在：金矿储量起伏使淘金收获方差大 → 大额多巴胺脉冲 → 阈值快速抬高 → 普通劳动的固定小奖赏相对贬值 → 涌现「醉心淘金、厌恶农桑」的人格（与 b13 积累财富的 4 级庄园纪律守卫不冲突——人格只调制意愿，不绕过分支门槛）。
- **空虚态**：`raw_drive` 低于独立消沉阈值持续累计低谷时长 → 高阶分支（b8 高阶升级 / b13 积累财富）进入**有界意愿等待**（乘子低于放行阈值且低谷未达窗口时推迟，窗口耗尽后无条件放行）；不阻断 b1~b5 生存链路。【已校订 v1.50.63 · H-08 落地】b8/b13 并无可乘的「阈值」字段，原稿「阈值上浮」表述作废；实际载体 = 意愿通道有界等待（`will_multiplier` 钳制 [0.75,1.35] + `da_low_streak` 窗口），消沉判定用 raw_drive 与独立阈值，禁用钳制值判断；Inspector「消沉」标签待后续版本随观察块扩展接入。
- **恢复**：阈值自然衰减 + 作息休整（接 20③ 作息后可加「深度休整重置」）。

### 4.2 血清素 5-HT —— 情绪基调、地位与季节

- **来源**：休整至满体力、长期饱食良好、威望增益（`prestige` 映射基线上浮——地位即情绪，接 [03 号](./03-social-relations.md) §5 威望社会化）、在宅团聚（与 OT 正耦合）、雌激素敏感度加成（女性，§3.4）。
- **★ 季节性情感（SAD）**：冬季（气温 / 光照档位，接 [15 四季](../../current/tech/15-seasons-climate.md)）血清素基线临时 − 配置百分比——**冬天不只是烧柴问题，全村情绪低落、动工意愿下降、易怒冲突升温**，给冬季注入区别于供暖的第二重生存质感。
- **低谷效应**：高阶需求（改善住宅 / 积累财富 / 立宅升级）阈值上浮（兴趣缺失）；熔断耐受下降（挫折 → 更早折返）；与高皮质醇叠加进入「消沉」。
- **边界（对 23）**：M01/M02 挨饿记忆是**情节经验**（一次饥荒，长期改变备货阈值），血清素是**当下基调**（这周状态不好）；两者通过不同通道叠加，共用同一钳制上限，不重复计权。

### 4.3 内啡肽 EP —— 劳动冲刺、跑者高潮与过劳崩解

- **来源**：持续重体力作业（连续采矿 / 伐木 / 采石满 N 游戏小时）、长途跋涉（远征 / 远途交易中徒步时长达标 → 「跑者高潮」移速与体力消耗减免）、狩猎搏斗、欢庆事件（婚礼 / 登基礼花）。
- **效应**：体力消耗与伤势移速惩罚临时减免（钳制）；**只掩盖不治疗**——伤势与疲劳照常积累（对 18 的 vitality / injury 只做感知掩盖，不改实际数值）。
- **★ 崩解窗口**：峰值回落后触发 `crash_timers`——体力恢复速率减半的疲偿期，涌现「连干三天 → 倒头睡两天」的劳动节律；盲目依赖内啡肽硬撑的 Agent 更早进入过劳循环。
- **生产耦合**：[03 号](./03-social-relations.md)管道①（劳动时间再分配）的生理表达——冲刺能力改变单趟采收 / 农忙抢收（17 农田 labor_progress）的时间结构。

### 4.4 催产素 OT —— 信任、联结与悲恸（[03 号](./03-social-relations.md)的生理通道）

- **来源**：与配偶在宅共处（门节点同场休整）、育儿照料互动（接 20① 照料占用）、并肩民兵 / 换工帮工（接 18 / 03 号 A4）、赠予与受赠往来（接 20④ / 03 号 A2）。
- **效应**：
  - **信任折扣**：内部市场（24）候选对手方若为高 OT 联结对象（首期：家户 / 宗族成员，关系网络落地后细化到人），交易成本估计 × 信任系数（钳制）；世仇（[03 号 §4.5 B5 宗族世仇](./03-social-relations.md)）反向加价——**OT 与恩怨记忆构成交易偏好的正负两极**；
  - **协作与赠予意愿**：换工 / 借工具 / 熟人求助分支的条件阈值下调；
  - **应激缓冲**：§3.4 耦合——有家可归、有人可依的 Agent 皮质醇反应更小，家庭即韧性；
  - **关系维持**：OT 低位的共处关系衰减更快（20④「长期单方索取使关系疏远」的量化载体）。
- **悲恸**：丧偶 / 丧子事件 → OT / 5-HT 大额崩落 + CORT 大额脉冲 → 数游戏日的「悲恸」标签（劳动驱动力下调、协作意愿下调），与既有丧偶封账 / 产后休养冷却并行不冲突。
- **首期边界**：OT 为**单 Agent 全局水平**（来源全部为家庭内事实）；「按人 / 按对的联结强度」延迟到 [03 号 §3.2 A2 熟人互惠](./03-social-relations.md)落地后再分化，避免提前建全人口两两矩阵（23 号同款性能纪律）。**【已校订 v1.50.32】A2 当前尚未落地**（在 03 号 §7 优先级中列第 2 位），故该分化属**未排期**增强，不作为 P3 收口的前置条件。

### 4.5 皮质醇 CORT —— 危机聚焦与慢性折寿

- **急性脉冲**：断流危机、饥渴警戒、流寇警报 / 遭袭（18）、目击偷窃（[03 号 §4.6 B6 偷窃与侵占](./03-social-relations.md)）、房屋坍塌、丧亲、重税征收日（[03 号 §4.4 B4 税政对抗](./03-social-relations.md) 高税率辖区的脉冲放大）。
- **急性效应（危机聚焦）**：高 CORT 经 H-08 **同一意愿通道**在钳制前线性减入（归一化皮质醇 × 压制强度），乘子跌破放行阈值时高阶分支（b8 高阶升级 / b13）进入有界等待——**压力让人只顾眼前**，与马斯洛「低层级绝对优先」同向但机制独立（调制而非重排）；不改升级扣账成本、不提高 `all_stocked` 判据、不绕过 `family_stock_on` 施密特触发器（b8 Tier0→Tier1 安居豁免）【已校订 v1.50.63 · H-09 落地，原「阈值临时大幅上浮」表述作废，成本/储备门槛上调方案因可能超出仓储目标且无补货分支响应造成永久卡死而否决】；体力动员（消耗减免小窗口，代价为事后疲劳）延期到 H-11 速率管道内接入，P1 不提前创建第二条速率路径。
- **★ 慢性代价**（`chronic_stress` 累计器越过阈值并持续）：
  1. **健康折损**：`health` 衰减速率上浮——**长期战乱 / 苛税真的会折寿**（税政压迫第一次有了生理证据链，接 [03 号 §4.4 B4 税政对抗](./03-social-relations.md) 与 11-plan M15 民意）；
  2. **记忆衰退**：23 号记忆衰减速率 × 慢性系数（海马体萎缩的机制映射）；
  3. **禁孕**：慢性高位时禁孕（应激性不孕，生物学准确）——被反复劫掠的营地出生率自然崩落，无需脚本；
  4. **雄激素压制**：经 §3.4 耦合下调求偶与竞争意愿——与禁孕构成「乱世生育崩落」的双重通道（钳制与总量上限见 §9）；
  5. **消沉级联**：经耦合拖低血清素。
- **解除**：危机源消失 + 衰减；OT 缓冲与公仓救济（接住极贫）都是慢性压力的制度解药——**救济制度的价值第一次可以被身体计量**。

### 4.6 肾上腺素 ADR —— 战斗或逃跑

### 4.8 雄激素 AND —— 竞争、求偶与力量（生殖轴 · 男性调制域）

- **基线曲线**：男性成年即高基线，随高龄缓慢下滑；女性保持低水平、不入调制域（§3.3）。
- **脉冲**：
  - **Winner effect**：竞争获胜（拍卖竞得 b17、登基 b14、战斗获胜、狩猎成功）→ AND 脉冲（与 DA 双脉冲，§3.4）→ 更敢再战；**Loser effect**：竞拍落败 / 远征放弃 → 小幅下调；
  - **Pair-bonding**：成婚 / 育儿共处期基线温和下调——「成家的男人更稳健、更少冒险」的生理表达；
  - **应激压制**：慢性皮质醇经 HPG 轴抑制（§3.4）。
- **效应**（全部走 §5 钳制调制）：
  1. **重体力劳动**：装载 / 采收速率乘子——与力量禀赋（M19.4c）、DA 驱动力**三通道独立叠加、共用全局钳制**；

  3. **竞争胃口**：b14 夺位远征意愿、b17 拍卖出价激进度、b20 狩猎猛兽倾向（18）；

### 4.10 孕激素 PROG —— 妊娠维持与孕期安稳（生殖轴）

- **来源曲线**：受孕后大幅抬升并维持全程；分娩 / 流产后崩落；哺乳期缓降。
- **效应**：
  1. **妊娠维持**：孕激素水平与应激 / 营养共同构成**流产风险因子**——孕期遭遇高皮质醇急脉冲（流寇袭击 / 丧亲）或极贫失守 → 风险累积，与既有流产规则合流（确定性阈值累积，不新增随机掷骰）；「战乱中孕妇流产」从叙事变为机制；
  2. **孕期镇静**：冒险类候选成本上浮、应激反应钝化（§3.4 拮抗）——孕妇少冒险的生理性安胎，配合 B18 在宅受孕与产后休养链路；
  3. **产后延续**：哺乳期孕激素缓降 + 崩落计时器 → 产后情绪脆弱与休养需求的连续表达。
- **钳制纪律**：孕激素失守与皮质醇禁孕（§4.5）是生育抑制的两条通道，共享**全局生育抑制总量上限**（§9 风险 5），防止战乱营地出生率被多重机制压至零。

### 4.11 甲状腺素 THY —— 基础代谢总闸门（代谢轴）

- **定位**：基础代谢率（BMR）乘子之源，全局调制**所有速率类生理量**：饥渴消耗速率、体力消耗与恢复速率、（微弱的）健康衰减速率——全部经 §5 ④ 的单点合成管道生效，**严禁各处散落乘**。
- **★ 禀赋代谢气质（可遗传）**：天生快代谢 ↔ 慢代谢的连续谱（§3.3）——
  - 快代谢：劳动速率↑、体力恢复↑，但饥渴消耗↑、冬季供暖需求↑；
  - 慢代谢：省粮耐饥、低温耐受，但行动迟缓、恢复慢；
  - **涌现动力学**：丰年快代谢家族扩张更快，荒年慢代谢家族存活率更高——能量策略的代际摆动，与 03 四季、17 农业的长程波动形成选择性压力。
- **★ 营养自适应节流（饥荒代谢）**：长期营养不良或长期供暖不足（家户粮 / 木低于生存线持续 N 游戏日）→ THY 下调 → 全消耗 × 节流系数（钳制下限）——大饥荒的群体动力学从「硬扛」变成「自适应节流后仍可能不够」；节流的代价：迟钝（劳动速率↓）、恢复慢、儿童发育迟缓（接 20⑤ 成长校准后启用）。
- **慢性耦合（P3+ 远期）**：长期应激 → 甲状腺亢进（消耗增大，「焦虑性消瘦」）；冬季低温与供暖不足的节流判定与 [15](../../current/tech/15-seasons-climate.md) 的供暖消耗共享同一有效供暖需求读数（25 §5 的「同一物资同一事实」纪律）。

## 9. 验收与风险

- **确定性**：全链不消耗 `WorldRng`（女性周期相位由 tick 派生）；同种子连续 / 分批 / 存读档 / 换世界逐字节一致；效果开关关闭 = 旧版行为逐字节等价。
  > **【已校订 v1.50.32】唯一例外**：**气质禀赋遗传（§3.3 第 3 维）会改变 RNG 消费序列**（`birth.rs` 既有 6 项 → 追加气质后 11 项），与本条「全链不消耗 WorldRng」冲突。这是**无法回避的设计二难**——无变异则无家族气质谱系，有变异则动 RNG。定案与配套措施见 §1.3 红线 2 与 §3.3 的校订注（默认：复用 `inherit` 闭包追加，接受基线变更 + changelog 声明 + 评估存档版本号 +1）。**除气质遗传外，激素动力学全链零 RNG。**
- **长程对照实验**：≥30 种子 × {无激素 / 只读 / 全量} 三组，观察人口与灭绝、家族存续、劳动时间分配、财富集中度、**婚配率与出生率（生殖轴专项）**、**饥荒存活结构（代谢气质专项）**、冬季行为差异；灭绝样本单列（纪律同 23 §8.6.8）。
- **性能预算**：更新为 O(agents) 定长运算、零堆分配；配对相对基线决策与内核耗时增长 ≤5%（`profile-benchmark.js`）。
- **重点风险与对策**：
  1. **消沉死锁**（低 DA + 低 5-HT 躺平至死）——求生守卫绝对性 + 调制钳制 + 基线回归保证自然恢复；消沉只降低生活品质，不阻断生存链路；
  2. **成瘾人口停滞**（淘金热掏空农业人口）——阈值慢衰减 + 变率强化的方差受金矿储量上限约束；长程实验专门观察职业结构是否单调坍缩；
  3. **调制叠加爆炸**（激素 × 记忆 × 禀赋三层乘子）——所有调制共用全局钳制上限，分层分通道各记来源（UI 展示修正分解，纪律同 23 的 MemoryEffects 来源标注）；
  4. **与 23 边界混淆**——记忆 = 情节经验（长期、事件性），激素 = 当下基调（短期、连续）；文档与代码注释双向声明，验收用例包含「同一记忆不同基调」「同一基调不同记忆」的行为区分；
  5. **★ 生殖轴人口动力学塌方**——皮质醇禁孕（§4.5）、雄激素求偶压制（§4.8）、孕激素流产因子（§4.10）三通道同时压制婚育，战乱营地出生率可能被压至零——各通道独立钳制 + **全局生育抑制总量上限** + 长程婚配率专项实验；b16 曾因被备货分支占满而必须提前（v1.19.0），人口自我更替是项目敏感红线，生殖轴行为效果默认 P2 关闭、实验通过后才开启；
     > **【已校订 v1.50.32】「不塌方」此前没有量化判据，无法裁定开关能否开启**。本稿原只写「长程婚配率专项实验」，未定义通过线，也未安排执行载体（项目内目前**没有**多种子批量长程对照工具，现有 `gold_mining_analysis.js` / `test-personalization.js` 均为一次性脚本）。
     > **定案**：① 先建**长程对照实验脚手架**（≥30 种子 × {无激素 / 只读 / 全量} 三组，固定输出人口与灭绝、家族存续、劳动时间分配、财富集中度、婚配率与出生率、饥荒存活结构、冬季行为差异、职业结构分布八项指标）；② 再跑**生殖轴专项实验**（≥30 种子 × {关闭 / 开启}），按下述建议判据裁定（实施时据实测回填具体阈值并写回本条）：
     > - 长程婚配率相对关闭组下降 **≤ X%**；
     > - 出生率相对关闭组下降 **≤ Y%**；
     > - 任一种子**不出现人口归零**；
     > - 战乱 / 苛税高压场景下出生率**下降但不归零**（验证全局生育抑制总量上限确实生效）。
     > ③ 另据 §4.8 校订，b16 调制**只作用于目标选择偏好、不调触发门槛**，从源头规避 v1.19.0 路径。

## 10. 总结

四轴十一激素系统是「生理层 → 化学基调 → 决策层」的中间调制层：奖赏-情绪轴让劳动有干劲与成瘾、给冬天与地位以情绪重量、制造冲刺与过劳的节律、把 [03 号](./03-social-relations.md)的依赖关系写进血液；应激轴让制度失败在身体上留下账单、为 18 号的暴力时刻提供爆发与警觉；生殖轴给求偶竞争、受孕、妊娠、产后与更年期以连续的生理节律；代谢轴用一个总闸门创造个体的能量策略差异与饥荒的群体自适应。它不新增任何需求、不指挥任何行动、不消耗任何随机数（**气质遗传是唯一例外，须显式承担基线变更**）——只让「同一个人，不同的一天」与「同一个家族，不同的命」成为可能。

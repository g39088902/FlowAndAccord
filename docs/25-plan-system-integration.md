## 1. 权威分工与实施顺序

本文是跨专项接口的规划权威；各专项负责领域规则和数值，现有实现仍以 `docs/current/`、源码和根 AGENTS.md 为准。新增接口名均为概念名称。共享接口应随第一个实际消费者落地，不提前建设无人使用的大框架。

| 共用设计 | 本文职责 | 领域权威 |
|---|---|---|
| 家庭可支配资源与预约 | 家庭保护线、并发承诺、权限、中断与复核 | 23 定义个人记忆阈值；24 定义市场交易与紧急预算；17 定义农业税 |
| 统一 L2 候选选择 | 可行性、救命时效、成本与偏好的组合顺序 | 当前决策架构；23 记忆偏好；24 报价结算 |
| 物资与身体 | 原粮/熟食/肉食、设施/用品、寿命/伤病之间的边界 | 20 加工照料；18 狩猎、伤势与防御 |
| 土地与通行 | 农田、房屋与公共设施共同消费地理查询 | 22 地形规则；21 视觉表现 |
| 事实与观察 | 一次事实、多种消费者、不同生命周期 | 23 编码/衰减；长期路线图历史年表 |

推进顺序：先随最小切片统一家庭储备/预约、选策与物资身份；24 内部市场 P0/P1 与 23 记忆 P0 可分别验证，采购偏好生效前合流统一选择器。17 农业须具备真实劳作、搬运及土地查询后实施；20 做饭与照料、18 狩猎共用物资和身体契约。21 的 S1～S3 可独立改善现有画面；22 T0 先建立公共地理查询，动态路卡晚于道路失效与任务恢复能力。该顺序表示依赖，不是新增排期。

## 2. 家庭资源保护与可支配余额

家庭实际库存只有家户账本，行囊、农田待运产物、加工中的投入和市场池各有明确位置与所有者，均不能再次计入家庭现货。家庭查询返回现货、保护量、有效预约、可支配量及原因，不创建第二份库存。

### 2.1 从个人准备倾向到家庭保护线

23 的 `effective_stock_band(agent, resource)` 继续负责个人补货锁存。家庭普通出售、赠予和资本投资统一采用：

```text
B_r = max(基准停止阈值, 本户具备该资源自主补货资格成员的有效停止阈值)
P_r = max(B_r, 安全时段内全家预计消耗)
A_r = max(0, 家户现货余额 - P_r - 其他有效的未扣账预约)
```

- 按资源分别计算；没有合格成员时回退基准。所有在世成员（含幼儿、衰弱者）的需求都进入耗用预测，不能因其无法补货而漏算口粮。
- 使用成员阈值最大值，不相加；记忆仍保持个人所有，不复制为全家共同经历。记忆效果关闭时按基准计算。
- 安全时段使用游戏时间，覆盖任务往返和预定安全余量；按现有生理、供暖等参数估算。成员/资格/记忆变化后在消费查询时更新，不逐 tick 全人口重算。
- 待扣账的明确事务只计入预约，不再叠加到预测耗用；做饭原料与对应预计进食不能重复扣算。同一物资的生产计划、行囊和预期收成都不能当作已经到家的现货。
- 任务目标量可冻结，但实际提货和支出前必须重算保护线、资格与余额；保护线升高则缩单/取消，下降不自动扩大已有授权。家庭变化通过正常决策与事务复核生效，不旁路改写 Agent 状态。

### 2.2 不同用途的权限

- **普通出售、对外赠予、资本投资**：只使用 `A_r`；市场仍受户主权限和断流等领域守卫限制，查询不授予新权限。
- **做饭、家庭进食和必要照料**：可使用为家庭生存保留的资源，不能被普通出售保护线阻止。加工必须保留来得及直接食用的应急口粮，只承诺本次所需量，不能把全家口粮锁在耗时加工里。
- **紧急自救**：沿用 24 的受限本人预算，允许突破普通储备保护和取消低优先级未提取预约；木材仍留安全期供暖最低量。不强抢别人已携带物资。
- **制度税收**：继续按所属制度结算，预约不构成免税资产。税收或消费改变余额后，受影响预约在下一次执行前重验；17 的产出税留粮规则不承诺豁免后续库存税。

## 3. 共用事务预约与任务占用

共享预约服务记录稳定预约 ID、任务/人物/家户、用途、资源上限、剩余未扣账量、目标对象和失效条件。预约不扣账；提货/投入提交时原子扣原库存并减预约，已提交部分只存在于行囊、在制品或资产中。

同户可以并存互不冲突的做饭、投资等预约，但同一时刻至多一个有效的市场提货任务。不能把市场限制扩展为锁住全家所有活动。照料对象、灶台和农田作业位置使用独立占用记录；同一对象同一排他任务只允许一个占用者，不把照料时间伪装成资源库存。

1. L1/L2 只读评估，选中任务后由统一执行入口申请预约/占用；稳定 ID 顺序提交，失败不扣料、不装入行囊。
2. 每次真正扣减前重新检查所有权、权限、位置、有效期与剩余余额；同户多人和多项 pending 不能分别花掉同一笔钱。
3. 紧急消费优先于普通交易/投资。必要时缩减或取消未执行预约，按稳定顺序处理；执行器只报告失效，Agent 通过正常决策重新选择。
4. 抢占/取消只释放未执行承诺。已提取货物不远程退款；加工中的原料及进度留在明确的在制品记录，不能自动恢复成原料又保留产物。
5. 死亡、分家、改嫁、家户解散或设施失效时取消不再合法的预约/占用；实际资产只走一次既有归属/继承处置。需委托运输的货物保留来源和预算，不能误作个人可自由出售的物资。
6. 预约、在制品、货物来源、占用、任务阶段及完成标志随档保存。读档重建索引但不重新提货、生产、成交或扣税。

禁止家庭管理器扫描成员强制派工；服务只提供需求、占用和提交结果。验收覆盖多人同拍申请、紧急消费、税后余额不足、途中死亡、分家及半段任务存读档。

## 4. 统一 L2 选策与记忆接入

L1 仍按配置顺序判断需求，持续任务由 `ActiveTask` 管理；内部市场与记忆不得各建一套采购仲裁器。候选统一表达目标资源/实际数量、资格、合法路线、首次取得救命量的时间、后续完成时间、支付来源、资产成本、失败原因和稳定 ID。

固定处理顺序：

1. **硬可行性**：身份、身体能力、资源触发器、真实库存、权限、行囊容量、预算与可达性；采用真实路径成本，含回家、装货、采收/交易等待，不只比较直线距离。
2. **求生时效**：先排除赶不及的方案。危机下按能满足最紧迫缺口、首次救命量更早取得、家庭资产牺牲更少排序；记忆和富裕偏好不能改变这个顺序。
3. **普通成本**：对同目标有效量比较。内外市场按 24 的完整报价；采收与采购比较使用配置化、单位明确的时间/资产换算，展示原始时间和资源代价。未校准跨策略尺度前，记忆 P1 仅开放同类 POI 偏好，采购记忆只记录事实。
4. **有限偏好**：安全候选的非负可比成本才应用 23 的合并限幅；禀赋/家资倾向一起进入该入口，不在前面提前返回。只有一个可行方案时忽略负面偏好；同分按稳定 ID 破平。

用统一候选选择替换当前 `should_buy_resource` 的布尔捷径时属于明确行为改动，需同版本确定性与长程实验；不能声称新行为与旧版逐字节等价。只读评估不消费 RNG、不修改余额、不创建预约；到场仍按当时库存重新报价。关闭记忆效果时，相对于已经接入新选择器的无记忆基准行为一致。

## 5. 食物、用品与身体状态

### 5.1 物资分类与加工

首期农业产粮沿用现有 `Food`；做饭/狩猎落地时，将 `Food` 明确为可直接食用的普通原粮，熟食和生肉作为独立物资身份。生肉可按食谱加工成熟食，营养转换、燃料、耗时、加工损耗和保鲜规则由 20/18 配置定义；不将肉与熟食额外复制成一份 `Food`。

生理恢复量与物资数量分开记录。“可食用储备”是按各品类实际营养系数换算的只读视图，原粮、熟食、生肉只计一次；原粮补货目标与总可食用量分别展示。成熟前作物和未完工饭菜不能按熟食供消费。未来每个新增品类必须覆盖账本、携带、消费、税收、继承、快照与存档；是否免税或不可交易需显式配置，不能靠遗漏枚举实现。

24 首期保持水/普通粮/木/石四池；肉和熟食不自动进入普通粮池，不隐式按 1:1 兑换，也不要求为本次融合新增交易池。估算饥饿风险和家庭保护量时，应识别家庭实际能及时吃到的各种食物。

兽皮是有数量的物资；投入被褥或装备后从原库存扣除，用品/设施状态承载效果。同一张皮不能同时作为库存兽皮与床上被褥获得两次保暖。多个保暖来源按配置合成并限制总减免（上限不得超过 100%，首期保留正的最低燃料比例）；18 的“每件减少 50%”只作为首件原型参数，不允许线性叠加成负烧柴量。燃料预测、木材保护线和缺柴记忆读取同一个有效供暖需求。

### 5.2 寿命、伤病与行动能力

保持当前 `health` 的寿命职责与衰弱判定；18 的 `vitality` 表示可恢复生命力，伤势记录伤害/功能限制，20 的康复照料消费同一模型，不另建第二条可恢复健康值。普通休息、治疗与照料不能增加自然寿限或清除寿命引起的衰弱。

共用只读能力查询区分可移动、可重体力、可加工、可照料等资格。狩猎/农业重劳动同时检查衰弱、伤势与体力，不能因“成年男性且力量高”绕过衰弱；轻加工、照料、传授也检查本人实际能力，不将所有老人自动转成照料者。避难和紧急自救使用各自可行性守卫，系统不强制切状态。

死亡只提交一次生命周期结算；战斗致死与既有死亡遗物归户流程合流。事实保留实际死因，未发生的冻伤、治疗、照料不能由记忆标签推导。

## 6. 土地、设施与通行

22 的地块/通行查询统一提供完整占地、高差、坡度、水域、占用、接入走廊与失败原因，供房屋、17 农田和 18 哨塔/路卡消费。天然适宜性与农田投资肥力分开计量；21 只绘制内核事实，不凭装饰生成土地收益或碰撞。

地形 T0 是农业和公共设施选址的共同依赖，不要求先完成河流、水文和所有地图模板。首期静态防务设施可以先消费查询；能阻塞/减速的路卡须等待独立通行版本、路径缓存失效、在途安全停靠与重新选策契约，不能借字符串 epoch 或强制瞬移修复。

路卡新建、关闭、破坏后的整个曲线合法性、A* 下界、APSP/缓存和当前车道上的人物都需校验；物理层报告变化并维持合法位置，决策层决定去向。警报与政令提供环境事实和激励，不扫描人群强制入伍。22 的“静态地形先行”不等于 18 可以提前绕过动态通行门槛。

## 7. 事实、快照与验证

农业、烹饪、照料、狩猎和市场执行器只生成已结算的类型化事实。统一事实身份及任务/访问关联，23 的活跃记忆和历史年表分别消费；市场两腿交易只作为一次相关访问证据，加工开始不等于吃到熟食。死亡后历史可留存，但不保留会行动的记忆副本。

事实提交时序、episode 去重与详情观察以 23 为权威；快照同步以[根 AGENTS.md §4.5](../AGENTS.md#45--快照与前端字段四处同步-m4-起v1453)和[影响矩阵](./current/13-impact-matrix.md)为准，所有消费者使用完整 FABS 链。家庭索引、地理缓存等派生数据可重建，影响未来结算的状态必须持久化。

取消 16 中的“按需求层级再错峰”。性能优化维持当前个人决策相位、各层评估时机、共享 RNG 消费顺序和结算顺序，只优化查询、索引、缓存及等价的数据处理；行为新增的实验与纯优化的等价验证分开进行。

联合验收至少包括：不同记忆成员的补货/出售不互相抵消；做饭、投资与市场同拍承诺不透支；唯一救命来源不被偏好否决；农业零劳动无产出、半程运输不入家账；加工与保暖不重复计物资；伤愈不逆转寿命衰弱；路卡失效时无穿墙/瞬移；上述场景分批推进和存读档均可复现。长期实验比较人口、灭绝、劳动时间、家庭储备、税负与资源分配，不能把新增初始物资效应误认成制度效果。

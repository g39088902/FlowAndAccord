## 1. 项目愿景

构筑一个**微观空间动线 × 自发生态演化 × 显式产权账本经济 × 现代混合政体光谱**深度交织的社区尺度微型社会——居民依据欲望线自发筑屋拓路，资产归属于有管理者的账本主体，统治者兼具民意/技术/资本/强制/宗法/意识形态六维权力，在有限寿命与精力约束下经历执政登顶与在野流变。

**核心设计哲学**：
- **确定性涌现**：纯规则内核驱动多智能体，长期演化不可预测但可复现（同种子逐字节一致）；
- **账本即权力**：资产负债表即社会结构快照，任何资源流动都是主体间显式 Transfer（可审计、可追溯）；
- **非互斥混合政体**：告别"纯民主 vs 纯独裁"二元标签，统治者可同时动用选举、算法、专利、武力、宗族多种合法性来源。
- **羊皮卷即叙事**：确定性内核意味着世界未来在种子播下那一刻便已写定，只是无人可知；以"梅贾德斯羊皮卷"为文学外壳，把"已写定但不可知的命运"转化为可预言、可回看的悬念装置（详见 §3 M14）。

## 3. 未来里程碑（规划态）

> 账本经济 M1~M4（v1.0.0~v1.3.0）、家户账本化 M6（v1.4.0）、家庭库存触发器 M7（v1.5.0）、升级成本矩阵 M8（v1.6.0）、存档系统 M9（v1.8.0）已全部落地，详见 [docs/current/12-ledger-system.md](./current/12-ledger-system.md)、[docs/current/15-save-load.md](./current/15-save-load.md) 与 [docs/12-plan-ledger-refactor.md](./12-plan-ledger-refactor.md)。以下为尚未实现的未来方向（编号自 M10 顺延，避免与已落地里程碑冲突）。

### M10 · 专利经济与痛点动态发明 → v1.9.0

**核心目标**：引入"痛点倒逼发明"机制，民间野生黑科技带来高回报高风险的投机博弈。

- 痛点追踪（拥堵/噪音/资源瓶颈）自动聚类生成科技方案；
- **民间野生黑科技**：底层居民突变发明高商业回报但伴随治理副作用的技术（如"下水道高压蒸汽穿梭车"）；
- 天使轮注资：玩家/家庭可用私产低价注资野生发明家，成功获垄断分红，失败承担舆论冲击；
- 专利股权确权写入资产负债表，支持在野做空收购、垄断收费或特权征用；
- **前置依赖（已满足）**：账本 M1~M9 已全部落地，专利授权计费、救济、工资、分红等一切主体间交易已有归属与可审计的资产负债表。

### M11 · 六维政治资本与混合政体 → v2.0.0

**核心目标**：统治者权力从"单一国王"升级为六维连续政治资本向量，复合形态与特权法案解锁。

- **六维向度**：民意 Civic / 技术 Tech / 资本 Capital / 强制 Dread / 宗法 Dynasty / 意识形态 Hegemony（各 0~100）；
- **固定年化指数衰减**（基准 8%/年）：高存量与多向度自然导致维持成本激增，杜绝"全知全能数值全满"；
- **复合统治者形态**：多维高阈值组合激活（镀金民选市长 = 高 Civic+Capital；民粹凯撒 = 高 Civic+Dread+Hegemony 等），LLM 动态生成民间诨号；
- **特权法案矩阵**：多维阈值交叉解锁（智慧绿波、私立收费站、人民卫队、王家御道等）；
- **执政与在野流变**：下台保留私产，可选择幕后操盘复仇 / 隐退食利躺平 / 自由读档。

### M12 · LLM 认知总线与生成式社交 → v2.1.0

**核心目标**：异步 LLM 层承担叙事生成——希腊合唱队、议会辩论、NPC 心声日记，核心循环仍由模板即时兜底。

- **双轨响应**：核心事件由模板引擎 0ms 即时返回，背景叙事由 LLM 异步润色；
- **希腊合唱队**：街头小报头条、酒馆打油诗、名流沙龙议论，以尖锐笔触点评政策矛盾；
- **议会大辩论**：重大法案/大选前触发语言攻防对决，玩家按六维向度打出不同特权论据；
- **NPC 心声日记**：剥离数值 Buff 功利绑定，聚焦真实价值观认同与立场冲突（如工会领袖在你向财阀妥协时写下"既心疼又失望"）；
- 生成式 2D 立绘与阶级微表情。

### M13 · 内核架构演进（ECS + 零拷贝快照）→ v3.0.0

**核心目标**：性能与可扩展性升级，为数千实体与复杂社会经济模拟奠定基础。

- **ECS 内核重构**：从当前 `Vec<Agent3D>` 结构体数组迁移至 ECS（hecs/bevy_ecs），组件化实体、系统调度；
- **零拷贝快照**：从当前 JSON 序列化迁移为双缓冲共享内存快照 + Hermite 时间戳插值，消除 WASM 边界序列化开销；
- **sim_cli**：命令行调试、性能 Benchmark 与大批量蒙特卡洛仿真；
- 详细架构愿景见 [docs/10-architecture.md](./10-architecture.md)。

### M14 · 梅贾德斯羊皮卷预言（确定性叙事层）→ v2.2.0

**核心目标**：把"确定性内核"这一早已写好的事实，转化为可感、可回看的文学装置——羊皮卷预言与游走观察者，为"纯观察者"定位注入 agency 与悬念。

> **设计原点**：确定性内核意味着世界的全部未来在种子播下那一刻便已写定，只是无人可知——这本身就是《百年孤独》的"羊皮卷"。梅贾德斯不是一个新系统，而是把"确定性 + 存档 + 旁白规划"这三样已具备的能力罩上一层文学外衣。

- **羊皮卷预言（确定性预取）**：复用已有 headless + 多步 tick 预取未来某时刻的锁定事实，再回到当前时刻以"预言"形式揭示（如"这一族将有一人在金矿营地登基"），不引入任何新机制，技术前置仅需确定性内核 + M9 存档；
- **梅贾德斯游走观察者（挂 M12 认知总线）**：一个不在族谱、不进账本、不参与竞争的"已死而复生"游走观察者，走纯观测钩子；点选他可读一句由确定性预取出的真预言，将文学神秘感与系统可解释性合一；
- **羊皮卷编年史与命名（挂 §6.1 建议 4）**：一局终了，由羊皮卷为帝国大道、大庄园、宗族冠以史诗之名，把"见证"转化为"被写进羊皮卷"的所有权；
- **前置依赖**：确定性内核、headless/多步 tick、M9 存档均已落地；梅贾德斯人设与旁白文风依赖 M12 LLM 认知总线；本里程碑为叙事层，可独立于 M13 内核重构提前落地；
- **梅贾德斯三不红线**（见 §4）：不剧透、不介入、不解释。

## 4. 跨里程碑核心设计原则

| 原则 | 说明 |
| :--- | :--- |
| **确定性红线** | 一切随机消耗走 `WorldRng` 按 agents 顺序消费；新增机制不破坏 `tools/test-wasm.js` 同种子逐字节一致性 |
| **新旧分离** | 新经济/政治系统与现有房屋/仓储/决策逻辑完全分离，通过旁路观测记账，不做兼容层迁移 |
| **Agent 自主决策** | 系统只当"物理规则执行者"，一切"做不做、何时做、在哪做"来自 agent 自己的需求评估，严禁扫描全图强制指挥 |
| **超参集中化** | 全部可调参数走 `config.rs`（命名 const + SimConfig 字段 + Default 映射三处）+ `config.js`，改完必跑 `config-check.js` |
| **持久化测试禁令** | 不持久化单元测试，临时验证后删除；长期验证只依赖 `node tools/test-wasm.js` |
| **快照三处同步** | 新增字段须同步 `snapshot.rs` → `world.rs::generate_snapshot()` → `rustworld.js::_applySnapshot()` |
| **账本即真相源** | 家庭物资唯一真相源是家户账本（房屋仓储已删）；决策读账、吃喝烧柴扣账、无容量上限 |
| **决策可编排** | Rust 内核无序，13 分支注册表按前端策展顺序迭代；顺序唯一真相源在 `config.decision-order.js`，拖动热注入 |
| **梅贾德斯三不原则** | 羊皮卷只揭示已被 `WorldRng` 锁定的宿命（不剧透可被干预的命运）；梅贾德斯纯观测、不介入、不消耗 RNG；只呈现、不解释 |

## 6. 游戏心理学与经济学视角的优化建议

> 本节为**优化建议**（非已承诺路线图），从游戏心理学与经济学两个维度审视现有设计与愿景，供 M10~M13 里程碑设计参考。核心命题：**当前已建立"账本即权力"的存量记账，但尚缺"交换与价格"的市场涌现；当前已建立"纯观察者"的沉浸，但尚缺"有克制的干预"的 agency。**

### 6.1 游戏心理学：从"纯观察者"到"有克制的干预者"

自我决定理论（SDT）指出，可持续沉浸依赖三大基本心理需求：**自主(autonomy) / 胜任(competence) / 归属(relatedness)**。现状评估：

| 心理需求 | 现状 | 缺口 |
| :--- | :--- | :--- |
| 归属 relatedness | 族谱时间轴 + 代际史诗 + 家庭/宗族/王国认同 | 已满足，可加深"认领一个家族"的视角锚点 |
| 胜任 competence | Inspector 揭示"为什么"（可解释性） | 部分满足，缺"看懂后可干预"的掌握闭环 |
| 自主 autonomy | 纯观察，零干预 | **几乎为零，最大缺口** |

建议（按投入产出比排序）：

1. **间接干预替代直接指挥（补 autonomy，守住涌现底线）**：不指挥个体，只施加**带延迟、有代价、不可撤销的环境层扰动**——天灾、税制微调、资源种子、迁徙令。既满足 agency，又不破坏"系统只当物理规则执行者"的涌现铁律（与 M10 专利注资 / M11 政体法条天然同构）。
2. **变量奖励与"未解之谜"钩子（补好奇心）**：确定性内核 ≠ 玩家可预测。保留隐蔽涌现空间（稀有基因组合、隐藏才能、罕见社会事件），制造"下次会看到什么"的 pull，对应 Hook 模型的 Variable Reward 环节。
3. **蔡格尼克效应：让"未完成叙事"可回看**：夺位远征中断、绝嗣废墟、冬日绝育等"悬而未决"事件应成为可追溯故事线（存档 M9 已支撑"续看结局"），玩家有"想知道结局"的驱动力。
4. **禀赋效应 + IKEA 效应：轻交互命名/立碑**：允许玩家给家族、帝国大道、庄园命名或立"追忆碑"，把"见证"转化为"所有权"，代价极低、情感收益高。
5. **渐进复杂度（守住心流带宽）**：复杂度分阶段揭示——早期仅生理/马斯洛，中期开放账本/宗族，后期才开放六维政治/市场，避免认知超载（呼应 §5 风险第一行）。
6. **损失厌恶的正向转化（防"无力感"）**：冬天冻馁是强情绪钩子，但纯无力会流失。设计"可干预的险境预警"（入冬前资源告警 + 玩家可注入一次救济），把损失厌恶转化为"挽狂澜"的胜任感。

### 6.2 经济学：让"账本即权力"长出市场与分工

当前经济已实现**存量记账**（谁有什么、谁付谁收、税收救济），但尚未实现**交换与价格**。经济学意义上，没有价格信号的资源配置是"计划式"的，无法涌现比较优势与专业化分工。建议：

1. **引入交换媒介与价格机制（最大杠杆）**：黄金当前仅是"终极建材"，建议升级为**通用交换媒介**，让 agent 间产生"以金易物"，供需自发形成价格，涌现**比较优势与专业化分工**（高智力→工匠、高力量→矿工）。这是经济涌现的核心引擎，也是 M10 专利经济可交易化的价值前提。
2. **税制从"财富税"转向"流转/累进税"**：当前族税/公仓税按"账面余额 × 固定税率"征收，属**扭曲性财富税**——储蓄越多缴税越多，抑制积累。建议改按产出/交易/消费计征，或引入累进税率，让税制成为可观察的制度变量而非固定惩罚。
3. **公共品搭便车 → 救济加"隐性成本"**：救济/互助是"免费公共品"，存在搭便车与福利依赖。建议给救济附加隐性成本——接受救济扣减威望（`prestige` 已落地）或须付劳动（workfare），把"等救济"变成有代价的选择。
4. **道路/土地产权缺位 → 引入地租与过路费**：道路是"正外部性公共品"（踩踏成道无主、搭便车），营地辖区无地租。建议引入土地/不动产产权 + 地租（营地升级为县后对辖区房屋征地租），以及私立收费站（M11 特权法案已提及），让外部性内部化。
5. **公地悲剧 → POI 特许经营/私有化实验**：POI 是"公地"，虽有施密特触发器缓解"雷鸣群集"，长期仍是无产权公地的过度开采。建议在 M10/M11 引入 POI 私有化/特许经营，对比观察"私有 vs 公地"的效率差异——制度经济学的天然实验场。
6. **财富分配可观测化 → 基尼系数 + 马尔萨斯循环**：引入基尼系数/洛伦兹曲线作为观察指标，让"贫富分化 → 社会动荡 → 政体更替"的循环可被直观看到，形成"制度 → 分配 → 稳定"的反馈闭环。
7. **时间偏好与跨期选择（行为经济学）**：冬季供暖是"春存冬用"的跨期选择。给不同 agent 引入**贴现率/时间偏好**（现时偏好差异），高时间偏好者更倾向"今朝有酒今朝醉"而冬天易死，让"耐心"成为可观察、可遗传的行为经济学变量。
8. **资源诅咒观察点**：金矿唯一（稀缺），可观察"金矿营地是否更易发生夺位冲突/腐败"，作为资源诅咒（resource curse）的涌现样本。

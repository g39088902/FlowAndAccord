- **核心原则 1：体力 50% 以下之前不寻求休息**
  - 体力 $\ge 50.0\%$ 时，族人不将休养作为需求，全力响应外出采收、建房、修缮或高层任务；
  - 仅当体力跌破 50%（$\text{stamina} < 50.0$）时，休养生息进入第一层生理需求队列，引导族人归巢恢复至 $100\%$。
- **核心原则 2：低层级需求绝对优先阻断高层任务（严禁越级）**
  - **仓库填满属于安全需求（优先于盖房）**：私宅水、粮、过冬木柴低于 $50\%$ 时优先外出搬运填满仓库，比盖房子（施工升级）更优先满足；
  - **房屋受损修缮**：私宅耐久度跌破 50%（$\text{durability} < 50.0\%$）时产生修缮欲望，一旦开工则一路修缮回血至 $100\%$；
  - **区分盖房淘金与娱乐淘金**：
    - **盖房淘金 (`StockGold`)**：3级庄舍升4级大庄园的建材储备，冷却时间为 **45 秒**；
    - **娱乐淘金 (`GoldWealth`)**：4级大庄园完全竣工后的闲暇财富积累，冷却时间为 **180 秒**；
    - **房屋未建至顶级（4级大庄园）绝不娱乐淘金**：若房屋未达到最高级或存在物资缺口，绝不进行娱乐性淘金。
- **核心原则 3：Agent 私有 POI 施密特可派遣性、连续采收与断流就近重路由**：
  - **私有施密特可派遣性（开启 $\ge 30\%$ / 关闭 $<10\%$）**：每个 Agent 在自身决策相位观察 POI 库存，更新 `poi_seekability`；库存到达 $\ge30\%$ 才对该 Agent 开放，已开放点只有跌破 $<10\%$ 才关闭，$10\%\sim30\%$ 维持该 Agent 的前态。决策上下文提供资源节点，选点与路由只读取 Agent 私有触发器；
  - **采收现场未满连续采收**：当族人在采收点现场作业时，若自己的目标触发器关闭，但族人自身需求未满（口渴/饥饿）或背包未满且家宅仍需，在体力和生理健康允许的前提下，自动就近寻路前往自身触发器已开放的下一处同类 POI，避免提前送货回宅；
  - **中途断流熔断与就近平滑重路由**：若族人在赶往某 POI 途中发现自身对目标的施密特触发器已关闭，小人通过 `turn_around_and_route_to` 原地掉头并平滑重新规划路径前往自身已开放 POI（继承反向进度 $L - s$，**绝不发生节点瞬移**）；仅当自身该类资源均关闭或自身体力/生理告警时才折返回家。
- **执行中状态的自适应与生理熔断**：
  - 族人在外出任何高层任务途中，一旦饥渴 $< 25.0$ 或体力 $< 50.0$，立即中断当前作业并降级折返。
- **错峰决策节拍（30 Tick 周期）**：
  - 决策调度间隔为 30 tick（1.0 模拟秒），每个族人在 `(tick + id) % 30 == 0` 相位上决策，保证帧率均匀与决策开销均摊。

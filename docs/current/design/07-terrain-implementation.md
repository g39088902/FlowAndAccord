# 07. 地形实现现状（产品视角）

> **本层定位**：写给不读代码的产品经理——当前地形系统做到哪一步、地图上能看到什么、哪些东西在影响玩法、产品可以调哪些旋钮、还缺什么。
> 本文只描述**当前代码中真实存在**的地形能力（基线 **v1.50.32**）；机制细节见 [`14 地形、空间拓扑与路网`](../tech/14-terrain-and-network.md)，玩家规则速览见 [02 世界与地图规则](./02-world-rules.md)，未来蓝图见 [`06 地图模板规划`](../../plan/tech/06-terrain-templates.md)。
> 文中数值默认值均以 `frontend/js/config.js` 为唯一真相源（括注字段名）；调参改配置即可，本文不另立口径。

## 1. 一句话现状

> **当前游戏里的地形 = 两张可随机轮换的地图 + 一套纯视觉装饰 + 确定性种子系统。**

| 维度 | 现状 |
| :--- | :--- |
| 可玩地图 | **2 + 1 张**：山口聚落、两岸河谷（随机轮换）；平地草原内核骨架已落地（`terrainProfile: 'grassland_plain_v1'` 显式锁定，v1.50.40） |
| 地表类型 | **7 种**：干地、软地、河阶、河岸、裸岩面、浅水、深水 |
| 地表装饰 | **5 类**：树、灌木、岩石、碎石堆、草丛（纯视觉，随季节变色） |
| 地图选择 | 默认由世界种子决定（两套随机轮换模板约各占一半）；支持配置锁定模板名 |
| 确定性 | 同一种子永远生成同一张图，可保存、回放、分享 |
| 附加地貌（湖/瀑布/峭壁/牛轭湖） | 「抽签器」已实现，但**还没有真正长到地图上**（见 §7） |

地图只约束**初始环境**：聚落怎么长、路往哪走、谁住哪，由模拟自行涌现，不预设某岸必富、某山口必成王都。

## 2. 玩家现在能玩到的两张地图

| 地图 | 地貌构成 | 玩家会体验到什么 | 状态 |
| :--- | :--- | :--- | :--- |
| **山口聚落** | 丘陵 + 一条主脊 + 一处山口 | 主脊陡到走不上去（超过 30° 硬禁行），**山口是唯一合法通道** → 去山那边必须绕行（实测绕行比 2.17~4.80），山口自动成为交通走廊 | ✅ 已落地 |
| **两岸河谷** | 一条主河 + 两处浅滩 + 两岸河阶 + 泉谷 | 河流把地图分成两岸，**跨河只能走两处浅滩**；河阶是天然的高肥力安家地；多个取水点共享同一份「水库存」 | ✅ 已落地 |
| **平地草原** | 低幅起伏平原 + 孤立残丘（1~2 处缓丘）+ 泉溪洼地（2 处微凹地） | **无硬禁行、无水面**的开阔开局：选址与通行近乎自由，绕行比 ≈1 是设计预期；选址取舍从「地形避让」变成「水源距离与软地规避」（软地 1.25× 慢行）；草甸沃土全图高肥力 | ✅ 已落地（v1.50.40 内核 + v1.50.45 草甸装饰） |
| **半坡林地** | 不对称单侧缓坡山体 + 坡脚平原 + 泉溪 + 密林梯级 | 坡度慢行但**全图无硬禁行**；>18° 禁建把房屋压进坡脚平缓带；林地纯视觉可穿行，坡腰密林 → 坡麓疏林 → 坡脚草原自然演替 | ✅ 已落地（v1.50.46/47） |
| **台地**（原“台地聚落”，v1.50.68 更名） | 圆角矩形台面 + 真实阻路陡峭台缘 + 双入口缓坡走廊 | 台缘硬禁行阻断直爬，路线必须走双入口缓坡；台面平缓可建区 ≥3 处房屋 | ✅ 已落地（v1.50.54） |

补充事实（产品可以拿来说事的数据）：

- 山口图的「山」不是整座山都不能去：主脊实测坡度 **36°~41°**，但全图仍有约 **80% 的格子可建**（可建 = 坡度 ≤16° 且非禁建带）——堵路的是山体本身，不是整张图；
- 河谷图跨河是有成本的：过浅滩走路明显变慢（2.0× 代价），两岸直线距离近、实际路程要绕到浅滩——这正是它制造「两岸聚落、经浅滩往来」的方式；
- **地图怎么选**：默认随机（`terrainProfile: 'random'`），由世界种子在 **8 张已收口模板**（山口聚落 / 两岸河谷 / 平地草原 / 半坡林地 / 台地 / 山前冲积扇 / 盆地 / 湖畔盆地）间确定性分配，各约 12.5%（★ v1.50.68 砍需求后 8 路；早期版本是山口/河谷二选一，原 9 路中的河谷聚落已删除）。也可以在配置里显式锁定某一张模板。

## 3. 地图上看得见的「地表词汇」

| 地表 | 长什么样 | 能不能走 | 能不能建 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 干地 | 草/土平地 | ✅ 正常 | ✅ | 大多数地面 |
| 软地 | 湿软泥土（常见于河岸） | ✅ 但慢（1.25×） | ✅（坡度允许时） | 只是慢，不引入疾病 |
| 河阶 | 河边平缓台地 | ✅ 正常 | ✅ | **高肥力（0.95）**，天然安家带 |
| 河岸/低滩 | 紧贴水面的砂砾带 | ✅ 慢 | ❌ 禁建 | 与水面之间的缓冲带 |
| 裸岩面 | 陡峭岩壁 | ❌ 硬禁行 | ❌ | ≥34° 的岩壁 |
| 浅水 | 河边浅水 | ❌ 禁行（仅浅滩通道可跨） | ❌ | 房屋占地碰到浅水直接拒绝 |
| 深水 | 河心深水 | ❌ 硬禁行 | ❌ | 任何情况不可通行 |

**三条玩家可以依赖的规则**：

- 缓坡可走，**超过 30° 的地面系统不会修路**；**超过 16° 的地面盖不了房**（`terrainMaxWalkSlope` / `terrainMaxBuildSlope`）；
- 普通水面禁行禁建；**跨河只走内核认可的浅滩**，不能从河里抄近路；
- 同一水系的多个岸点**共享一份储量**——换个岸点取水不能绕开资源耗尽（详见 [02 §3](./02-world-rules.md)）。

## 4. 地形对玩法做了什么：三条主线

### 4.1 决定「哪里走得了」

山要绕（山口唯一通道）、河要渡（浅滩唯一通道）、陡坡禁行、软地慢行。路网不是画出来的，是族人踩出来的：踩过的路从荒野小径一路升级到帝国大道（移速 0.5×~2.2×），没人走的路按比例衰减回荒野。**地形决定走廊，走廊决定聚落之间的往来**。→ 道路规则见 [02 §5](./02-world-rules.md)。

### 4.2 决定「哪里建得了」

建房要过**完整占地校验**：房屋整块占地坡度 ≤16°、不碰水面、不碰禁行区（不是只看中心点）。低滩禁建、河阶可建、山腰缓坡可建——这就是「哪里能安家」的全部依据。没有合法地块时，族人会自己换地方再试，**系统不替他搬家**。

### 4.3 决定「聚落长在哪」

水源、浆果、木材等资源点的位置 + 地形走廊共同决定聚落雏形；聚落行政级别（营地→村→乡→镇→县）是「房子盖在哪里」的统计结果，不是规划出来的。地形只提供约束，不指定谁住哪、谁先到。

## 5. 种子：同一张地图可以被记住和分享

- **同种子 = 同地图**：地形、装饰、资源布局完全一致，可以复现、回放、比较「如果当时换条路」；
- **地图图鉴页**：用与正式游戏同一套渲染管线预览地形（不启动模拟），输入种子即可预览那张图长什么样；
- **分享**：`?seed=<n>` 链接可把当前世界带回任何人的浏览器；
- **对产品意味着什么**：确定性是玩法资产（回放、比较、分享），也是**改动地形参数的代价**——任何地形参数变化都会「换一批新世界」，旧存档作废（有存档门禁保护，不会出现旧路网配新地貌的错乱）。

## 6. 产品可以调的「体验旋钮」

> 调参入口：`frontend/js/config.js`（免重编译，刷新即生效）。⚠️ **凡改动地形参数都等于换一个新世界**，旧存档会被门禁拒绝。

| 旋钮 | 默认值 | 调大 / 调小会怎样（体验语言） |
| :--- | :--- | :--- |
| 地图模板 `terrainProfile` | `random` | 锁定山口或河谷，或保持种子随机轮换 |
| 山脊陡峭度 `terrainPassRidgeAmplitude` / `terrainPassRidgeWidth` | 53m / 62m | 山更高更陡（绕行更难）还是更缓（山形消失）。**两个值必须配套**：调坏会让山「不挡路」（太缓）或「山口被夹死」（鞍部过窄） |
| 主河宽度 `terrainRiverWidthMin` / `terrainRiverWidthMax` | 28m / 42m | 河面视觉宽度与河阶布局；浅滩固定两处，跨河难度主要看下一个旋钮 |
| 浅滩通行代价 `terrainShallowWaterCost` | 2.0 | 过河成本：调大 → 两岸往来更贵；调小 → 跨河几乎免费 |
| 建房坡度上限 `terrainMaxBuildSlope` | 16° | 可建房区域大小：调大 → 山腰也能盖；调小 → 只有平地能盖 |
| 装饰密度 `terrainAccentDensity` | 1.0（0~2） | 画面茂密程度：0 = 光秃秃，2 = 茂密森林。**纯视觉，不影响任何玩法** |
| 分辨率 `terrainGridRes` | 256 | ⚠️ **危险旋钮**：改变它等于换世界、废弃全部旧存档，通常不建议调（v1.50.70 由 160 提升） |

## 8. 验证清单：在游戏里亲手确认这些说法

| 想验证 | 怎么做 |
| :--- | :--- |
| 两种地图长什么样 | 地图图鉴页输入不同种子预览；主界面「随机重置地图」反复重置观察 |
| 山口图「绕山必经山口」 | 选一个山口图开局，等路网成型：观察主干道是否都汇聚在山口处，是否有路横穿主脊 |
| 河谷图「跨河只走浅滩」 | 河谷图开局后观察跨岸路径：人物只在两处浅滩过河，浅滩处有踏石视觉 |
| 过河/走软地会变慢 | 鼠标悬浮道路查看「移速加成」悬浮卡；观察族人过浅滩时明显减速 |
| 路是自己踩出来的 | 开局观察营地与水源之间最先出现浅色虚线，越走越亮、升级变色 |
| 房屋选址有门槛 | 观察族人半山腰选址：陡坡处会自动放弃换地方，不强行盖 |
| 同种子同图 | 记下当前种子 → 重置 → 输入同一种子，地形与装饰完全一致 |
| 装饰是纯视觉 | 任意装饰（树/石/草丛）都不挡路、不产出资源、不能点击交互 |

## 9. 已知限制与产品需要知道的边界

1. **地图多样性当前 = 2 种骨架 × 装饰随机**：附加地貌（湖、瀑布、峭壁）尚未注入，同骨架地图之间只有装饰分布和细节差异；
2. **资源布局是共享规则**：全图固定 23 处资源点 + 1 座榷场，地形改变的是画面、通行和选址，**不改变资源点数量**——山多水多不会让资源变多；
3. **装饰不避让道路和房屋**：装饰在创世时一次性撒下，之后才出现道路和房屋，所以可能出现树挨着路、屋旁有树——纯视觉，不影响任何判定；
4. **创世兜底尚未完全实现**：两套模板在实测中稳定成立（60 个种子全过、40 个世界创世自检零失败），但「创世失败自动重试 / 降级」机制还未落地（规划项，极端情况下缺一道保险）；
5. **调地形参数 = 换世界**：任何影响地形生成的参数改动都会使旧存档作废，这是确定性承诺的代价，不是 bug。

## 1. 世界是一张「可以被记住的地图」

设计目标不是随机噪声，而是**有名字的地方**：分隔聚落的那条河、绕山必经的那个山口。
地图同时改变三件事：画面轮廓、路线选择、聚落条件。

组合只约束**初始环境**；聚落兴衰、道路流量与家庭选择由模拟涌现——不预设某岸必富、某山口必成王都。

## 3. 八类基础地形（拼装词汇）

| 地形 | 玩法价值 | 状态 |
| :--- | :--- | :--- |
| 丘陵 | 建房地点与绕行距离的取舍 | ✅ |
| 山脊与山口 | 交通走廊与资源距离差异 | ✅ |
| 河流与浅滩 | 分隔聚落并形成跨岸通道 | ✅ |
| 河滩与河阶 | 安家位置与取水距离的取舍 | ✅ |
| 湖泊与出水口 | 环湖聚落与绕湖交通 | ⏳ 子特征注入 |
| 湿地与泥泽 | 通行代价与土地利用差异 | ❌ 已删除（视觉辨识度过低） |
| 峡谷与断崖 | 少量强地标与路线瓶颈 | ⏳ 子特征注入 |
| 泉谷与瀑布 | 把水源 POI 与山地联系起来 | 泉谷 ✅ / 瀑布 ⏳ |

**关键地理规则（玩家可依赖）**

- 缓坡可通行；超阈值坡段（`terrainMaxWalkSlope` 30°）硬禁行，山口是合法缓坡通道而非传送节点。
- 普通水面禁行禁建；跨河只经内核认可的浅滩连接。
- 同一水系的多个岸点共享一个资源池——换个岸点不能绕过资源耗尽。
- 河岸软地只增加通行成本，不引入疾病。
- 房屋须通过完整占地校验（不是只查中心点）。

## 4. 聚落不是画上去的，是长出来的

营地是**行政区地名**：它随辖内绑定房屋数量的增长自动晋升级别并全图播报。
族人并不「建设」它——他们只是各自选址盖房，聚落的行政级别是这些选择的统计结果。

| 阶位 | 名称 | 图标 | 辖内房屋数（默认门槛） |
| :---: | :--- | :---: | :--- |
| 1 | 营地 | 🏕️ | 0 ~ 4 |
| 2 | 村 | 🏕️ | 5 ~ 9 |
| 3 | 乡 | 🏘️ | 10 ~ 14 |
| 4 | 镇 | 🏘️ | 15 ~ 19 |
| 5 | 县 | 🏛️ | 20 及以上 |

每座私宅选址时自动绑定最近营地，达成门槛即晋升——**「哪里人多」不是规划出来的，是被走出来的**。
晋升门槛依次为 `campLevelVillageMinHouses`=5、`campLevelTownshipMinHouses`=10、`campLevelTownMinHouses`=15、`campLevelCountyMinHouses`=20（营地阶为 0 起算）。

## 5. 路：他们自己踩出来的

没有预设路网。族人走过的每一段累加踩踏值，从荒野小径升级为帝国大道；没人走的路按比例衰减，长回荒野。

| 等级 | 名称 | 移速加成 |
| :--- | :--- | :---: |
| 1 | 泥土细道 | 0.50×（下限 `roadLevelFactorMin`） |
| 2 | 夯土小道 | ⬆ |
| 3 | 硬质石道 | ⬆ |
| 4 | 精修通衢 | ⬆ |
| 5 | 帝国大道 | 2.20×（上限 `roadLevelFactorMax`） |

> 一条被几代人反复踩踏的道路，就是一部无声的家族迁徙史。

道路**先于建筑绘制**并参与统一深度排序，所以远处的山能挡住山后的图标；普通观察使用土/砂砾/石板材质，
高等级亮色只在道路分析视图出现。渲染细节见 [`16 前端总览`](../tech/16-frontend-overview.md)。

## 6. 四季与气候

| 规则 | 数值 | 对玩家的意义 |
| :--- | :--- | :--- |
| 一年时长 | 240 模拟秒（`seasonYearLength`） | 一杯咖啡里能看完若干朝代 |
| 气温区间 | -3~31℃ 正弦起伏（`tempBaseMid`=14 ± `tempAmplitude`=17） | 冬夏资源压力完全不同 |
| 冬季供暖 | 气温低于 **8℃**（`houseWinterColdTemp`）即启动（不再绑定季节名）：非 0 级有主房屋每秒从**家户账本**烧 0.12 木材（`houseWinterWoodBurnRate`） | 柴火是冬天的硬通货，账本见底的家族只能硬扛 |
| 霜冻降产 | 气温跌破 **8℃**（`berryFrostDeclineTemp`）起，野外浆果产速按平滑曲线衰减 | 深秋是最后的囤粮窗口 |
| 冰封绝收 | 气温跌破 **0℃**（`berryFrostZeroTemp`）时野外浆果彻底绝收 | 断粮的家族只能入冬赴榷场买粮 |
| 木材红线禁孕 | 房屋木材储备 **< 10** 时自动禁用受孕（代码固定红线、非配置超参；0 级仓库无壁炉同样不满足） | 冬季不只是「冷」，还影响代际延续 |

**春夏秋三季偷懒不囤柴的家族，会在冬天付出代价。**

光照视觉：光位由快照驱动，一年扫 360°——春东 / 夏南 / 秋西 / 冬北；盛夏最亮、隆冬最弱；
地形受光、水底石光与水面波光统一联动，快捷键 `L` 开关。见 [`17 季节光照`](../tech/17-seasonal-lighting.md)。

## 7. 有效世界保障（开局必须成立）

每个世界在创世时都必须通过校验，否则按固定次序修复，绝不无限重抽种子：

- 初始居民落在干燥可达区域；
- 每个营地可达所需水粮，且**往返时间与饥渴/体力消耗在生存诊断上限内**（连通 ≠ 能活下来）；
- 全局关键资源与市场在同一陆路连通分量内；
- 每个营地有规定的可建面积与扩张余量；
- 失败时按固定次序调整浅滩、缓坡或候选 POI；超有界重试则退回简化模板并记录原因。

> **禁止**运行中移动居民来修地形。

## 8. 分辨率与「地图图鉴」

- 地形栅格实际分辨率 **120 × 120**（世界 764 m，步长 ≈ 6.42 m），已抽离为配置项 `SIM_CONFIG.terrainGridRes`。
- 「地图图鉴」独立页以相同种子加载只读渲染管线，可预览地形模板而不启动模拟；主界面可用 `?seed=<n>` 分享复现。

> ⚠️ 早期文档曾把分辨率误记为 60 × 60（对应 12.95 m 阶梯锯齿），已于 v1.50.19 更正；改动分辨率会改变地形形态与全部确定性基线，并使旧存档废弃。

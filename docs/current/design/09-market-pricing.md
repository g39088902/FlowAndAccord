> **本层定位**：写给不读代码的产品经理——外部市场（榷场互市）与动态价格系统现在能玩到什么、规则是什么、玩家能看到什么、产品可以调哪些旋钮、还缺什么。
> 本文只描述**当前代码中真实存在**的市场能力（基线 **v1.50.37**）；机制细节见 [`09 市场与定价`](../tech/09-market-pricing.md)，

## 1. 一句话现状

> **当前游戏里的外部市场 = 全图唯一一座榷场互市 + 一套「越缺越贵」的幂律动态定价 + 一个黄金单向流出的通缩闭环。**

| 维度 | 现状 |
| :--- | :--- |
| 地标 | **全图仅 1 处**榷场互市（`countMarkets`=1，POI ID 60 段位，全图 23 处 POI 之一） |
| 供给 | 三级外部储备：清水 400 / 粮食 400 / 木料 400（`marketStockMax*`），各 2.0/s 自然再生 |
| 定价 | **幂律动态计价**：按市场存量实时推导黄金单价，存量越低价格越陡（`marketPricePowerExponent`=2 平方反比） |
| 兜底对象 | 野外断流 + 家户水粮告急时，**男户主**揣黄金赴市买命；木料断流时远程结算直购（v1.36.0） |
| 黄金流向 | 单向流出：家户账本 → **系统虚空**（`LedgerRef::Void`），回收流通货币、杜绝通胀 |
| 市场性质 | **付费贸易点，不是免费公地**：不进入野外采集池、不设公共施密特触发器，只有绝境商贸 AI 会去 |

它是部落经济的「终极生存安全垫」与「货币蓄水池」：野外采得到时没人去，等野外断流再进，价格已经站在山腰上了。

## 2. 玩家能玩到的：榷场互市与幂律定价

### 2.1 一座市场的三级货架

| 货架 | 商品 | 储量上限 | 自然产速 |
| :--- | :--- | :--- | :--- |
| 主库存 | 清水（Water） | `marketStockMaxWater`=400 | `marketRegenBaseWater`=2.0/s |
| 次级库存 | 粮食（Food） | `marketStockMaxFood`=400 | `marketRegenBaseFood`=2.0/s |
| 第三库存 | 木料（Wood）★ v1.36.0 | `marketStockMaxWood`=400 | `marketRegenBaseWood`=2.0/s |

石料、金矿**没有外部报价**——市场只救「水、粮、木」这三样命脉物资。

### 2.2 幂律动态定价：越缺越贵

单价由纯函数从当前库存推导，不掷骰子：

$$P(S) = P_0 \times \left(\frac{S_{max}}{\max(S, S_{floor})}\right)^k$$

- `marketPriceBase`=0.1 金/单位（满库存基准价；木材 `marketPriceBaseWood`=0.15）；
- `marketPricePowerExponent`=2.0（平方反比敏感度——价格随「满仓 ÷ 存量」的**平方**抬升）；
- `marketPriceFloorStock`=1.0（计价安全钳制下限，防除零；库存跌破下限按下限计价，价格到顶）。

**玩家感受四档**（与 04 经济规则 §4 同口径）：

| 市场存量 | 单价 | 玩家感受 |
| :--- | :--- | :--- |
| 满仓（400） | 0.1 金 | 廉价补给，顺手就买 |
| 半个仓（200） | 0.4 金 | 价格温和上涨 |
| 只剩一成（40） | 10 金 | 暴涨百倍——**买命钱** |
| 触底（`marketPriceFloorStock`=1） | **16000 金封顶** | 硬顶收口，绝不出现无穷大（按上式 P₀×(Smax/floor)² 实算） |

> ⚠️ 供产品参考：tech/09 文档正文仍写着「封顶 1000 金」，但代码实际按上式封顶，默认参数下水粮为 **16000 金**（04 经济规则文档口径正确）；tech 文档该处表述待更正。

## 4. 市场对玩法做了什么：四条主线

### 4.1 绝境兜底：野外断流时的「买命通道」

当野外采集点对某个家户**彻底断流**（私有施密特触发器全关）且家户水或粮跌破 `marketEmergencyFamilyStockThreshold`=10.0 时，男户主自动揣黄金直奔榷场采购维生水粮——这是比「回巢休眠」更高优先级的**极端生存兜底**。水荒粮荒任一触发即可赴市，不必等双绝境（大旱但浆果尚存时也能买水保命）。

### 4.2 价格叙事：稀缺本身就是剧情

幂律定价让「市场存量」成为可读的故事：市场越空、金价越陡，买命钱从 0.1 金涨到 10 金、100 金……价格曲线本身就是世界在告急的信号。玩家看行情牌价就能读出这个部落的经济健康状况。

### 4.3 通缩锚：黄金单向流出的宏观作用

交易黄金从家户账本流经 `LedgerRef::Void`（虚空），**绝不转给其他 Agent 或营地**——黄金作为一般等价物持续向外部世界流失，沉淀货币蓄水池，为后续营地中介驱动的二手房屋竞价等经济系统提供**紧缩锚**。这是整个经济体系防恶性通胀的阀门。

### 4.4 阶层分化：钱多的人用钱买时间

★ M19.4c：家户金币 ≥ `marketWealthyFamilyGold`=200 的**豪绅户主**，按 80% 几率免于亲自伐木/采石，直接赴市现货采购；家户金币 < `marketPoorFamilyGold`=50 的平民则严格野外自力更生，非绝境不赴榷场。市场因此不只是一条补给线，也是**贫富分化在行为上的投影**。

## 5. 谁来买、怎么买：B15 绝境商贸决策（产品视角）

### 5.1 谁有资格赴市（B15 全守卫）

- **在世成年男性 + 家户户主**：家庭跟着男人走，只有户主有权支配全家金库出资采购；
- 体力 ≥ `marketMinDispatchStamina`=15.0（防止半路虚脱倒毙）；
- 家户黄金 ≥ `marketMinFamilyGold`=0.5（过滤空跑与高频微量寻路）；
- 绝境触发：家户水 < 10 **或** 粮 < 10，且野外同类资源点对该户主的私有触发器已全关。

### 5.2 现场交易流程

1. **现场自救缓冲**：抵达时若处于濒死线（口渴 <10 或饥饿 <10），先就地自饮自食补满生命底线（扣黄金）——绝不出现「手握清水却因装袋规则渴死在货架前」；
2. **离散步长装袋**：按 `marketSettlementStep`=5.0 单位逐笔购入，水粮木并行；每笔需同时满足「背包余量 ≥ 5」「市场有货 ≥ 5」「黄金够付 5 × 单价」，直至背包满额（`carryCapacityResource`=100/类）、市场售罄或黄金不足；
3. **协同支付**：优先扣家户账本黄金（远程结算），不足由随身黄金差额补足——**不用先回家取钱**；
4. **平滑返航**：无任何可执行交易 / 体力告警 / 途中现场临界饥渴时，自动返家，购入物按物理速率卸入家户账本。

### 5.3 木材兜底（v1.36.0）

外部森林衰竭或采木途中/现场断流时，家户户主（账本金币 ≥ `marketMinFamilyGold` 且体力达标）可直接**原地掉头改道榷场**采购木材，交易从家户账本远程结算。石/金采集不享受该兜底。

## 6. 产品可以调的「体验旋钮」

> 调参入口：`frontend/js/config.js`，免重编译、刷新即生效。

| 旋钮 | 默认值 | 调大 / 调小会怎样（体验语言） |
| :--- | :--- | :--- |
| 市场数量 `countMarkets` | 1 | 全图市场座数；>1 会稀释「唯一的救命稻草」的叙事与距离成本 |
| 货架容量 `marketStockMaxWater` / `Food` / `Wood` | 400 / 400 / 400 | 市场越能囤货，断流期价格曲线越平缓、兜底越从容；越小越容易「买不到」 |
| 再生速率 `marketRegenBase*` | 2.0/s | 市场回货速度——决定高价位窗口持续多久 |
| 基准单价 `marketPriceBase` | 0.1（木 0.15） | 起步价；调高 = 补给整体更贵 |
| 幂指数 `marketPricePowerExponent` | 2.0 | **价格陡峭度**：调大 → 缺货时暴涨更凶（更刺激、更买不起）；调小 → 曲线平缓 |
| 计价下限 `marketPriceFloorStock` | 1.0 | 决定价格硬顶的位置（封顶 = 基准价 × (容量÷下限)²）；调大 → 早早封顶 |
| 绝境警戒线 `marketEmergencyFamilyStockThreshold` | 10.0 | 家户水粮跌破多少触发赴市；调高 → 族人更早「惜命」进场 |
| 起步黄金 `marketMinFamilyGold` | 0.5 | 赴市的最低家财门槛 |
| 起步体力 `marketMinDispatchStamina` | 15.0 | 赴市的最低体能门槛，防半路倒毙 |
| 结算步长 `marketSettlementStep` | 5.0 | 单笔买入批量；调大 → 每次买更多（黄金消耗更快）、流水更稀疏 |
| 豪绅门槛 `marketWealthyFamilyGold` | 200 | 家资达到多少进入「80% 免劳役、现货采购」阶层 |
| 平民门槛 `marketPoorFamilyGold` | 50 | 家资低于多少严格自力更生、非绝境不进市场 |

## 9. 已知限制与产品需要知道的边界

1. **市场不解决物理短缺**——它只是外部输入，若全社会已无水粮，市场库存也会被买空；无偿救济仍由宗族/王国的社会互助机制承担。
2. **市场不保证无资产者获救**——家户黄金不足 `marketMinFamilyGold` 者不会空跑赴市；买不起的人仍会死在断流期，这是设计内的事。
3. **石/金无市场兜底**——采石、采金断流只能硬扛，不享受榷场兜底。
4. **只有男户主能赴市采购**——女性、非户主成员不直接支配家户金库出资。
5. **市场是「只买不卖」的单行道**——玩家/部落民不能向榷场出售物资；黄金只出不进。
6. **全图只有一座市场**——距离即成本，偏远家户的「赴市保命」代价更高；同时它也因唯一性成为地理锚点。
7. **价格硬顶随参数漂移**——「封顶价」= 基准价 × (容量 ÷ 计价下限)²，默认水粮为 16000 金；改容量或基准价会同步改变封顶位置（tech/09 正文「1000 金」表述待更正）。
8. **调参是全局热调**——市场参数不换世界、不废旧档，但会显著改变经济节奏与贫富分化曲线，调参前建议在确定性种子下对照观察（同种子可复现）。

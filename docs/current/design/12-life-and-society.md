## 1. 马斯洛六层需求：他们为什么这么做

每个族人心里压着一座金字塔，**低层需求绝对阻断高层欲望**：

| 层次 | 需求 | 他们会做什么 |
| :--- | :--- | :--- |
| ⓪ 瞬间行为 | 竞拍购房 / 就近求偶 / 在宅养育 | 满足条件当拍即刻写入意图，零位移、零消耗，且同一拍内继续向下评估常规分支 |
| ① 生理 | 夺位远征 / 解渴 / 觅食 / 休养 / 立宅 | 王位是生存资源的终极分配权（空悬即点燃野心）；无家成年男性生理稳定后自主选址立宅，必须物理走完路线才实体化 |
| ② 安全 | 房屋修缮 / 水粮家宅储备 | 耐久跌破 50% 一路修满 100%；家户账本库存跌破阈值即出发补货 |
| ③ 归属与爱 | 求偶成婚 / 家庭供给 | 单身男性主动追求魅力最高的单身女性；成家后为家户账本驮运给养 |
| ④ 尊重 | 升级施工 / 养育小孩 / 采石备料 | 账本建材达标当拍瞬时晋升，每晋升一级威望 +1 |
| ⑤ 自我实现 | 大庄园备金 / 娱乐淘金 | 4 级大庄园竣工前绝不享乐淘金——自我实现必须建立在基业长青之上 |

**决策没有掷骰子**：同样的处境必然做出同样的选择。
资源点该不该跑一趟，由每名族人心里那把**私有标尺**（施密特触发器）决定：库存过半才值得出发，跌破一成就不再前往；
途中遇枯竭会当场平滑掉头改道，绝不瞬移。

**玩家可以策展他们的价值观**：控制台「🧠 决策引擎」把全部 18 条分支按 6 大层级排成可拖动卡片，
拖动分界线或重排卡片即刻热注入运行中的模拟，并可一键落盘持久化。

## 2. 生命周期

| 阶段 | 规则 |
| :--- | :--- |
| 出生 | 始祖按正态分布生成（饱食/水分基线 45 并携带满额补给）；新生儿取父母禀赋均值叠加 ±10 偏移 |
| 禀赋 | 六项先天禀赋：智力 / 力量 / 魅力 / 消化效率 / 睡眠效率 / 预期寿命。高消化更耐饿、高睡眠恢复更快、力量大走得更快 |
| 成年 | 成年阈值后参与决策、劳动与婚育 |
| 婚育 | 成家男性名下拥有 ≥1 级私宅且夫妇体征达标即可孕育；妊娠约 200 秒分娩；流产（450s）与产后（900s）休养冷却独立分立 |
| 代谢 | 健康 / 饱食 / 水分 / 体力四项持续代谢；饿死与渴死在顶栏被单独统计 |
| 死亡 | 遗体保留 12 秒逐渐风化消散；随身五类物资归入其家户账本（无家户则入公仓） |

> 几代之后，某些姓氏会明显「更能活」。

## 3. 房屋：从一间仓库到一座大庄园

| 等级 | 名称 | 升级所需建材（水/粮/木/石/金） | 解锁 |
| :--- | :--- | :--- | :--- |
| 0 | 📦 仓库 | 立宅起步（生理层末档自主选址） | 遮风挡雨的基本盘，无生育功能 |
| 1 | 🛖 茅草房 | 水 50 + 粮 50 | 解锁养育后代资格 |
| 2 | 🏡 半棚屋 | 木 75 + 水粮各 75 | 坚固居所，容纳家族繁衍 |
| 3 | 🏯 木石庄舍 | 石 100 + 水粮木各 100 | 前往金矿淘金 |
| 4 | 🏰 大庄园 | 金 125 + 水粮木石各 125 | 娱乐淘金、终极形态 |

- 升级是**家户账本一次性支付固定建材矩阵**、当拍瞬时晋升，无工时无体力消耗。
- 每晋升一级户主威望 +1；国王与宗族长老天生自带 +3 威望（兼任双重身份叠加为 +6）。
- 房屋**完全去仓储化**：家庭物资唯一真相源是家户账本，房屋只承担等级/耐久/位置/户主/代际。
- **自然折旧** 0.04/s（有主无主统一速率），耐久掉到一半就会有人放下一切去修。

### 无主房：麦穗 37% 最优停止博弈拍卖

户主去世后房屋变为无主空置房，由营地中介主持拍卖：

1. 前 37% 损耗期**只摸底立标杆、绝不出售**；
2. 进入决策期后新报价 ≥ 标杆即成交；标杆无人击穿时按 0.02 金/秒平滑衰减，**打破购买力脱节的双锁死**；
3. 跌过 10% 出清线则见价就卖；无人问津便随耐久归零坍塌。

出价下沉至个体决策的**瞬间层**：买家对全图所有更高等级在售房一次性倾囊出价，
执行器按 ID 升序逐个落地、**首套成交即停**（一人一房铁律）。

## 4. 社会结构：家户 → 宗族 → 王国 → 帝国

| 层级 | 形成规则 | 玩家能看到的 |
| :--- | :--- | :--- |
| **婚姻** | 单身男性主动追求魅力最高的单身女性；一人一生多段婚姻全部留痕，丧偶封账、改嫁开新账 | 婚姻登记簿、族谱配偶连线 |
| **家户** | 家庭跟着男人走；成年子嗣按权重分走家产自立门户；绝嗣则财产入公仓 | 家户账本储备与成员列表 |
| **宗族** | 同姓自动成族，族长为最年长在世男性；按期征收**族税**，并对揭不开锅的族人**互助救济** | 宗族公库与族税流水 |
| **地区王国** | 每座营地是一位国王的领地，**长子继承制**传承王位；王位空悬（含孤儿营地）时男性发动**夺位远征**——物理抵达营地才正式登基，途中目标易主则原地重定向 | 王冠标牌、国王档案、事件日志 |
| **帝国** | 上层政体（M5） | 帝国公帑与辖属关系 |

> **设计判据**：一切制度都必须落回「某个人、某个家庭、某个世代因此改变」。
> 若一个制度只产生数字而不改变任何人的生活轨迹，它就不该先做。

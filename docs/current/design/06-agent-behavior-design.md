# 06. AI 行为设计：自治、可解释与涌现

> **本层定位**：回答「他们**为什么**这样行动」——为什么是严优先级马斯洛而不是效用打分、为什么系统不能替居民派活、为什么决策不掷骰子。
> 六层需求与 18 条分支的**规则清单**见 [`03 族人、家庭与社会规则`](./03-life-and-society.md) §1；
> 状态机、错峰节拍、寻路算法与数据结构见 [`11 决策引擎`](../tech/11-decision-engine.md)、
> [`12 M19 决策架构`](../tech/12-m19-architecture.md) 与 [`03 确定性`](../tech/03-determinism.md)。

## 1. 一句话：他们不是被指挥的单位，是各自过日子的居民

玩家改变的是**环境、公共规则和观察焦点**；「盖不盖、何时盖、盖在哪、娶不娶、夺不夺位」由居民自己决定。
系统只扮演物理规则执行者：放置校验、路网接入、施工结算、交易交割。

这条边界是 [`01 产品总览`](./01-product-overview.md) §2 第二条哲学的展开，也是本文每一条取舍的最终判据。

---

## 2. 为什么是严优先级的马斯洛，而不是效用打分或行为树

| 追问 | 效用最大化 | 行为树 | 本项目选择（严优先级马斯洛） |
| :--- | :--- | :--- | :--- |
| **生存底线能不能被越过** | 不能保证：权重微调让「盖房」略高于「喝水」时，族人会**渴死在工地** | 取决于作者写没写这条优先级 | 用**序数而非基数**：低层未满足时高层完全不被考虑，「生存底线不可逾越」是结构性成立的 |
| **玩家能不能看懂** | 不能：效用分数是黑箱，Inspector 只能给出一个数字 | 可以，但要看懂整棵树 | 可以：看一眼**主导需求**就知道他在干什么、为什么 |
| **行为从哪来** | 从权重表里调出来 | 从作者预设的分支里走出来 | 从**生理 + 环境 + 家宅状况的组合**自然长出来——本项目要的是涌现，不是剧本 |
| **调参代价** | 权重脆弱，微调就可能引发全局行为剧变 | 分支越写越多 | 层级边界语义清晰，加一条分支只影响它自己 |

> **一句话**：本项目的核心体验是**涌现**。族人每拍只回答「我现在最迫切的需求是什么」，
> 剩下的寻路 → 采收 → 返家 → 入账闭环由执行层自动完成。

---

## 3. 为什么系统不能扫描全图替居民派活

禁止「系统扫描指挥」的三条理由：

| 理由 | 系统指挥会怎样 | 自主决策会怎样 |
| :--- | :--- | :--- |
| **涌现性** | 全体族人同步行为（如「所有仓满的房子同时升级」），个体差异与时间分散被抹平 | 各自的处境与节拍不同，行为自然错开 |
| **可解释性** | 无法回答「这个小人在做这件事」是哪来的——动因在系统扫描器里，不在他身上 | Inspector 可追溯到这名族人的主导需求与私有标尺 |
| **扩展性** | 每加一条规则就要新增一个扫描器，代码持续膨胀 | 需求评估是天然扩展点，未来叠加政治资本、认知层都从这里长 |

配套的**可观察结果**：每名族人持有一把**私有标尺**（需求是否值得跑一趟由他自己的滞回区间决定，
而不是全族共用一条阈值线），因此不会出现「全族一窝蜂扑向同一处资源点、采空后又同时放弃」的共振。

---

## 4. 决策不掷骰子：确定性是玩法，不是实现细节

同样的处境必然做出同样的选择。这不是为了好看，而是**回滚、分支、复演、分享**四件事的共同前提：
只有逐字节可复现，「如果当时做了另一个选择」才成为可以真的打开看一眼的东西。

- 决策过程不消耗世界随机数；创世与立宅选址等有掷点的环节按固定顺序消费，保证可复现。
- 想看机制层为什么这么约束，见 [`03 确定性`](../tech/03-determinism.md)；
  想知道它换来了什么玩法，见 [`01 产品总览`](./01-product-overview.md) §2 第一条哲学。

## 5. 他们的价值观是可以被策展的

玩家不能下令某人去做某事，但可以**整体地调整这套价值观**：

| 玩家能做 | 看哪里 |
| :--- | :--- |
| 「🧠 决策引擎」把全部 18 条分支卡片（16 条活跃，另 2 条分别并入「改善住宅」与下沉为采购策略）按 6 大层级排列 | 控制台 |
| 拖动分界线改变层级权重、重排卡片改变同类内的检索顺序，**当拍热注入**运行中的模拟并一键落盘持久化 | 控制台 + 顶栏 |
| 点小人看「🎯 意图 / 🧭 策略 / ⚡ 原语」三栏透视，读到他此刻在做什么、为什么 | 右侧 Inspector |

> 这是本层唯一允许玩家介入「他们怎么想」的入口：**改规则，不改人**。
> 交互细节见 [`05 观察与交互设计`](./05-observation-ux.md) §3。

## 6. 生命周期闭环：从求生到传承

```text
个体求生（饥渴 → 就近资源点 → 采收 → 行囊 → 回家卸货）
  → 真实搬运（每类物资独立背包，容量约束，绝无瞬移）
    → 筑巢成家（成年男性自主选址 → 0 级仓库 → 逐级升级 → 成婚）
      → 代际传承（受孕 → 胎儿入世 → 出生 → 随父入家户/宗族/地区 → 成年分家 → 下一代立宅）
        → 踏路成道（行走留下踩踏值 → 道路升级 → 更多人走 → 主干道涌现）
```

闭环里**没有「系统目标」，也没有「胜利条件」**：每个人只追求自己那一层需求的满足，
群体层面却长出了路网、聚落分布、代际家族树与资源流动模式——这正是确定性规则驱动不可预测长期演化的体验来源。

## 7. 待补：AI 行为的下一步（规划态）

当前结构是**纯确定性规则系统 + 加权 A\* 寻路 + 踩踏拓路涌现 + 生理/家庭/房屋生命周期闭环**，
不含任何学习成分。规划方向：

- **决策架构**：六维政治资本仲裁 + 异步 LLM 认知总线（LLM 不作为核心依赖，只做受控文本层）。
- **寻路**：欲望线热度场 + 时空冲突预约。
- **社会**：人对人的个人态度层——关系 × 生产的传导管道、神经内分泌调制、人际好感度。

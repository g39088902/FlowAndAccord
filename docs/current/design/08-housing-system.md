# 08. 房屋系统（产品视角）：从一间仓库到一座大庄园

> **本层定位**：写给不读代码的产品经理——房屋系统现在能玩到什么、规则是什么、玩家能看到什么、产品可以调哪些旋钮、还缺什么。
> 本文只描述**当前代码中真实存在**的房屋能力（基线 **v1.50.36**）；机制细节见 [`13 房屋系统`](../tech/13-housing-system.md)，
> 玩家规则速览见 [03 族人、家庭与社会规则 §3](./03-life-and-society.md)，「为什么这样设计」见 [06 AI 行为设计](./06-agent-behavior-design.md)。
> 文中数值默认值均以 `frontend/js/config.js` 及拆分配置（升级成本矩阵在 `config.house-upgrade-cost.js`）为唯一真相源（括注字段名）；调参改配置即可，本文不另立口径。

## 1. 一句话现状

> **当前游戏里的房屋 = 0~4 五级私产资本品 + 繁衍与自我实现的资格门槛 + 一套死后流转的二手拍卖市场。**

| 维度 | 现状 |
| :--- | :--- |
| 等级形态 | **5 级**：0 仓库 → 1 茅草房 → 2 半棚屋 → 3 木石庄舍 → 4 大庄园 |
| 家庭物资 | **不存屋里**——房屋已完全去仓储化（M6），家庭物资唯一真相源是家户账本 |
| 升级方式 | **瞬时**：家户账本一次性付清建材矩阵，当拍晋升，无施工计时、无体力消耗 |
| 决策权 | 建房 / 升级 / 修缮**全是族人自主决策**，系统只当「物理规则执行者」，不替任何人派活 |
| 房屋流转 | 户主死亡 → 无主空置 → 营地中介**麦穗拍卖**（已取代父系自动继承） |
| 产权规则 | **只有男性可拥有房屋**；女性不能成为户主 |

房屋是确定性内核里少数几样「可积累、可传承、可流转」的私产：从一间遮风挡雨的仓库，到唯一解锁「娱乐淘金」的 4 级大庄园，它把繁衍资格、社会地位与财富再分配串成一条看得见的上升通道。

## 2. 玩家能玩到的：五级房屋与建材升级

| 等级 | 名称 | 升级到本级的一次性材料成本（水/粮/木/石/金） | 解锁与门槛 |
| :---: | :--- | :--- | :--- |
| 0 | 📦 仓库 | 立宅起步，无成本 | 单身成年男性生理稳定后自主选址立项；遮风挡雨的基本盘，**无生育功能、不供暖** |
| 1 | 🛖 茅草房 | 水 50 + 粮 50 | **解锁养育后代资格**（另需家户木材 ≥ 10.0，代码常量暂未入 SimConfig） |
| 2 | 🏡 半棚屋 | 木 75 + 水/粮各 75 | 坚固居所，容纳家族繁衍 |
| 3 | 🏯 木石庄舍 | 石 100 + 木/粮/水各 100 | 更坚固的庄舍（不消耗黄金） |
| 4 | 🏰 大庄园 | 金 125 + 石/木/粮/水各 125 | 终极形态，**唯一解锁 B13 积累财富（娱乐淘金）的等级** |

**三条产品要记住的规则**：

- **升级是「付得起」而非「等得起」**：升级就绪 = 家户账本可一次性支付该级材料矩阵（`houseUpgradeCostTier{1..4}*` 共 20 字段），该级不消耗的品类填 0、扣账自动跳过；当拍扣账、当拍晋升，**没有施工等待、没有体力门槛**。
- **威望是升迁的可见回报**：房屋每晋升一级，户主威望（prestige）+1；国王与宗族长老天生各带 +3 威望（`prestigeKingBonus` / `prestigeClanElderBonus`，兼任双重身份叠加为 +6）。
- **采货看家户账本，不看房子等级**：去采货（含 0 级有房即可）由施密特触发器驱动——家户账本余额 < `decisionFamilyStockTriggerOn`（默认 100）去采、补到 ≥ `decisionFamilyStockTriggerOff`（默认 200）停；只有自我实现的 B13 才需要 4 级庄园。

### 2.1 三条自主决策链路（族人自己决定盖不盖、何时盖、在哪盖）

1. **立宅（0 级仓库）**：生理层最后档的 `FoundHome`——无家成年男性且饱食/水分 ≥ `decisionFoundHomeHungerMin`/`decisionFoundHomeThirstMin`（默认各 20）、体力 ≥ `decisionFoundHomeStaminaMin`（默认 60）时必然触发；自己掷 `decisionFoundHomeCandidates`（默认 12）个候选点选址，沿路网走到分配地点后系统才做放置校验、路网接入与房产绑定。
   - ★ **无房国王盖房约束**（v1.9.0）：若立宅人是现任国王且无房，候选点必须落在其**王国营地** `poiMinDistance`（70m）半径内，宅邸挂靠王国辖区——国王的家即王国的家。
2. **升级**：家户账本可付该级成本矩阵且轮到户主本人决策相位时产生 `B8ImproveHome` 意图；人在宅门口且无其他持续任务则瞬发提交、当拍晋升，否则生成返宅持续任务。
3. **修缮**：耐久 < `decisionHouseRepairNeedThreshold`（默认 50）时，户主或配偶的决策相位触发 `RepairingHouse`。

## 4. 房屋对玩法做了什么：四条主线

### 4.1 繁衍资格链：没有房，就没有下一代

生育与房屋等级重新挂钩（★ v1.28.0）：**男方（户主）名下须有 ≥1 级私宅方可生育**，0 级仓库不生育；且家户木材 < 10 时禁孕（代码常量，暂未入 SimConfig）。房屋是「让这个家族延续下去」的硬门槛。

### 4.2 社会地位链：威望是升迁的货币

每晋升一级威望 +1，国王/宗族长老自带 +3。威望没有掷骰子、没有捷径——它只来自实打实的家底积累，是族人「被看见的成就」。

### 4.3 自我实现链：大庄园是长线目标

马斯洛第五层（自我实现）只有一条路：**4 级大庄园竣工后才开始娱乐淘金**（B13）。1~3 级房屋是「为生存与家庭」，4 级才是「为自己」——这是全游戏最长的个人目标之一。

### 4.4 财富再分配链：死后房子去哪

户主死亡当拍，房屋 `owner_id`/`spouse_id` 置空，登记到所属营地的 `vacant_houses` 列表并附带受益人（在世子女 + 在世配偶，按 id 升序去重）→ 进入营地中介的麦穗拍卖 → 成交后**份额制分账**：王国公户（`houseAuctionCrownShareWeight`=1）与遗产受益人（在世配偶 1 份 + 每个在世子女 1 份）按权重共分全额成交价，失效受益人份额并入王国公户。**黄金通过房屋在代际与王国内部再流转**——房屋既是资产，也是财政工具。

## 5. 二手房屋市场：麦穗 37% 最优停止博弈（产品视角）

户主去世后的空置房由营地中介主持拍卖，成交判定**只看新报价、不回溯历史**：

| 阶段 | 耐久区间 | 规则 |
| :--- | :--- | :--- |
| 🌾 **观察期** | 损耗 ≤ `houseAuctionObservationRatio`=37% | 只收集报价、刷新最高标杆价（`benchmark_bid`），**绝不出售** |
| 🎯 **决策期** | 37% < 损耗 ≤ `houseAuctionDeadlineDurability`=10% 的补充 | 新报价 ≥ 标杆即成交；标杆每模拟秒按 `houseAuctionBenchmarkDecayRate`=0.02 金线性衰减（下限 `houseAuctionMinBidGold`），**防止高标杆与购买力脱节导致双锁死流拍** |
| ⚠️ **出清期** | 损耗 > 10% | 有新报价即成交；无人出价则挂到耐久归零坍塌，接受该兜底缺失 |

**买家怎么出价**（★ v1.31.0 起为「倾囊出价」）：

- **无房者**（视为 0 级）对全部在售空置房（含 0 级仓库）一次性出价；**有房者**只对 `等级 > 自宅` 的在售房出价（改善型换房）；
- 出价金额 = 家户账本全部黄金（倾囊，无上限）；一次决心写入升序目标集合，执行器按房屋 ID 升序逐个落地、**首套成交即停**（一人一房铁律）；
- 出价后进入 `houseAuctionBidCooldownTicks`（默认 180）全局冷却；成交后买方与配偶/子女迁入，买方搬入后耐久不足 50% 自然激活修缮欲望。

**产品能拿到的数据看板**：世界级累计统计 `auction_started` / `auction_sold` / `auction_flopped` + 全局应价与流拍历程（容量 `AUCTION_HISTORY_CAPACITY`=256，代码常量）；前端按「已结束 = sold + flopped」计算**流拍率**（正在拍卖的场次不进分母），历史应价视图完整呈现成交与流拍两类卡片。

## 6. 产品可以调的「体验旋钮」

> 调参入口：`frontend/js/config.js`（升级成本矩阵在 `config.house-upgrade-cost.js`），免重编译、刷新即生效。

| 旋钮 | 默认值 | 调大 / 调小会怎样（体验语言） |
| :--- | :--- | :--- |
| 升级成本矩阵 `houseUpgradeCostTier{1..4}*`（20 字段） | 水粮 50 / 木水粮 75 / 石木水粮 100 / 金石木水粮 125 | **社会升级节奏**：成本越高，家族繁衍与自我实现越慢，威望越稀缺；越低则人人庄园、淘金泛滥 |
| 房屋折旧 `houseDepreciationRate`（有效速率 ×2） | 0.02/s → 0.04/s | 房子旧得越快，修缮越频繁、空置房越早拍卖或坍塌——整个「房子生命周期」的时钟 |
| 修缮阈值 `decisionHouseRepairNeedThreshold` | 50 | 调高 → 族人更早放下手头事去修（更惜房）；调低 → 房子更破才修 |
| 修缮速率 `houseRepairSpeed` | 5.0/s | 修房占用时间的长度 |
| 冬季供暖阈值 `houseWinterColdTemp` | 8℃ | 调高 → 更早开始烧柴，木材成为冬季硬通货 |
| 供暖耗柴 `houseWinterWoodBurnRate` | 0.12/s | 冬季木材消耗压力 |
| 立宅门槛 `decisionFoundHomeHungerMin` / `ThirstMin` / `StaminaMin` / `Candidates` | 20 / 20 / 60 / 12 | 门槛越高、候选点越少，无家者越难安家——人口流动与聚落扩张速度 |
| 拍卖观察期 `houseAuctionObservationRatio` | 0.37 | 观察期越长，空置房「挂而不卖」越久，房价越可能被拉高 |
| 出清线 `houseAuctionDeadlineDurability` | 10% | 越高越早「见价就卖」，流拍越少 |
| 标杆衰减 `houseAuctionBenchmarkDecayRate` | 0.02 金/s | 调大 → 无人击穿的标杆快速回落，空置房更容易成交；调 0 关闭 |
| 出价冷却 `houseAuctionBidCooldownTicks` | 180 | 冷却越长，抢房节奏越慢 |
| 王国分账权重 `houseAuctionCrownShareWeight` | 1.0 | 调大 → 王国公户从房屋流转中抽成更多，王室更富、继承人更穷 |
| 威望加成 `prestigeKingBonus` / `prestigeClanElderBonus` | 3 / 3 | 身份带来的威望光环强弱 |

## 9. 已知限制与产品需要知道的边界

1. **只有男性可拥有房屋**——女性不能成为户主，丧偶/未婚女性随夫入家户或住营地；这是当前确定性内核的产权规则，不是临时 bug。
2. **房子不装东西（去仓储化）**——玩家的直觉「把物资存在家里」在本作不存在：家庭储备的唯一真相源是**家户账本**，房屋只展示等级/耐久/位置/户主/代际。任何新机制不得另建「房屋库存」真相源。
3. **升级是瞬时的**——没有「盖房子等几天」的施工体验；升级只考验「攒不攒得起建材」，不考验等待。
4. **无主空置房无人修缮**——空置房以与有主房相同速率（0.04/s）风化，无人修、只能等拍卖或坍塌；坍塌后其大门路网节点可被新立宅复用。
5. **拍卖成交保持成交时等级**——换手不升不降；买方搬入后若耐久 < 50% 自然激活修缮。
6. **有房者只能竞买更高等级在售房**——改善型换房不向下置换；无房者（视为 0 级）可竞全部在售房。
7. **0 级仓库不供暖、无生育功能**——冬天 0 级房主靠自身代谢与营地，不享受供暖。
8. **家户木材 < 10 禁孕**——该红线目前是代码常量，暂未入 SimConfig（产品无法直接调参）。
9. **调参影响**：房屋参数（成本矩阵 / 折旧 / 拍卖）属配置热调，不换世界、不废旧档；但它们改变经济节奏与代际财富分布，调参前应先在确定性种子下对比观察（同种子可复现、可比较）。

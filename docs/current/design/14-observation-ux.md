# 14. 观察与交互设计（玩家视角）

> **本层定位**：玩家用什么工具看懂这个世界。
> 实现见 [`50 前端总览`](../tech/50-frontend-overview.md)、[`53 UI 实现`](../tech/53-ui-implementation.md)、
> [`54 制度大盘 UI`](../tech/54-society-ledger-ui.md)、[`55 前端开发指南`](../tech/55-frontend-dev-guide.md)。

---

## 1. 设计原则：观察优先于操作

玩家是观察者，不是指挥官。因此界面投入的重点是**因果可读性**——让每一次「发生了什么」都能追溯到
「谁、为什么、影响了谁」，而不是提供更多的操作按钮。

| 原则 | 落地方式 |
| :--- | :--- |
| **信息逐步展开** | 首局呈现生存、房屋、关系；账本/王国/决策编排/经济分析按需展开 |
| **每个数字可下钻** | 事件卡可跳转到人物、房屋、家户、宗族、王国或族谱 |
| **只提升关键事件** | 事件日志不是流水账；只记录有原因、有后果的转折点 |
| **普通观察保持安静** | 高亮只留给选中/悬浮/关键异常；分析色阶放进可切换的分析视图 |

## 2. 窗口模型：一个世界窗口，四类附属窗口

当前前端是**单页静态前端**，没有 URL 路由器，也没有多页面应用的页面栈：

```text
浏览器标签页
└── 世界窗口 index.html（Canvas 视口 + DOM 浮层）
    ├── 常驻面板   顶栏状态栏 / 生态大盘 / 观察堆栈 / 控制台
    ├── 模态弹窗   拍卖大盘 / 时光倒流 / 存档管理 / 设置
    ├── 独立页     族谱时间轴（独立标签页）
    └── 独立页     地图图鉴 map.html（只读渲染，不启动模拟）
```

- 入口与返回关系、跨窗口跳转契约见 [`53 UI 实现`](../tech/53-ui-implementation.md)。
- 地图图鉴以相同 seed 加载 `index.html?mapOnly=1&nogate=1`，与正式游戏同源且不受存档门禁影响。

## 3. 核心观察工具

| 工具 | 回答什么问题 |
| :--- | :--- |
| **Inspector（点小人）** | 他此刻最想要什么、为什么想要、行囊里装着什么、累计开采与威望 |
| **决策行动中枢** | 🎯 意图 / 🧭 策略 / ⚡ 原语 三栏透视，加 ⓪ 瞬发微光 Pill |
| **房屋面板（点房屋）** | 建筑等级、耐久折旧、家户账本储备、家庭成员列表 |
| **地标面板（点地标）** | 储量、产速与实时单价；榷场显示实时金价与成交流水 |
| **族谱时间轴** | 血脉与代际；Y 轴严格映射出生时刻，主干优先落位，已故胎儿亦入谱 |
| **制度大盘** | 家户 / 婚姻 / 宗族 / 王国四标签页枢纽 |
| **拍卖大盘** | 麦穗博弈时间轴、意向买家池、实时竞价流水 |
| **事件日志** | 关键转折点（婚姻、出生、死亡、分家、继承、建房、升级、迁徙、夺位、拍卖） |
| **时光倒流** | 输入任意历史 Tick 或拖动滑块，毫秒级回滚并自动暂停 |
| **决策引擎视图** | 18 条分支可拖拽重排，热注入并持久化，改变整个部落的价值观 |

## 4. 操作一览

| 操作 | 效果 |
| :--- | :--- |
| **鼠标左键点击小人 / 房屋 / 地标** | 选中并在右侧 Inspector 展开详情 |
| **鼠标滚轮 / 右键拖拽** | 缩放与平移视口（选中小人后镜头自动跟随） |
| **`Space`** | 全局暂停 / 继续 |
| **`L`** | 开关动态季节光照引擎（默认开启） |
| **`R`** | 道路等级热力图（把亮色分阶从普通观察移入分析层） |
| **顶栏「⏪ 倒流」** | 时光倒流控制器（`-100` / `-300` / `-900` / `-1800` / `Tick 0` 快捷芯片） |
| **顶栏「🏛️ 报价」/ 双击在售房屋** | 打开拍卖大盘 |
| **顶栏「☀️ 主题」** | 深色沉浸 / 明亮通透双主题切换并持久化 |
| **控制台「🧠 决策引擎」** | 拖拽分支卡片与分界线，实时改变需求优先级 |
| **控制台「🗺️ 地图图鉴」** | 打开只读地图预览页 |
| **顶栏气温卡片悬停** | 滑出未来 49 年宏观气候演化折线图 |
| **顶栏「💾 存档」「📂 读档」** | 三槽位存档 / 本地文件直接读写 |

> ⚠️ 必须使用 **Chrome 或 Edge**：存档依赖 File System Access API 直写磁盘 `.json`，
> Firefox / Safari 无法建立存档、会被启动门禁阻断。

## 5. 视觉与信息层级

| 尺度 | 该读到的东西 |
| :--- | :--- |
| 远景 | 地貌与聚落（草地、林地、坡地、村落） |
| 中景 | 资源与房屋（小型景观群、接地阴影与院地） |
| 近景 | 人物细节（在土路上往返、泉边取水） |

- 自然偏暖、低至中饱和度的地面色；明亮颜色留给选中对象与紧急事件。
- 固定世界光向统一受光面与投影；地形受光、水底石光与水面波光联动。
- **遮挡排序是硬约束**：Canvas 2D 无深度缓冲，所有世界实体必须进入统一深度队列，
  远处的山要能挡住山后的图标；长条状特征（河道、岸线、边界侧壁）必须**分段入队**，
  否则任一岸段靠近相机就会盖住更远的一切。实现铁律见 [`50 前端总览`](../tech/50-frontend-overview.md)。

## 6. 待补的观察能力（规划态）

- **家族年表与因果链**：把「资源短缺 → 行动选择 → 路线/账本变化 → 家庭结果」串成可回看的链。
- **首局导览与观察焦点**：开局选择家户/族人/宗族/营地，镜头与事件围绕该对象聚焦。
- **事件卡片化**：确定性模板给出「发生了什么 / 直接原因 / 影响了谁」，LLM 不作为核心依赖。
- **导出与分享**：导出家族年表、族谱片段与一局摘要。

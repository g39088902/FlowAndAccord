# 04. 经济与资源规则（玩家视角）

> **本层定位**：物资怎么来、怎么搬、怎么记、怎么定价、怎么被征收。
> 实现见 [`21 生态与 POI`](../tech/08-ecology-and-poi.md)、[`22 市场与定价`](../tech/09-market-pricing.md)、
> [`20 账本与政体`](../tech/07-ledger-and-polity.md)。

---

## 1. 有限生态：23 处资源点

世界不是无限刷新的资源池。全局共 **23 处有限生态地标**：

| 类型 | 数量 |
| :--- | :--- |
| 营地 | 4 |
| 清泉 | 6 |
| 浆果丛 | 6 |
| 林木 | 3 |
| 采石场 | 2 |
| 金矿 | 1 |
| 榷场互市 | 1 |

- 每处有**储量与再生速率**；枯竭后按类型恢复，断流是真实的生存危机。
- Agent 对每处 POI 持有一把**私有施密特触发器**：库存过半才值得出发，跌破一成就不再前往。
- 营地可随行政需要升级。

---

## 2. 真实搬运：没有远程传送

经济的可信度来自**每一步都要真的走完**：

1. 需求成立 → 2. 前往 POI → 3. 装袋（受行囊容量约束）→ 4. 返程 → 5. 回家卸货 → 6. 入家户账本。

- 每人携带水/粮/木/石各 100 独立随身背包，四类容量**不共享**；黄金按需携带。
- 途中资源断流会**当场平滑掉头改道**，绝不瞬移。
- 死亡时随身物资归入其家户账本（无家户则入公仓），不凭空消失。

---

## 3. 家户账本是家庭储备的唯一真相源

这是本项目最重要的经济不变量：

- 房屋**已完全去仓储化**（无 pantry），家庭物资只有家户账本一份真相源，账本**无容量上限**。
- 卸货（Deposit）、在家吃喝（Consume）、冬季烧柴（Heating）都在生态与维护层**真实收付**账本。
- 补货由**家庭库存施密特触发器**驱动：余额低于下阈出发、补到上阈停止，水/粮/木/石/金五类统一；
  有房（含 0 级）即可采，与房屋等级**彻底脱钩**。
- 房屋升级就绪判定 = 家户账本能否支付该次一次性材料成本。

> 任何新机制都**不得**另建与家户账本冲突的储备真相源（这是历史教训：早期房屋仓库层已被删除）。

---

## 4. 外部市场：榷场互市与幂律定价

野外断流或家底告急时，户主直奔全图唯一的榷场，用黄金购买救命水粮。

| 规则 | 说明 |
| :--- | :--- |
| 供给 | 榷场提供外部输入的水、粮、木材储备（石料无外部报价） |
| 定价 | **幂律动态定价**：按市场存量实时推导黄金兑换单价，存量越低价格越陡 |
| 结算 | 固定以 **2.0 离散单位**整洁结算，避免碎数 |
| 支付 | 支持家户账本与随身黄金协同，无需先回家取钱 |
| 流向 | 支付的黄金**流出本地经济**进入虚空，成为整个经济的紧缩通货锚 |
| 观察 | 交易流水环形缓冲全量可查，Inspector 实时显示金价 |

> 典型故事：水荒粮荒、野外断流时，有人揣着最后一点黄金，扑向涨价 100 倍的榷场买命。

## 5. 二次分配：族税、公仓税与救济

| 流向 | 触发 | 玩家能看到 |
| :--- | :--- | :--- |
| 族税 | 宗族按期向族人征收 | 宗族公库余额与族税流水 |
| 族内互助 | 揭不开锅的族人获得宗族救济 | 救济流水与受助家户 |
| 公仓税 | 地区王国按期征收 | 公仓余额 |
| 公仓救济 | 极贫家户获得地区救济 | 救济流水 |
| 国王内帑 | 王国层级的财政留存 | 国王档案 |

> **现状诊断**：这些制度性关系目前是**被动的周期结算**（world tick 定时扫描划账）——
> Agent 既不选择纳税对象，也不选择救济对象。让「某个具体的人」进入他人的生产候选集，
> 是 [`../../plan/design/03-social-relations.md`](../../plan/design/03-social-relations.md) 要解决的核心缺口。

## 6. 内部居民市场（规划态）

当前只有**外部榷场**（向世界购买、黄金流出）。规划中的**居民市集**负责跨家庭、跨时间调剂真实存量：
缺水缺粮的家庭用积存的木材、石料和黄金换命；水粮富余的家庭在建材断流时用余粮换回物资。

方案已从「AMM 恒定乘积池」演进为**售货员撮合 + 有限订单簿**（真人族人充当中介，价格背后是人与人的行为，
更易叙事、更易观察）。详见 [`../../plan/tech/03-internal-market.md`](../../plan/tech/03-internal-market.md)。

> 市场**不解决**全社会已无水粮的物理短缺，也**不保证**无资产者获救——无偿救济仍由既有社会互助机制承担。

## 7. 经济可观察性

经济不是魔法数字，**每一笔流动都写进账本**：

- 人物卡：行囊物资、累计开采、社会威望、当前意图与原因。
- 房屋面板：等级、耐久、家户账本储备与成员列表。
- 地标面板：储量、产速与实时单价；榷场额外显示水粮实时金价与成交流水。
- 制度大盘：家户 / 婚姻 / 宗族 / 王国四标签页枢纽，含分家继承与宗族公库。
- 宏观：资源流水与市场历史可查；未来规划中的分配、贫富差距与资源诅咒视图见
  [`../../plan/design/01-roadmap.md`](../../plan/design/01-roadmap.md) M14。

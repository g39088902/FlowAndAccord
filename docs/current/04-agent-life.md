# 4. 🧬 部落民生理代谢、繁衍与寿命 (`agent`)

> **模块索引**：[← 返回 CURRENT.md 全景索引](../../CURRENT.md) · 主要源码：`crates/sim_core/src/spatial/agent.rs`、`birth.rs`、`housing_system/marriage.rs`

---

- **生理基础指标体系**：
  - **❤️ 健康需求条 (`health`)**：出生时初始值为先天寿命属性值（`life_expectancy`），每秒自然衰减 $0.02$ 单位（不可通过进食或休息补充，对应约 5000s / 150,000 ticks 寿命），初始族人按开局年龄折减初始健康，归零后部落民寿终正寝（安详离世）。Inspector 与均值大盘均展示实时健康需求条与百分比。
  - **🍖 饱食度 (`hunger`)**：容量 $0.0 \sim 50.0$ 单位（初始 $25.0$ 即 $50\%$），未怀孕 $0.10/\text{s}$，孕期 $0.125/\text{s}$（$1.25\times$ 正常代谢），归 0 即饿死。
  - **💧 水分值 (`thirst`)**：容量 $0.0 \sim 50.0$ 单位（初始 $25.0$ 即 $50\%$），未怀孕 $0.10/\text{s}$，孕期 $0.125/\text{s}$（$1.25\times$ 正常代谢），归 0 即渴死。
  - **⚡ 体力值 (`stamina`)**：$0 \sim 100\%$，劳作/奔跑/爬坡消耗，休眠快速恢复。
  - **🎒 随身行囊 (真实搬运机制)**：水/粮/木/石在资源点**装入行囊 (每类独立容量 50.0 单位，互不共享)**，回家休整时按 10.0/s 卸货存入私宅仓库，行囊满或家宅满即返程；**🪙 黄金 (`carried_gold`) 容量无限**，单趟运满 20 回宅存入金库。
- **年龄与两性分化**：
  - $0 \sim 1800\text{s}$ 为幼年期（男童/女童），未成年子女与父母同住共享私宅。
  - $\ge 1800\text{s}$ 为成年期，初始 20 名始祖族人（10男10女）开局年龄统一设定为 $1800\text{s}$（成年）。男性成年且满足条件可自发立项建房，女性具备生育功能。
  - **私产确权原则**：**只有男性可以拥有房屋**；男性只有成年后（$\ge 1800\text{s}$）才会盖房/升级，但未成年男嗣可以接受遗产继承。女性（包括遗孀和女儿）不能拥有私宅，在丧偶或未婚时住营地或改嫁入驻有房男性私宅。
- **婚姻、改嫁与繁衍闭环**：
  - 拥有 1 级以上私宅的成年单身/丧偶男性会自动就近迎娶营地中的成年单身/丧偶女性（**改嫁机制**）；**成婚机制与建房/升级事件完全解耦**（v0.9.37 起移除 0级→1级升级竣工瞬间的即时迎娶 eager 钩子），由 `marriage.rs` 每 tick 持续扫描自动匹配——升级竣工后 ≤1 tick 内即可自动成婚，择偶就近选取。
  - **受孕门槛**：成年已婚女性在**执行任意任务期间均可受孕**（v0.9.41 起不再要求必须在家休息），饱食度 $\ge 40.0$（$80\%$）且水分 $\ge 40.0$（$80\%$）且体力 $\ge 80.0\%$ 且房屋水粮木均 $\ge 50\%$ 最大容量；**流产后的休养冷却期为 450 秒**（v0.9.41，期间禁止再次受孕）。
  - **900 秒妊娠期**：孕妇头顶显示孕育进度环与粉色光晕。
  - **分娩与血脉传承**：孕期圆满后在家庭私宅诞生新生儿（50%男婴/50%女婴），精准计算代际（$\max(\text{父代}, \text{母代}) + 1$），始祖为第 1 代，新生儿明确标注代数（如第 2 代、第 3 代等），记录父母双亲与子女双向索引并在族谱与标签中全链路呈现。
  - **🧬 先天禀赋属性**：每位族人携带 6 项先天属性 —— 🧠智力 / 💪力量 / ❤️‍🔥魅力 / 🍽️消化效率 / 😴睡眠效率 / ⏳预期寿命。始祖代按正态分布 $N(100, 20)$ roll（均值 100、标准差 20，约 95% 族人落在 60~140，clamp 10~190 防极端值）；**新生儿**各属性取父母双方均值再叠加 $\pm 10\times$ 线性随机数（$\pm[0,10]$ 均匀偏移）。属性随快照下发前端，族谱弹窗记录展示；其中 **🍽️消化效率参与代谢结算**（饱食代谢消耗速率 $= 0.10/\text{s} / (\text{消化效率}/100)$，进食按 1:1 直接摄入；高消化效率者代谢消耗慢、极度耐饿，食物匮乏时具备更强的存活抗逆性）**、😴睡眠效率参与休息结算**（体力恢复速率 $= 8.0\%/\text{s} \times$ 睡眠效率$/100$，属性越高所需休息时间越短）。
  - **🤰 孕期禁改嫁与生父确权 (v0.9.21)**：受孕时记录受孕生父（`pregnancy_father_id`）；若丈夫在 900 秒妊娠期内不幸离世，怀孕女性在妊娠完成前**绝对不可改嫁**（排除在 0 级建房与营地单身迎娶候选人之外）；新生儿分娩出生时准确继承真实生父 ID，分娩圆满结束后母亲方可恢复单身待改嫁资格。
- **尸体风化消散**：饥荒或脱水死亡后遗骸保留 $12\text{s}$ 逐渐风化消散，配偶自动恢复单身。

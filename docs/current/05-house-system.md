# 5. 🏡 多级私产房屋与建材升级体系 (`house`)

> **模块索引**：[← 返回 CURRENT.md 全景索引](../CURRENT.md) · 主要源码：`crates/sim_core/src/spatial/house.rs`、`housing_system/`（5 子模块）  
> **版本演进记录**：见 [11-changelog.md](./11-changelog.md)

---

房屋是部落民的耐用资本品、独立分品类仓储与繁衍避风港。共有 5 级建筑形态：

| 建筑等级 | 图标 | 各项仓储容量 | 升级所需物资与条件 | 特殊功能与权限 |
| :--- | :---: | :---: | :--- | :--- |
| **0级 仓库** (`Tier0Warehouse`) | 📦 | 各 $20.0$ 单位 | **无初始赠送**，需自主搬运水18 + 粮18蓄满 | 单身成年男性立项设立，无生育功能。 |
| **1级 茅草房** (`Tier1ThatchedHut`) | 🛖 | 各 $40.0$ 单位 | 需木材蓄至85% ($34.0$)，水粮保底充足 ($20.0$) | 自动迎娶结发妻子，水粮木 $\ge 50\%$ 激活生育。 |
| **2级 私宅** (`Tier2LeanTo`) | 🏡 | 各 $80.0$ 单位 | 需石料蓄至85% ($68.0$)，水粮木充足 ($40.0$) | 私产大屋，开始允许采石积累升级建材。 |
| **3级 木石庄舍** (`Tier3Homestead`) | 🏯 | 各 $120.0$ 单位 | 需 **黄金蓄至85% (102.0) + 石料蓄至85% (102.0)** | 高级庄舍，激活前往金矿淘金动机。 |
| **4级 氏族大庄园** (`Tier4Manor`) | 🏰 | 各 $160.0$ 单位 | 终极形态 (无需再升) | 极品大庄园，提供超大规模独立储备空间。 |

- **房屋自然折旧与修缮**：房屋随房龄缓慢折旧，耐久度 $< 85\%$ 时户主自发投入体力劳作修缮至 $100\%$。
- **父系代际继承机制**：
  - 男人死后，房屋确权转让给其在世且自身无房的直系男性后代（年长优先，未成年亦可继承接受遗产）；
  - 遗孀与女儿不拥有房屋，迁出至管辖营地居住，遗孀可改嫁其他单身男性户主；
  - 其余未继承房产的男性子嗣迁回营地居住，成年后可自立门户选址建房；
  - 若故去男主人无无房男性后代，宅舍沦为无主废墟。

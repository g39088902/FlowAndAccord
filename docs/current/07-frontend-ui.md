  - 小人状态专属色彩、妊娠光环、分娩彩屑、施工进度环与位移拖尾。
- **动态 Inspector 观察仪表盘**：
  - **小人面板**：饱食度/水分值/体力值实时进度条、🎒 随身行囊 (💧水/🍒食/🌲木/🪨石 各 50.0 容量 + 🪙黄金无限，实时数值与容量条)、🚚 搬运去向 (正在搬运的资源与目标家宅)、年龄与性别可育状态、家族世系族谱（可点击直接追踪父母/配偶/子嗣）。
  - **🧬 族谱弹窗先天禀赋**：族谱页展示当前族人的 6 项先天属性数值条（🧠智力/💪力量/❤️‍🔥魅力/🍽️消化效率/😴睡眠效率/⏳预期寿命，刻度 0~200），并标注属性来源（始祖代 N(100,20) 正态 / 后代父母均值±10 遗传）。
  - **房屋面板**：耐久度、水/粮/木/石/金 5 种独立私有储备仪表、户主确权标识、生育激活状态。
  - **地标面板**：地标储量进度条、产出速率、地理高程与坐标定位。
- **🗺️ 图例窗口 (Legend Panel)**：
  - 右侧面板默认折叠收起，展示 21 处 POI、5 阶道路等级与建造升级规则，支持一键展开/收起。
- **全景控制台**：
  - 240s 四季时钟与实时气温显示、暂停/继续、倍速调节 (1x~32x)、随机重抽生态、镜头一键跟随选中小人、**🧠 无头模式按钮 (只推进模拟、跳过画布渲染，适合长程快速演化)**。
  - 实时部落重大历史事件滚动日志（建房、结发、受孕、分娩、升级、冻馁事件等）。
- **⚡ 高效轻量化渲染引擎 (低 GPU 显卡开销优化)**：
  - **地形网格批处理**：全图 $60\times 60$ 网格采用单次顶点投影 + 静态高度颜色预缓存 + 视口边界裁剪 + 批处理线框渲染，将单帧 Canvas GPU 绘图指令减少 80%+。
  - **零 Shader 开销光晕**：彻底移除高显存开销的 Canvas `shadowBlur` 高斯模糊与 CSS `backdrop-filter`，改用高性能双层矢量描边与深色质感半透明底色。
  - **高分屏 DPR 自动钳制**：智能约束最大渲染分辨率 `Math.min(devicePixelRatio, 1.25)`，大幅降低 2K/4K 屏幕显存带宽吞吐。
  - **DOM 统计节流**：顶栏生命体征与大盘仪表盘以 10 FPS 降频更新，杜绝主线程高频 Style 重排。
  - **全阶演化倍速控制**：提供 1x/2x/4x/8x/16x/32x/64x/128x 八档仿真倍速，支持 `localStorage` 状态持久化记忆与高倍速无头演化。
  - **📊 全局族人均值大盘卡片 (v0.9.18)**：右侧提供默认折叠的均值聚合面板，实时计算并展示全图所有存活族人的饱食/水分/体力/年龄/移速均值、随身物资负重均值、六维先天禀赋遗传均值、性别比例、有房率，以及**💘 成年单身男女人数 (男♂ / 女♀) 与 💑 结发夫妻对数统计**；全面修复已故族人与后代在 Inspector/族谱中点击穿梭时的变量作用域引用异常。

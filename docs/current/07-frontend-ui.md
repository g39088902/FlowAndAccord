## 模块定位

纯静态前端（无构建步骤），通过 Canvas 2D/3D 投影渲染模拟世界，提供 Inspector 观察面板、族谱可视化、账本大盘、调试监视器与全景控制台。前端是用户与模拟内核交互的唯一界面。

## 核心机制

### Canvas 渲染管线
- **分层渲染顺序（★ v1.47.5 P0 / ★ v1.47.9 统一深度 / ★ v1.48.0 光照氛围）**：严格遵循地表物理遮挡层次调度：
  0. `SimLighting.update()`：推进年度光相（含视觉限速器），光档变化时整片重着色地形（`cell.color` 原地写回）；
  1. `drawSkyBackdrop()`：天空/地平渐变与逆光光晕（第一个氛围插入点，地表之下）；
  2. `drawTerrain()`：3D 连续坡度与法线环境光遮蔽（AO）高程沙盘网格（含随光向变化明的沙盘侧壁）；★ v1.48.1 起每格四边沿外法线外扩 `TERRAIN_SEAM_PX`(0.75px)，消除相邻格抗锯齿缝隙导致的「深色网格线透出」（详见 `frontend/AGENTS.md` §5.9）；
  3. `drawLanes()`：动态踩踏路网（贴地纹理，先于建筑绘制）；
  4. `drawSelectedCampHouseLinks()` + `drawPoiGroundBases()`：贴地图元补充层（选中营地辖区虚线、POI 底座与营地暖光，必须先于立体实体落笔）；
  5. `drawAtmosphereWash()`：大气色洗（第二个氛围插入点，在立体实体之前，建筑与文字不被洗灰）；
  6. `drawWorldEntities()`：**★ v1.47.9 世界立体实体统一深度绘制**——POI 标记（图标/门牌/储量环）、私产宅舍（手办级 2.5D 微缩立体模型与落底阴影）、部落民（微接触投影、植物染料服色与低噪状态环）合并为单一绘制队列，按相机深度**远 → 近**依次落笔；
  7. `drawCoronationEffects()`：登基礼花与全屏动态特效。
- **★ v1.48.0 动态季节光照（年周期光弧）**：光源绕世界一年转一圈，四季各占一个象限（春=东 / 夏=南 / 秋=西 / 冬=北），盛夏高度角 72°、隆冬 22°；地形反照率与光照解耦（`computeTerrainAlbedo` 一次性预算 + `SimLighting.relightTerrain` 按光档重算光因子），房屋墙面/屋顶与沙盘侧壁按面法线受光，阴影方向与长度由世界空间光向投影到屏幕（随相机旋转）。详见 [27-plan-seasonal-lighting.md](../27-plan-seasonal-lighting.md) 与 `frontend/AGENTS.md` §5.10。
- 动态等高线网格地形，读取内核 `GeoCell` 的地表类别、坡度和自然适宜性；v1.47.7 起不再绘制 `Ridge` 山脊线、`Saddle` 山口圆与 `Terrace` 台地轮廓（该类特征已整体删除）；T2 仍绘制真实两岸河谷、河阶、浅滩走廊与泉谷等水系特征。
- **灵动立体水系（★ v1.47.5 P1 升级）**：`ShallowWater`/`DeepWater` 告别暗黑枯水色，升级为清透碧蓝山泉色盘；`River` 采用三层渲染（深潭暗底 + 碧蓝水体 + 中心斜阳波光反射高光线），`RiverBank` 采用温润浅金细砂漫滩，`ShallowFord` 呈现卵石踏道与飞溅浪花，消除“干涸黑凹槽”死气。
- **世界实体统一深度排序（★ v1.47.8 房屋 → ★ v1.47.9 全实体）**：Canvas 2D 无深度缓冲，同层元素按数组原序绘制会出现「远物压近物」。`drawWorldEntities()` 每帧把 POI 标记 / 房屋 / 族人按 `project3D().depth`（= `ry·sinX + z·cosX`，数值越大越靠近视点）升序排列后绘制——**远物先画、近物后画**，同深度保持快照原序（`Array.sort` 稳定）以维持渲染确定性；排序只作用于绘制队列，不修改 `sim.pois` / `sim.houses` / `sim.agents` 顺序，点击拾取与 Inspector 遍历逻辑不受影响。POI 的贴地底座/营地暖光归入第 3 层地面 pass，因此不会糊在近处建筑上。
- 地貌特征来自 FABS/JSON 静态快照，前端不自行生成碰撞、通行或资源事实；换世界、读档和回溯时随地形缓存一起重建。
- **双模道路呈现**：默认自然观察模式采用低饱和泥土、夯土与石板的大地材质色阶（随 wear 动态提升线宽与平整度），关闭刺眼外发光；按 `R` 键切换道路热力图分析模式，高亮展示 5 阶等级色与外圈发光，专供交通运力拓扑研判。

### ★ Web Worker 独立仿真架构（★ v1.38.0 Phase 1 解耦）
- **内核与渲染双核分离**：将计算密集型的 Rust WASM 确定性内核与状态快照生成完全移入专属 Web Worker（`frontend/js/sim_worker.js`），运行在独立的 CPU 核心上；主线程（`rustworld.js` 作为轻量 Facade 代理）专职负责 Canvas 视口绘制与用户事件。
- **自适应计时循环与背压限频**：Worker 自主以 60Hz 循环步进 `world_tick_steps`（步长由 `speedMult` 驱动）。通过 `ackReceived` 握手锁实施背压控制——Worker 仅在主线程消费完上一帧快照并回传 ACK 后才下发最新快照（★ v1.44.3 起锚定 ~30Hz，与前端 30 FPS 渲染帧率对齐；★ M5-0.4 v1.46.0 起改为**按人口自适应降频**：≤200 人 30Hz / ≤320 人 25Hz / ≤450 人 20Hz / 更高 15Hz，档位由帧头 AGENT 记录数驱动，见 `sim_worker.js::SNAP_THROTTLE_TIERS`）。高倍速（5x~100x）下 Worker 在后台吃满算力全速冲刺，主线程 Canvas 彻底免于消息堆积，始终稳定在 30 FPS（`TARGET_FPS = 30`）丝滑响应。
- **异步存读档桥接**：`saveWorld()` 与 `loadWorld()` 升级为 Promise 异步桥接，完全适配 `save-ui.js` 的 File System Access API 异步读写流程，存读档操作零阻塞 Canvas 绘制。
- **多核算力跃升**：彻底打破单核单线程瓶颈，多核 CPU 利用率由原本的 25% 跃升至 40%~50%（主线程与 Worker 各自跑满独立物理核），彻底根除了高倍速下的 UI 冻结与相机卡顿。

### 族谱系统（时间轴布局）
自 v0.9.64 起彻底废除力导向布局，改为**确定性时间轴布局**：
- **Y 严格线性映射出生 tick**：`Y = (birthTick − tickMin) × PX_PER_TICK`，先出生者必在上，无任何排名/代数/力学修正。默认密度 0.002 px/tick，按图中最短有效亲子出生间隔自动提高密度下限，使子代顶部至少低于父母卡片底部 34px；密度滑块低于此下限时保持最小间距。
- **X 冲突横向扩展**：主干链优先落位（焦点父系上溯+长子下溯主脉锚定第 0 列）、核心家庭分组（同父母子女按出生序居中于双亲中点）、整数列网格冲突探测（纵向净距 < 114px 即冲突，向两侧探测最近无冲突列）、两轮局部松弛。
- **视口虚拟化 + 缩放分层 LOD**：只挂载视口内（含 260px 缓冲）的卡片与边，DOM 池复用；LOD 三档——概览档（scale<0.45）纯色块、简档（0.45~0.75）头像+编号+世代徽章、全档（≥0.75）完整卡片。概览底色按男蓝/女紫/已故灰编码，主干仅用亮边，红色专用于当前选中人物；悬停提示编号、世代与生死。
- **时间刻度尺**：左侧常驻 74px 宽刻度尺，按缩放自适应粒度（季/年/5/10/25/50/100 年），配年代分隔带背景线。
- **认知减负**：悬停卡片时仅高亮其父母与子女，其余降至 16% 透明度；顶栏时间密度滑块（0.25x~4x）实时 relayout，保留选中人物的屏幕位置；悬停仅切换高亮类，不重建卡片内容；拖拽记录按下时的节点 ID，指针取消或超过拖动阈值时不触发选中。
- **直系血脉单图**：仅收录焦点的父/母递归祖先链 + 子女递归后代链，旁系亲属不入图，避免长期演化后节点爆炸。
- **模块拆分（4 文件）**：`dag-layout.js`（纯布局数学，零 DOM）/ `dag-view.js`（虚拟化渲染+LOD+pan/zoom+刻度尺）/ `dag-standalone.js`（独立新标签页模板）/ `dag.js`（数据构建+模态编排+Inspector）。
- **已故与流产入谱（v1.8.7）**：死亡/流产墓碑（`snap.recent_deaths`）驱动档案库补记——高倍速下跨过衰减窗口也不丢死因（"💀 死因: 饥荒饿死"等）；流产/随母亡故的腹中胎儿以"已故子嗣"节点入谱（死因: 流产），血缘 fatherId/motherId 由墓碑携带，族谱时间轴可见。

### 全景控制台
- 240s 四季时钟与实时气温显示、暂停/继续（空格键）、倍速调节（1x~1024x 八档）、随机重抽生态、镜头一键跟随。
- **时光倒流控制器（⏳ 回滚）**（v1.46.1）：点击顶栏或控制台「⏳ 回滚」呼出控制器，支持任意不晚于当前世界的 Tick、拖动滑块与快捷芯片。Worker 收到请求即原子暂停，从最近的前置完整检查点按 `world_tick_steps(delta, 1/60)` 分批确定性重演，并显示实时进度；回滚后自动暂停、截断旧未来检查点和状态命令，形成新的唯一时间线。读入中途存档后，面板会显示该存档 tick 为最早可回滚边界，而不再错误宣称可回到 Tick 0。

**产速口径（v1.22.6 统一）**：

- 倍率**唯一真相源在内核**：`World3DEngine` 的 5 个 `*_regen_multiplier`（已入存档）经快照下发为 `sim.regenMultipliers`；滑块每 100ms 由内核值回写（`syncEcoRegenSliders()`），读档/重置后滑块自动回到世界真实倍率。

## 关键不变量
- 前端是纯静态文件（index.html + style.css + js/*.js），无构建步骤，改完刷新即生效。
- 族谱布局为确定性时间轴，同数据必得同结果（无随机数、不依赖遍历顺序）。
- 空格键暂停不受 web 控件焦点残留影响（仅文本输入场景保留空格原始行为）。
- 3000 端口被占用时说明服务已运行，无需重复启动 server.js。

## 与其他模块接口
- `rustworld.js`：通过 WASM 线性内存获取快照，调用 `sim.tick()` 推进模拟，`applyConfig` 注入配置。
- `sim_wasm.wasm`：编译产物双副本（`frontend/rust/` 与 `frontend/`）。
- `config.js`：所有数值参数的唯一前端入口。

## 调参入口
前端无独立配置文件，所有数值参数通过 `config.js` 驱动，见 [06-config-reference.md](../06-config-reference.md)。

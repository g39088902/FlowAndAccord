- **⚡ 高效轻量化渲染引擎 (低 GPU 显卡开销优化)**：
  - **地形网格批处理**：全图 $60\times 60$ 网格采用单次顶点投影 + 静态高度颜色预缓存 + 视口边界裁剪 + 批处理线框渲染，将单帧 Canvas GPU 绘图指令减少 80%+。

  - **DOM 统计节流**：顶栏生命体征与大盘仪表盘以 10 FPS 降频更新，杜绝主线程高频 Style 重排。
  - **全阶演化倍速控制**：提供 1x/2x/4x/8x/16x/32x/64x/128x 八档仿真倍速，支持 `localStorage` 状态持久化记忆与高倍速无头演化。

  - **🌳 直系血脉时间轴族谱 (v0.9.20 ~ v0.9.23, v0.9.57 重构, v0.9.58 纯力学布局, v0.9.59 出生时序播种, v0.9.60 收敛重构, v0.9.61 直系血脉裁剪, v0.9.62 焦点暗红+祖先红蓝边, **v0.9.64 出生时间轴重构**)：**自 v0.9.64 起彻底废除力导向布局**（力学的 Y 向松弛与"Y 严格映射出生 真实数据拟合得出（`tools/gen-dag-testdata.js`）：亲子出生间隔 min 30,885 tick → 124px ≥ 114px（任意亲子纵向不打架、连线基本垂直），同胞间隔 p50 27,007 tick → 108px < 114px（同父母子女自然横向并排成"同代行"），整图 50 万 tick → 约 2,000~2,400px 高、长宽比≈1.35，各焦点 fit 直线边，简档（0.45~0.75）显示头像+#编号+世代徽章，全档（>0.75）显示完整卡片（状态行+六维禀赋+居所）；左侧常驻**时间刻度尺**（74px 宽，不随横向平移）：按缩放自适应粒度（季/年/5年/10年/25年/50年/100年）标注「第N年」并配贯穿画布的年代分隔带背景线（1 tick=1/30 秒，7,200 tick=1 年）；顶栏新增**时间密度滑块**（0.25x~4x

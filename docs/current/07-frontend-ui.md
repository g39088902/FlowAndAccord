## 模块定位

纯静态前端（无构建步骤），通过 Canvas 2D/3D 投影渲染模拟世界，提供 Inspector 观察面板、族谱可视化、账本大盘、调试监视器与全景控制台。前端是用户与模拟内核交互的唯一界面。

## 核心机制

### Canvas 渲染管线
- 动态等高线网格地形、光晕 POI（💧水泉/🍒果丛/🌲林地/🪨石矿/🪙金矿/🏕️营地）。
- 小人状态专属色彩、妊娠光环、分娩彩屑、施工进度环与位移拖尾。
- 5 阶道路恒宽色彩渲染（详见 [01-spatial-network.md](./01-spatial-network.md)）。

### 动态 Inspector 观察仪表盘
- **小人面板**：2×2 紧凑生存健康网格（❤️健康/⚡体力/🍖饱食/💧水分）、5 格行囊胶囊徽章（水/食/木/石各 100.0 + 黄金无限，仅显示分项数值）、搬运去向、年龄性别可育状态、家族世系族谱入口。
- **房屋面板**：耐久度、水/粮/木/石/金 5 种独立私有储备仪表、户主确权标识、生育激活状态。
- **地标面板**：储量进度条 + 产出速率。（v1.22.6 起移除「地形地貌 / 所属辖区」两行；产出速率显示**生效值**＝基准产速 × 生态大盘倍率。榷场互市为双商品地标，清水与粮食各占一条独立库存进度条与一条独立产速）
- **家户归属卡片**：家户 ID/户主姓氏/成员数/角色徽章（👑户主·💍配偶·👶子女）/账面 5 资源/家户大事记/最近流水。
- **婚姻登记卡片**：存续中·丧偶离异·未婚三态、婚龄、历史婚姻段列表。
- **宗族与王国归属**：所属宗族/族长、所属地区/国王、是否夺位远征中（`is_on_expedition`，目标营地 `expeditionTargetCamp`/待登基 `coronationPending` 随快照下发）。
- **★ v1.9.0（Task1）进度条悬停速率**：饱食/口渴/体力/房屋耐久/怀孕进度条悬停显示「每秒变化速度」（EMA 平滑 + 真实时间戳按游戏秒计量，0.6s 间隔重置；耐久含修缮/自然风化场景文案，怀孕以进度 % 计量）。
- **★ v1.9.0（Task3）营地王国卡片**：选中营地时，Inspector 展示「王国·营地辖区」信息框——国王（可点击追踪）/继承人/历史国王档案/管辖家庭/王国账本（公仓 5 资源 + 最近流水含 `Legacy` 绝嗣遗产事由）；王位空缺显示「可被夺位」。营地详情进一步按“空置 / 已有人居住”分组列出辖区全部房屋，并在地图上以特殊虚线连接营地与所属房屋（空置橙色、已居住蓝色）。
- **★ v1.9.0（Task8）房屋跳转**：agent 卡片/族谱弹窗中的房屋引用（`data-house-id`）可点击，跳转房屋卡片并聚焦镜头。
- **★ v1.26.3 调试模式累计开采（分品种）**：勾选「🐞 调试模式」时，小人卡片「当前意图」卡之后、健康/体力区块之前新增「⛏️ 累计开采」卡片——标题行展示合计 `cumulativeMined`（水/粮/木/石/金五类合计；市场购买与就地自饮自食不计入），下方五品种胶囊网格分别展示 `cumulativeMinedWater/Food/Wood/Stone/Gold`（💧水/🍒粮/🌲木/🪨石/🪙金）；关闭调试模式即隐藏。

### 族谱系统（时间轴布局）
自 v0.9.64 起彻底废除力导向布局，改为**确定性时间轴布局**：
- **Y 严格线性映射出生 tick**：`Y = (birthTick − tickMin) × PX_PER_TICK`，先出生者必在上，无任何排名/代数/力学修正。
- **X 冲突横向扩展**：主干链优先落位（焦点父系上溯+长子下溯主脉锚定第 0 列）、核心家庭分组（同父母子女按出生序居中于双亲中点）、整数列网格冲突探测（纵向净距 < 114px 即冲突，向两侧探测最近无冲突列）、两轮局部松弛。
- **视口虚拟化 + 缩放分层 LOD**：只挂载视口内（含 260px 缓冲）的卡片与边，DOM 池复用；LOD 三档——概览档（scale<0.45）纯色块、简档（0.45~0.75）头像+编号+世代徽章、全档（>0.75）完整卡片。
- **时间刻度尺**：左侧常驻 74px 宽刻度尺，按缩放自适应粒度（季/年/5/10/25/50/100 年），配年代分隔带背景线。
- **认知减负**：悬停卡片时仅高亮其父母与子女，其余降至 16% 透明度；顶栏时间密度滑块（0.25x~4x）实时 relayout。
- **直系血脉单图**：仅收录焦点的父/母递归祖先链 + 子女递归后代链，旁系亲属不入图，避免长期演化后节点爆炸。
- **模块拆分（4 文件）**：`dag-layout.js`（纯布局数学，零 DOM）/ `dag-view.js`（虚拟化渲染+LOD+pan/zoom+刻度尺）/ `dag-standalone.js`（独立新标签页模板）/ `dag.js`（数据构建+模态编排+Inspector）。
- **已故与流产入谱（v1.8.7）**：死亡/流产墓碑（`snap.recent_deaths`）驱动档案库补记——高倍速下跨过衰减窗口也不丢死因（"💀 死因: 饥荒饿死"等）；流产/随母亡故的腹中胎儿以"已故子嗣"节点入谱（死因: 流产），血缘 fatherId/motherId 由墓碑携带，族谱时间轴可见。

### 全景控制台
- 240s 四季时钟与实时气温显示、暂停/继续（空格键）、倍速调节（1x~1024x 八档）、随机重抽生态、镜头一键跟随。
- **无头模式**：只推进模拟、跳过画布渲染，适合长程快速演化；顶栏数据栏在无头模式下依旧实时更新。v1.9.0（Task2）无头模式按钮移至**重演生态右侧同行空位**（节省一行）。
- **调试监视器（🐞）**：每 200ms 刷新，含模拟 Tick、每秒 Tick（现实世界每秒推进的模拟 Tick 数，含倍速加成）、渲染 FPS、内核/快照/渲染耗时、CPU 与内存占用、WASM 线性内存；无头模式下同样刷新。
- 实时部落重大历史事件滚动日志（建房、结发、受孕、分娩、升级、冻馁、**登基/继承/夺位**等）。

### 全局族人均值大盘
右侧默认折叠面板，实时计算全图存活族人的饱食/水分/体力/年龄/移速均值、随身物资负重均值、六维先天禀赋遗传均值、性别比例、有房率、成年单身男女人数、结发夫妻对数。

**有房率口径**（v1.22.6 修正）：分子＝**有主房屋数**（`owner_id` 非空，排除空置/在售/无主房），分母＝**存续家户数**（`is_dissolved === false`），显示为 `百分比 (N间/M户)`。此前口径为「有房人数 ÷ 存活人数」，已废弃。

### 全图生态总余量大盘（含产速倍率滑块）
左侧面板：上方为水/果/木/石/金五类全图储量汇总条，下方为五档**产速倍率滑块**（0x~5x，步进 0.1）与「重置为默认产速」按钮。

**产速口径（v1.22.6 统一）**：
- 滑块标签显示**生效产速**＝`SIM_CONFIG.regenBase*` 基准值 × 当前倍率；基准值一律读配置，不再写死字面量（修正了石 1.50/金 1.20 与内核 2.0/1.8 的既有漂移）。
- 倍率**唯一真相源在内核**：`World3DEngine` 的 5 个 `*_regen_multiplier`（已入存档）经快照下发为 `sim.regenMultipliers`；滑块每 100ms 由内核值回写（`syncEcoRegenSliders()`），读档/重置后滑块自动回到世界真实倍率。
- 用户拖拽期间（`pointerdown`~`pointerup`）暂停回写，避免与拖动打架。
- POI 卡片「产出速率」与滑块标签共用同一算法（基准 × 倍率），两处数字必然一致。

- 全局族人均值大盘显示按金币排序、ID 作为并列裁决的最富家户；家户制度大盘不重复展示该指标。

### 轻量化渲染优化
- 地形网格批处理：单次顶点投影 + 静态高度颜色预缓存 + 视口边界裁剪 + 批处理线框渲染。
- 零 Shader 开销光晕：移除 Canvas shadowBlur 与 CSS backdrop-filter，改用双层矢量描边与深色半透明底色。
- 高分屏 DPR 自动钳制：`Math.min(devicePixelRatio, 1.25)`。
- DOM 统计节流：顶栏与大盘以 10 FPS 降频更新。
- 族谱视口虚拟化：DOM 数量恒定在视口容量+缓冲。

## 关键不变量
- 前端是纯静态文件（index.html + style.css + js/*.js），无构建步骤，改完刷新即生效。
- 族谱布局为确定性时间轴，同数据必得同结果（无随机数、不依赖遍历顺序）。
- 空格键暂停不受 web 控件焦点残留影响（仅文本输入场景保留空格原始行为）。
- 3000 端口被占用时说明服务已运行，无需重复启动 server.js。

## 与其他模块接口
- `rustworld.js`：通过 WASM 线性内存获取快照，调用 `sim.tick()` 推进模拟，`applyConfig` 注入配置。
- `sim_wasm.wasm`：编译产物双副本（`frontend/rust/` 与 `frontend/`）。
- `config.js`：所有数值参数的唯一前端入口。

## 调参入口
前端无独立配置文件，所有数值参数通过 `config.js` 驱动，见 [06-config-reference.md](../06-config-reference.md)。

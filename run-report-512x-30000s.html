6机制归因与结论

  • 改动已验证生效：决策序注入确认 b16 位于 b5 之前；末态仍观察到多名男性处于 SeekingCourtship / Belonging·Courtship，说明求偶不再被备料分支长期压制。
  • 灭绝回归解除：v1.16.0 婚姻断链导致的 5/5 灭绝（18~48ks 归零）未再出现；30ks 末 0/5 灭绝。
  • 剩余瓶颈（非本次改动范畴）：存活仍偏低源于"创始代寿终高峰（约 10ks）+ 出生后劲不足"。健康衰减 0.01/s、寿命基准≈100 健康单位 → 创始代均值寿命约 10,000s；需更高出生率（每对夫妇终生 1~2 孩，低于更替水平 2.1）才能稳定。
  • 正向对照：seed 42 展示出健康路径——4 级庄园 ×3、五营地国王齐备、gen5/gen6 幼年人口在位，说明排序修正后社会可走向繁荣；但依赖种子，平均尚未稳定。

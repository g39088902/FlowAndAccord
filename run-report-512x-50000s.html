2核心发现：v1.16.0 人口灭绝回归

5机制归因（高置信度推断）

  • v1.16.0 核心改动：删除旧自动成婚 tick_marriage_and_remarriage（每 tick 流水线配对），婚姻改由 B16Courtship 求偶决策分支驱动——仅成年单身男性发起，检索魅力最高单身女性。
  • 决策序瓶颈：生产决策序中 B16 位于第 11 位，排在 b14(夺位) b1(口渴) b2(饥饿) b15(榷场) b3(休养) b12(立宅) b4(修缮) b5/b6/b7(备水粮木) 之后，属马斯洛第三层「归属与爱」。男性长期被生理/安全类分支占满决策，求偶极少触发。
  • 正反馈塌陷：婚姻少 → 出生少 → 新生男性少 → 可求偶对象更少 → 更早灭绝；创始代老化死亡后无继。
  • 对照证据：v1.15.1 旧版自动配对婚姻，同种子 50,000s 末 204~242 存活、房屋 72~81、婚姻 779~843，从无灭绝。

6数据口径与方法

  • 引擎：本仓库 frontend/rust/sim_wasm.wasm（本次编译 875,624 B），Node WebAssembly 无头驱动，world_create(60, 764.0, seed, 20) + 生产配置注入。
  • 推进：world_tick_steps(512, 1/30) 循环至 1,500,000 tick；每 ~2 ks 采样一次快照。
  • 对照：git worktree 检出 v1.15.1（3b7eb3a）独立编译，同种子、同口径运行。
  • 口径：快照 total_births / total_deaths_natural / total_deaths_unnatural / total_miscarriages；「自然死亡」=寿终正寝，「非自然」=饥荒/脱水等；灭绝时刻=存活人口首次归零的采样点。
  • 局限：灭绝时刻为 2ks 采样分辨率下的近似；对照仅做 3 个共同种子；结论基于涌现统计而非单元断言。
